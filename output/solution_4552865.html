Intuition

Задача заключается в том, чтобы научиться генерировать k-ую перестановку множества цифр [1, 2, 3, ..., n], где n - заданное число, а k - порядковый номер перестановки. Перестановка - это упорядоченная последовательность элементов.
Пример:
Для n = 3, множество [1, 2, 3] имеет следующие перестановки:
"123"
"132"
"213"
"231"
"312"
"321"
Если k = 3, то третьей перестановкой будет "213". Задача заключается в том, чтобы эффективно находить эту перестановку, не генерируя все предыдущие. Решение задачи требует использования математических итераций для определения каждой цифры k-ой перестановки.

Approach

Для понимания решения задачи о поиске k-ой перестановки можно воспользоваться следующей идеей: каждая цифра в каждой позиции появляется (n-1)! раз в общем наборе перестановок. Это связано с тем, что для каждой фиксированной цифры в текущей позиции, остальные (n-1) цифр можно переставить между собой, а их количество равно (n-1)!. Таким образом, если мы знаем, сколько раз каждая цифра появляется в (n-1) позициях, мы можем определить, какая цифра будет на первом месте, на втором месте и так далее.
1. Создадим вектор factorial, где factorial[i] будет хранить факториал числа i. Этот вектор понадобится для вычисления индекса цифры на каждой позиции.
2. Создадим вектор digits, который будет содержать цифры от 1 до n.
3. Уменьшим значение k на 1, чтобы использовать 0-индексацию.
4. Начнем с самой левой позиции (позиция с индексом n-1) и будем определять цифры на каждой позиции.
5. Для каждой позиции:
- Вычислим индекс текущей цифры на основе k и факториала (n-1).
- Добавим цифру с найденным индексом в результирующую строку.
- Удалим использованную цифру из вектора digits.
- Обновим значение k, вычитая вычисленный индекс умноженный на факториал (n-1).
- Перейдем к следующей позиции.
6. По завершении цикла получим k-ую перестановку.

Complexity

  • Time complexity: O(n), где n - количество цифр.
  • Space complexity: O(n), из-за использования векторов для хранения факториалов и цифр.

C++

#include <iostream>
#include <vector>

using namespace std;

class Solution {
public:
    string getPermutation(int n, int k) {
        string result;
        vector<char> digits;

        // Заполняем вектор цифр числами от 1 до n
        for (int i = 1; i <= n; ++i) {
            digits.push_back(i + '0');
        }

        // Корректируем k для использования 0-based индексации
        k--;

        // Генерируем k-ую перестановку рекурсивно
        generatePermutation(n, k, digits, result);

        return result;
    }

private:
    void generatePermutation(int n, int k, vector<char>& digits, string& result) {
        if (n == 0) {
            return;  // Базовый случай: все цифры обработаны
        }

        int factorial = getFactorial(n - 1);
        int index = k / factorial;  // Индекс цифры в текущей позиции
        result.push_back(digits[index]);  // Добавляем цифру в результат
        digits.erase(digits.begin() + index);  // Удаляем использованную цифру из вектора
        k %= factorial;  // Обновляем значение k

        generatePermutation(n - 1, k, digits, result);  // Рекурсивно обрабатываем следующую позицию
    }

    int getFactorial(int n) {
        if (n == 0 || n == 1) {
            return 1;
        }
        return n * getFactorial(n - 1);
    }
};
