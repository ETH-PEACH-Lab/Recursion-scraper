递归思路

这段代码实现的功能是在一个链表中交换每两个相邻的节点，并返回交换后的链表的头节点。它是用递归的方法来完成这个任务的。下面我将解释这个代码的逻辑，并通过一个具体的例子来说明它是如何工作的。

代码逻辑

  1. 首先，检查链表是否为空(head == null)或者只有一个节点(head.next == null)。如果是这种情况，直接返回head，因为没有足够的节点来进行交换。
  2. 如果链表至少有两个节点，那么将第二个节点(head.next)作为新的头节点newHead。
  3. 接下来，对newHead.next之后的链表部分递归调用swapPairs函数。将head.next设置为这个递归调用的结果。这样，原来的头节点现在指向后面所有已经交换好的部分的头节点。
  4. 将newHead.next设置为head，完成第一个节点和第二个节点的交换。
  5. 返回newHead，即新的头节点，作为整个链表交换后的头节点。

例子

假设有一个链表 1 -> 2 -> 3 -> 4，我们要交换每两个相邻的节点。

  • 在第一层递归中，head指向节点1，因为链表不为空且至少有两个节点，所以进入交换逻辑。
  • newHead会指向节点2。
  • 递归调用swapPairs，此时传入的是节点3，作为新的head。
  • 在第二层递归中，head指向节点3。
  • newHead会指向节点4。
  • 递归调用swapPairs，此时传入的是null，因为节点4后面没有节点了。所以，这一层的递归会返回节点4。
  • 回到第一层递归，节点1的next指向节点4（第二层递归的结果）。
  • 然后，节点2的next指向节点1，完成节点1和节点2的交换。
  • 最终，返回节点2作为新的头节点。

通过这个递归流程，原链表 1 -> 2 -> 3 -> 4 会被重新排列为 2 -> 1 -> 4 -> 3。

在每一步交换中，我们只关注当前的两个节点和如何连接已经交换好的后续节点，而递归调用负责处理链表的剩余部分。

递归Code

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 是否为空(head == null)或者只有一个节点(head.next == null)。如果是这种情况，直接返回head，因为没有足够的节点来进行交换。
        if(head == null || head.next == null) {
            return head;
        }
        // head是两两交换前的头，定义要变成新的头的节点newHead
        ListNode newHead = head.next;
        // 递归交换 传入剩余链表的老头，返回值是交换后的新头
        head.next = swapPairs(newHead.next);
        // 真正的逻辑是 newHead反向指到head，返回新头
        newHead.next = head;
        // 返回新头
        return newHead;


    }
}

第二次做递归

要画图和思考，怎么递归进行传递，就明白了。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode swapPairs(ListNode head) {
        // 递归不需要虚拟头，终止条件是为空或者只剩下一个节点
        if(head == null || head.next == null) {
            return head;
        }
        // 本层的逻辑想清楚，递归方法的调用肯定是一个节点.next = swapPairs(下一个头节点)
        // 1->2->3，head是1，newHead是2，newHead.next是3
        ListNode newHead = head.next;
        head.next = swapPairs(newHead.next);
        // 2反指回来到1
        newHead.next = head;
        // 返回的是newHead这个新头节点
        return newHead;
    }
}

/*
* Definition for singly-linked list.
* public class ListNode {
* int val;
* ListNode next;
* ListNode() {}
* ListNode(int val) { this.val = val; }
* ListNode(int val, ListNode next) { this.val = val; this.next = next; }
* }
/
class Solution {
public ListNode swapPairs(ListNode head) {
//定义虚拟头
ListNode dummyNode = new ListNode(0);
//虚拟头指向真正的头
dummyNode.next = head;
//当前的头
ListNode cur = dummyNode;
while(cur.next != null && cur.next.next != null){//初始cur肯定不是null，我后面需要两个交换，所以必须cur.next和cur.next.next都不是null
//定义暂存的变量 dummy->1->2->3->4，现在是dummy->2->1->3->4，所以需要存的是1的地址cur.next，和3的地址，因为dummy->2的时候丢失了1的地址，2->1的时候丢失了3的地址
ListNode temp1 = cur.next;//1的地址
ListNode temp2 = cur.next.next.next;//3的地址
//开始交换
cur.next = cur.next.next;//dummy指向2
cur.next.next = temp1;//2指向1
cur.next.next.next = temp2;//1指向3
//cur后移两个，相当于dummy->2->1->3->4中，1是现在的虚拟头
cur = cur.next.next;
}
return dummyNode.next;
}
}


# 自己做的递归法

class Solution {
    public ListNode swapPairs(ListNode head) {
        ListNode dummyHead = new ListNode(-1,head);
        dummyHead.next = swap(dummyHead.next);
        return dummyHead.next;
    }
    private ListNode swap(ListNode head) {
        // 终止条件是为空或者只剩下一个节点，我刚开始没想清楚
        if(head == null || head.next == null) {
            return head;
        }
        ListNode newHead = head.next;
        // nextHead是不是null无所谓
        ListNode nextHead = newHead.next;
        newHead.next = head;
        head.next = swap(nextHead);
        return newHead;
    }
}
