1. USING VARIABLES ONLY(Most Optimised):

Intuition

  1. We want to compute the nth Fibonacci number efficiently using recursion.
  2. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones.

Approach

  1. Base Cases:
    • If n is 0 or 1, return n.
    • These are the base cases for the Fibonacci sequence.
  2. Iterative Approach:
    • Initialize n1 as 0 and n2 as 1 (the first two Fibonacci numbers).
    • Initialize n3 as 0 (to store the result).
    • Iterate from i = 2 to n:
      • Compute n3 as the sum of n1 and n2.
      • Update n1 to be n2.
      • Update n2 to be n3.
    • Return n3 as the nth Fibonacci number.
  3. Example:
    • For n = 7:
      • Initialize n1 = 0, n2 = 1.
      • Compute n3 = n1 + n2 = 1.
      • Update n1 = 1, n2 = 1.
      • Compute n3 = n1 + n2 = 2.
      • Update n1 = 1, n2 = 2.
      • Compute n3 = n1 + n2 = 3.
      • Continue until n3 is the 7th Fibonacci number.

Complexity

  • Time complexity: O(n) (each Fibonacci number is computed once).
  • Space complexity: O(1) (constant space for storing variables).

Code

class Solution {
    public int fib(int n){
        if(n==0 || n==1) return n;
        int result = fib(n-1) + fib(n-2);
        return result;
    }
}

2. RECURSION:

Intuition

  1. We want to compute the nth Fibonacci number efficiently using recursion.
  2. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones.

Approach

  1. Base Cases:
    • If n is 0 or 1, return n.
    • These are the base cases for the recursion.
  2. Recursive Case:
    • Otherwise:
    • Compute fab(n-1) (the (n-1)th Fibonacci number) recursively.
    • Compute fab(n-2) (the (n-2)th Fibonacci number) recursively.
    • Add the results of the above two computations to get the nth Fibonacci number.
    • Return this result.
  3. Example:
    • For n = 7:
      • Compute fab(6) (the 6th Fibonacci number) recursively.
      • Compute fab(5) (the 5th Fibonacci number) recursively.
      • Compute fab(4) (the 4th Fibonacci number) recursively.
      • Compute fab(3) (the 3rd Fibonacci number) recursively.
      • Compute fab(2) (the 2nd Fibonacci number) recursively.
      • Base case: fab(2) returns 1.
      • Compute fab(1) (the 1st Fibonacci number) recursively.
      • Base case: fab(1) returns 1.
      • Add the results: fab(3) = fab(2) + fab(1) = 2.
      • Compute fab(4) recursively.
      • Add the results: fab(4) = fab(3) + fab(2) = 3.
      • Compute fab(5) recursively.
      • Add the results: fab(5) = fab(4) + fab(3) = 5.
      • Compute fab(6) recursively.
      • Add the results: fab(6) = fab(5) + fab(4) = 8.
      • Return fab(6) as the 7th Fibonacci number.

Complexity

  • Time complexity: O(2^n) Exponential (inefficient due to repeated computations)..
  • Space complexity: O(n) (due to the recursion stack).

class Solution {
    public int fib(int n){
        if(n==0 || n==1) return n;
        int result = fib(n-1) + fib(n-2);
        return result;
    }
}

3. MEMOIZATION(BOTTOM UP APPROACH):

Intuition

  1. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones.
  2. We want to compute the nth Fibonacci number efficiently using dynamic programming.

Approach

  1. Using Dynamic Programming (DP):
    • We’ll use an array dp to store the computed Fibonacci numbers.
    • Initialize dp with zeros.
    • If n is 0 or 1, return n (base cases).
    • Otherwise:
      • Check if dp[n] is already computed (non-zero).
      • If yes, return dp[n].
      • Otherwise, compute dp[n] as the sum of fib(n-1) and fib(n-2).
      • Store dp[n] in the array.
      • Return dp[n].
  2. 1-D Array for Memoization:
    • Since only n is changing in the recursion, we use a 1-D array (dp) to store the computed values.
    • The array size is n+1 because the Fibonacci sequence starts from 0.

Complexity

  • Time complexity: O(n) (each Fibonacci number is computed once).
  • Space complexity: O(n) (for the dp array).

Code

class Solution {
    public int fib(int n){
        int[] dp = new int[n+1]; //n+1 to avoid any out of bound case
        if(n==0 || n==1){
            return n;
        }
        if(dp[n]!=0){  //dp[n] if not 0 that means there is some value stored.
            return dp[n];  //so return the stored value to avoid extra calculation.
        }
        dp[n] = fib(n-1) + fib(n-2); //store the each unique computation so we can use it later calls
        //only n is changing --> use 1-D array
        return dp[n];
    }
}

4. TABULATION(BOTTOM UP APPROACH):

Intuition

  1. The Fibonacci sequence is a series of numbers where each number is the sum of the two preceding ones.
  2. We want to compute the nth Fibonacci number efficiently using dynamic programming.

Approach

  1. Creating a DP Array :
    • We create an array dp of size n+1 to store the computed Fibonacci numbers.
    • Initialize dp[0] and dp[1] with the base cases (0 and 1).
  2. Iterating Over the DP Array :
    • Starting from index 2 (since we already have dp[0] and dp[1]), iterate over the dp array.
    • For each index i :
      • Compute dp[i] as the sum of dp[i-1] and dp[i-2].
      • Store this value in the dp array.
  3. Example:
    • For n = 8:
      • dp[0] = 0, dp[1] = 1.
      • Compute dp[2] = dp[1] + dp[0] = 1.
      • Compute dp[3] = dp[2] + dp[1] = 2.
      • Continue until dp[8].

Complexity

  • Time complexity: O(n) (each Fibonacci number is computed once).
  • Space complexity: O(n) (for the dp array).

class Solution {
    public int fib(int n){
        int[] dp = new int[n+1];  //create a dp array

    //store the base case in dp array
        dp[0] = 0;
        dp[1] = 1;

    //iterate over the dp array and stores the values
        for(int i=2;i<=n;i++){  //i<=n --> lenght of n is n+1
            dp[i] = dp[i-1] + dp[i-2];  //continously storing in the next place with the help of previous data
        }
        return dp[n];
    }
}
