回答下这个疑惑，因为自己也有过这样的疑惑。

l1.next =mergeTwoLists(l1.next, l2); 无论执行多少次递归最后到这来了l1还是原来的l1没有变——即仍然是链表头。不理解这点主要是对递归过程不熟悉。

这个语句的本质是确保把l1->next指向下一个较小的节点，他可能是l1.next也可能是l2，执行到这里并没有立刻返回一个值，也就是l1-next还是原值没有变，此时程序进入第二层函数mergeTwoLists(l1.next, l2)，然后再同样的过程进入第三层函数，依次类推，直到最深层的函数中触碰了基线条件，才开始返回，从最深层逐渐返回到最外层函数，至此递归完成。递归实现相当于是从链表的最后开始向前建立排序连接的。

注意这里l1.next已经作为参数传入递归函数中，意味着这里的l1->next在第二层函数空间中又以l1的名称继续进行同样的if判断，递归下去，就是链表不断向后比较但不返回值，一旦触碰基线条件（有其中一个指针为nullptr）才开始返回，回传，回传的过程就是将从最深层函数空间往最外层函数空间逐个把l1->next = 返回值（这和习惯思维是反向的，由于栈是后进先出的，返回一个值，代表一个函数出栈）。

不要用迭代的思维看递归，容易绕进去。递归就看成一层层函数空间就行。

class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        // 递归现编
        // 基线条件 传入的两个链表其中一个为空
        if(list1 == nullptr)
            return list2;
        else if(list2 == nullptr)
            return list1;
        // 下面是递归过程  递归只有触碰到了基线条件才会开始往返回
        else if(list1->val > list2->val){
            list2->next = mergeTwoLists(list1,list2->next);
            return list2;
        }
        else if(list1->val <= list2->val){
            list1->next = mergeTwoLists(list1->next,list2);
            return list1;
        }
        return nullptr;

    }
};
