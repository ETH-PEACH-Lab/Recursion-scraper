迭代+递归两种方式，四种解法

1.迭代

方法一：局部链表反转

  • 定义当前节点curr : ListNode curr = head
  • 定义前置节点pre，反转时，当前节点的next指向前置节点，即curr.next = pre
  • 定义后置节点post，用于标记下一个要反转的节点，注意：反转前，要先标记post。
    原因是：反转后，curr与后面的节点就断开了，没法继续后续操作了，因此需要提前标记post，反转后，再将curr引用指向该后置节点：curr = post
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode pre = null;
        ListNode curr = head;
        while (curr != null) {
            // 反转前，先标记下一个节点，反转结束后，将curr要指向下一个节点，进行后续反转
            ListNode post = curr.next;
            curr.next = pre;
            pre = curr;
            curr = post; 
        }
        return pre;
    }
}

方法二：局部链表反转，用head.next来指向下一个要反转的节点

与上面方法一的思路相同，只是用head.next来指向下一个要操作反转的节点

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
public ListNode reverseList(ListNode head) {
    if (head == null) {
        return null;
    }
    ListNode curr = head;
    ListNode post = curr.next;
    while (post != null) {
        // 标记下一个要反转的节点
        ListNode temp = post.next;
        post.next = curr;
        // 用head.next来指向下一个要反转的节点
        head.next = temp;
        curr = post;
        post = temp;
    }
    return curr;
}

2. 递归

方法一：将上面的迭代转递归

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    ListNode pre = null;
    public ListNode reverseList(ListNode head) {
        if (head == null) {
            return pre;
        }
        ListNode post = head.next;
        head.next = pre;
        pre = head;
        head = post;
        return reverseList(head);
    }
}

方法二：从后往前递归反转

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) {
            return head;
        }
        ListNode curr = reverseList(head.next);
        ListNode post = head.next;
        post.next = head;
        head.next = null;
        return curr;
    }
}
