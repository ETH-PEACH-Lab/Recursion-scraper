Approach:

This solution implements a recursive approach to remove nodes from a singly-linked list. Each node is removed if its value is less than the value of the next node. The recursion continues until the end of the list is reached. If the value of the current node is less than the value of the next node, the current node is removed by returning the next node. Otherwise, the current node is kept, and the recursion continues with the next node.

Explanation:

1. removeNodes Function:

  • This function takes the head of a singly-linked list as input and returns the head of the modified list after removing nodes with values less than their successors.
  • The base case of the recursion is when the head is null, in which case, it returns null.
  • The function recursively calls itself on the next node (head.next) to remove nodes from the remaining list.
  • After the recursion, it checks if the current node (head) should be removed based on the condition head.val < head.next.val.
  • If the condition is true, it returns the next node (head.next) to remove the current node.
  • Otherwise, it returns the current node (head) to keep it in the list.

Time Complexity:

  • The time complexity of this solution is O(n), where n is the number of nodes in the linked list. This is because the function traverses each node of the linked list exactly once.

Space Complexity:

  • The space complexity is O(n), where n is the number of nodes in the linked list. This is due to the recursive function calls, which consume space on the call stack proportional to the number of nodes in the list.

Java Code:

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode removeNodes(ListNode head) {
        if (head == null) return null;
        head.next = removeNodes(head.next);
        return head.next != null && head.val < head.next.val ? head.next : head;
    }
}
