LeetCode Problem: Different Ways to Add Parentheses

Problem Statement

Given a string expression of numbers and operators, return all possible results from computing all the different possible ways to group numbers and operators. You may return the answer in any order.

Intuition and Approach

The key to solving this problem is breaking down the string into smaller parts recursively by splitting at every operator (+, -, *). For each operator, we evaluate all possible values from the left and right substrings, and then combine them based on the operator.

This is essentially a divide-and-conquer problem, where at each step we break the expression into smaller sub-expressions, compute the results for both parts, and then combine the results based on the operator between them.

We also make use of memoization to store results for sub-expressions we've already computed, which helps avoid redundant calculations and speeds up the solution.

Algorithm

  1. Base Case: If the expression consists only of a single number, we return that number as the only result.

  2. Recursive Step: For each character in the string, if it's an operator, we:
    - Split the expression into two parts: left and right.
    - Recursively calculate all possible values for the left and right parts.
    - Combine the results from the left and right parts using the current operator.

  3. Memoization: We store the results of each sub-expression in a map, so that if the same sub-expression is encountered again, we can retrieve the result in constant time instead of recalculating it.

Complexity Analysis

Time Complexity:

Each operator in the string creates two recursive calls, leading to a tree-like structure with potential exponential growth. In the worst case, this results in a time complexity of O(n * 2^n), where n is the number of characters in the string.

  • For each operator, we split the expression into left and right sub-expressions.
  • Memoization helps by avoiding redundant calculations, but in the worst case, the time complexity still remains exponential.

Space Complexity:

The space complexity is dominated by the recursion depth and the memoization storage.

  • The depth of recursion is O(n), where n is the length of the expression.
  • We store results for all possible sub-expressions in the memoization map, which leads to a space complexity of O(n * 2^n), as there can be that many unique sub-expressions.

vector ways(const string& s, unordered_map>& mem) {
// Check if the result for the current string is already memoized
if (mem.find(s) != mem.end())
return mem[s];

    vector<int> ans;

    // Iterate through each character in the string
    for (int i = 0; i < s.length(); ++i) {
        // If the character is an operator
        if (ispunct(s[i])) {
            // Recursively compute results for left and right parts
            vector<int> left = ways(s.substr(0, i), mem);
            vector<int> right = ways(s.substr(i + 1), mem);

            // Combine results from left and right based on the operator
            for (const int a : left) {
                for (const int b : right) {
                    if (s[i] == '+')
                        ans.push_back(a + b);
                    else if (s[i] == '-')
                        ans.push_back(a - b);
                    else if (s[i] == '*')
                        ans.push_back(a * b);
                }
            }
        }
    }

    // If there are no operators, it means the current string is a number
    if (ans.empty())
        ans.push_back(stoi(s));

    // Memoize the result for the current string
    mem[s] = ans;
    return ans;
}
