# 正则化匹配
👤 xdeng7 👍 0 2020-08-21 🖼 ↗ 查看原 Solution

动态规划

与通配符匹配问题类似，该问题也可用动态规划解决，但是在‘ * ’匹配上有所区别。‘ * ’可以copy前一个字符任意次包括0次，但不能匹配空字符。则在处理‘ * ’匹配上我们要选择copy前一个字符或者不copy前一个字符。选择条件为，‘ * ’前的字母字符是否在匹配过程中是多余的。例如，位于在‘ * ’前的字母字符前的字符段已经完全匹配，那么当前‘ * ’选择不匹配前一个字符并将前一个字符置零。如果选择匹配，即‘ * ’前一个字符在p与s中相同，我们可以选择复制前一个字符，但是同时，我们也要查看‘ * ’与位于当前s的字符之前的字符段是否都匹配成功，若不成功，则当前问题的子问题不成立，则当前问题不成立。我们同样建立二维动态规划表来记录匹配过程。

Base Cases
• 空字符与空字符匹配成功，dp[0][0]=true.
• 空字符与任何字符匹配都不成功。
• 当‘ * ’与空字符匹配，若‘ * ’前有一个字符，‘ * ’可以使前一个字符置空，则匹配成功。
'*'匹配情况：
• 当选择忽略‘ * ’前字母字符时，两个字符段匹配成功，即p[:j-2]==s[:i-1]=>dp[i][j]=dp[i][j-2]=true.
• 当p中‘ * ’前的字母字符与s当前字母字符相同或为‘ . ‘，可以选择copy前一个字母字符，但前提条件为' * '前的子问题为true，即dp[i-1][j]=true.
Noth that:
详细解释一下第二种情况。第二种情况的前提条件为dp[i-1][j]=true&&p[j-1]==‘ * ’;dp[i-1][j]=>s[:i-1]==p[:j-1]；首先，如果上述式子成立，则说明p中‘ * ’前的字符段已经与s匹配上了，即子问题为true。如若没匹配上，不管当前选择copy还是不copy，当前问题都不可能为真。

class Solution
{
public:
    bool isMatch(string s, string p)
    {
        int s_size=s.length();
        int p_size=p.length();
        vector<vector<bool>> dp(s_size+1,vector<bool>(p_size+1));
        dp[0][0]=true;
        for(int j=1;j<=p_size;++j)
            if(p[j-1]=='*')
                dp[0][j]=dp[0][j-2];
        for(int i=1;i<=s_size;++i)
            for(int j=1;j<=p_size;++j)
                if(p[j-1]==s[i-1]||p[j-1]=='.')
                    dp[i][j]=dp[i-1][j-1];
                else if(p[j-1]=='*')
                    dp[i][j]=dp[i][j-2]||((s[i-1]==p[j-2]||p[j-2]=='.')&&dp[i-1][j]);
        return dp[s_size][p_size];
    }
};

递归

该问题也可用递归来解，递归可以被更好的理解，但是效率却不高，我们不详细的讨论，只是简单的分析一下。递归中我们只关注当前问题，后续问题交给递归处理，递归会把后续问题的解返回给当前问题。那么首先我们匹配s与p中当前字符,s[i]和p[j],是否成功，成功我们将后续字符段交给递归处理。下面分析一下当出现‘*’的情况。

若两个字符为字母字符，匹配不成功，则继续通过匹配的可能只有当p中当前字符p[j]后续字符为‘ * ’,p[j+1]=='',可以使p中当前字符置空，否则没有匹配成功的可能。
若p中当前字符成功置空，那么s当前字符,s[i],就得继续与p的‘’后一个字符相比较,s[i]==p[j+2]。
最后，若当前两个字符比较成功且p[j+1]=='*',则要检查s[i]的后续字符与当前p[j]的字符是否匹配,s[i+1]==p[j]，‘ * ’可以copy当前p中的字符,否则false。
根据上述内容代码为：

if((j<=p.length()-2)&&p[j+1]=='*')
{
    ans=first&&dp(i+1,j,s,p)||dp(i,j+2,s,p);
}
else
{
    ans=first&&dp(i+1,j+1,s,p);
}

而停止递归的base case为p的指针j已经到达尾部，若s的指针同样到达尾部，则返回true；不然，返回false。if(j==p.length()) return i==s.length();

class Solution
{
public:
    unordered_map<int, bool> dict;
    bool dp(int i,int j,string &p,string &s)
    {
        int key = i * 100 + j;
        bool ans = false;
        if (dict.find(key) != dict.end())
        {
            return dict[key];
        }
        if (j == p.length()) return i == s.length();
        bool first =(i <= s.length()) && (p[j] == s[i] || p[j] == '.');
        if (j <= p.length() - 2 && p[j+1] == '*')
            ans = (first && dp(i + 1, j,p,s) )||dp(i,j+2,p,s);
        else
            ans = first && dp(i + 1, j + 1,p,s);
        dict[i*100+j] = ans;
        return ans;
    }
    bool isMatch(string s, string p)
    {
        if(p.empty())
            return s.empty();
        return dp(0, 0, p, s);
    }
};
