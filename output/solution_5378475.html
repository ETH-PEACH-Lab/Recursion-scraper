Intuition

As usual the proof of the speed:

The idea is to read and confront 2 node per time and store in the new list the lower node. When we reach the end of at least one of the 2 list we add the remaining nodes of the other list to the list we gave in output.

Approach

To start we have to first skip some specific cases like:
1. both list are void
2. just the first is epty
3. just the second is empty
To do that we start controlling these possible scenarios:

if(list1==NULL && list2==NULL){
        return NULL;
    }

And then:

 or

In case 2 or 3 we just have to copy the not empty linked list with all of his elements inside the list of output. To cpoy that we use a pointer (tmp) that will copy all the element of the linked-list into the new one:

        struct ListNode* list3=(struct ListNode*)malloc(sizeof(struct ListNode));
    list3->next=NULL;
        list3->next=NULL;
        list3->val=list1->val;
        struct ListNode* tmp3=list3;
        struct ListNode* tmp1=list1->next;
        while(tmp1!=NULL){
            tmp3->next=create(tmp1->val);
            tmp3=tmp3->next;
            tmp1=tmp1->next;
        }
        return list3;

The last case is when 2 list are not empty.To do as we said in "intuition" we need to create a list with a pointer to the list that we'll use to add new nodes:

    struct ListNode* list3=(struct ListNode*)malloc(sizeof(struct ListNode));
    list3->next=NULL;

Then we reuse the while cycle of before with the control that decide what element enters:

if(tmp1->val<tmp2->val){

In the ned we control if any element was left to add and we retunr our linked-list.
To add nodes I used a function named create:

struct ListNode* create(int val){
    struct ListNode* node=(struct ListNode*)malloc(sizeof(struct ListNode)); 
    node->next=NULL;
    node->val=val;
    return node;
}

The function returns the address of the new node to connect it to the list.

Complexity

  • Time complexity: O(n+m)
  • Space complexity: O(n+m)
