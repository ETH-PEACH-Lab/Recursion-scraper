Intuition

2 different kinds of solutions.
1 is recursion, done several months ago & slow.
Could you do it in O(n) time and O(1) space?
Other use Floyd's tortoise and hare algorithm to find the middle node pointed by slow, then reverse slow as backward and compare head & backward.

Approach

Let's focus on the method using Floyd's tortoise and hare algorithm.
1. Set 2 pointers slow & fast with strides 1 & 2. Tranverse til fast reaching the end.
2. If fast!=NULL which means the length of the linked list is odd,move slow 1 more step

3. Use the same function reverseList (in Leetcode 206. Reverse Linked List) to reverse slow as backward
4. Transverse & compare both of head & backward tilbackward reaches the end.

Complexity

  • Time complexity:

O(n)
- Space complexity:

O(1)

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
#pragma GCC optimize("O3", "unroll-loops")
class Solution {
public:
    ListNode* reverseList(ListNode* node) {
        if (node==NULL || node->next==NULL) return node;
        ListNode* cur=node, *Next, *prev=NULL;
        while(cur!=NULL){
            Next=cur->next;
            cur->next=prev;
            prev=cur;
            cur=Next;
        }
        return prev;
    }
    bool isPalindrome(ListNode* head) {
        if (!head->next) return 1;
        ListNode* fast=head, *slow=head;
        while(fast && fast->next){
            slow=slow->next;
            fast=fast->next->next;
        }
        if (fast)// odd length, move slow 1 more step;
            slow=slow->next;
        ListNode* backward=reverseList(slow);

        for(ListNode* cur=backward, *forward=head; cur;
        cur=cur->next, forward=forward->next){
            if (cur->val!=forward->val) return 0;
        }
        return 1; 
    }
};

The recursive solution is tricky which uses system stack. By successive recursive calling the function check(Node->next), in fact the Node behaves like a backward transverse as the parameter in check(ListNode* Node).

Just see the process by uncommenting the output for pairs (Node->val, front->val) in the testcase head=[1,2,3,5,6,3,2,1] as follows

class Solution {
public:
    ListNode* front;
    bool check(ListNode* Node){
        if (Node!=NULL) {
            if (!check(Node->next)) return 0;
        //    cout<<"("<<Node->val<<","<<front->val<<")";
            if (Node->val!=front->val) return 0;
            front=front->next;
        }
        return 1;
    }
    bool isPalindrome(ListNode* head) {
        front=head;
        return check(head);
    }
};
