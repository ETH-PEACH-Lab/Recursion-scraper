Approach 1: Iteration

Intuition :

The idea is to keep dividing the number by 4, i.e, do n = n/4 iteratively. In any iteration, if n%4 becomes non-zero and n is not 1 then n is not a power of 4, otherwise n is a power of 4.

Algorithm :

  1. If n is less than or equal to 0, return false.
  2. Otherwise, loop until n becomes 1 or n%4 becomes non-zero. In the loop, do n = n/4.
  3. After the loop, return true if n is 1, otherwise return false.

Complexity Analysis

  • Time complexity : O(log4n). In each iteration, we reduce the number by 4 times until it either becomes 1 or a number not divisible by 4.
  • Space complexity : O(1). We are not using any extra memory.

Code:

``` Python []
class Solution:
def isPowerOfFour(self, n: int) -> bool:
if n <= 0:
return False
while n > 1:
if n % 4 != 0:
return False
n //= 4
return True

``` C++ []

public:
    bool isPowerOfFour(int n) {

            return false;
        }
        while (n > 1) {
            if (n % 4 != 0) {
                return false;
            }
            n /= 4;
        }
        return true;
    }
};

# Intuition :
Return true if n is a power of four. That is, return true if n is a power of 2 and its exponent is even. The second part of the condition can be checked by ensuring that n is not divisible by 3. If n is a power of 4, it is definitely a power of 2 since 4 is a power of 2. If n is a power of 2 but not a power of 4, its exponent must be odd. That is, if n is a power of 2, n%3 should be 1. Return true if n>0 and n is a power of 2 and n%3 is 1.

# Algorithm :
1. If n is less than or equal to 0, return false.
2. Otherwise, check if n is a power of 2 by checking if n&(n-1) is 0. If not, return false.
3. Finally, return true if n%3 is 1, otherwise return false.

# Complexity Analysis
- Time complexity : ***O(1)***. We are only doing one operation.
- Space complexity : ***O(1)***. We are not using any extra memory.

# Approach 4: Math
![Screenshot 2023-10-23 at 7.47.44 AM.png](https://assets.leetcode.com/users/images/d4a79f40-d13f-4252-b173-610a319ac132_1698028966.923919.png)


# Intuition :
If n is a power of 4, it can be expressed as 4^a where a is an integer. If a is even, 4^a will be a power of 2. Otherwise, 4^a will not be a power of 2. We can use this fact to determine if n is a power of 4. First, we check that n is a power of 2. Then we check that the exponent a is even. Since a is an integer, a will be even only if a%2 is 0. In the case when n is a power of 2, a is n/2. Therefore, we check if n/2 is even or not. If n/2 is even, we return true. Otherwise, we return false.

# Algorithm :
1. If n is less than or equal to 0, return false.
2. Otherwise, check if n is a power of 2 by checking if n&(n-1) is 0. If not, return false.
3. Finally, return true if n/2 is even, otherwise return false.

# Complexity Analysis
- Time complexity : ***O(1)***. We are only doing one operation.
- Space complexity : ***O(1)***. We are not using any extra memory.



# Code:

Approach 5: Recursive

Intuition :

The idea is to keep dividing the number by 4, i.e, do n = n/4 iteratively. In any iteration, if n%4 becomes non-zero and n is not 1 then n is not a power of 4, otherwise n is a power of 4.

Algorithm :

  1. If n is less than or equal to 0, return false.
  2. Otherwise, loop until n becomes 1 or n%4 becomes non-zero. In the loop, do n = n/4.
  3. After the loop, return true if n is 1, otherwise return false.

Complexity Analysis

  • Time complexity : O(log4n). In each iteration, we reduce the number by 4 times until it either becomes 1 or a number not divisible by 4.
  • Space complexity : O(1). We are not using any extra memory.

Code:

``` Python []
class Solution:
def isPowerOfFour(self, n: int) -> bool:
if n <= 0:
return False
if n == 1:
return True
return n % 4 == 0 and self.isPowerOfFour(n // 4)

``` C++ []
class Solution {
public:
    bool isPowerOfFour(int n) {
        if (n <= 0) {
            return false;

        if (n == 1) {

# Approach 6: Using Lookup Table

![Screenshot 2023-10-23 at 7.51.47 AM.png](https://assets.leetcode.com/users/images/4150d468-99d5-439b-bee2-9c24eb8470f3_1698029071.8372757.png)


# Intuition :
We can use a lookup table to check if n is a power of 4. The lookup table will contain all the powers of 4 that can be represented by a 32-bit signed integer. We can create the lookup table by calculating the powers of 4 until the maximum value of a 32-bit signed integer is reached. We can then check if n is present in the lookup table.

# Algorithm :
1. Create a lookup table that contains all the powers of 4 that can be represented by a 32-bit signed integer.
2. Check if n is present in the lookup table.

# Complexity Analysis
- Time complexity : ***O(1)***. We are only doing one operation.
- Space complexity : ***O(1)***. We are not using any extra memory.


# Code:
