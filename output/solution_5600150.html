The numberToWords Method

    public static String numberToWords(int num) {
        if (num == 0) {
            return "Zero";
        }

        for (Map.Entry<Integer, String> entry : mp.entrySet()) {
            if (num >= entry.getKey()) {
                String start = "";
                String placeValue = entry.getValue();
                String end = "";

                if (num >= 100) {
                    start = numberToWords(num / entry.getKey()) + " ";
                }             

                if (num % entry.getKey() != 0) {
                    end = " " + numberToWords(num % entry.getKey());
                }
                return start + placeValue + end;
            }
        }
        return "";
    }
  • The method numberToWords takes an integer num as input and returns its word representation as a String.
  • If num is 0, the method immediately returns "Zero".
  • The method then iterates over each entry in the map.
  • For each entry, it checks if num is greater than or equal to the key (number).
  • If num is greater than or equal to the key, it initializes an empty string a.
  • If num is greater than or equal to 100, it recursively calls numberToWords with num divided by the key, appends a space, and assigns the result to a.
  • It then gets the word representation of the key (value of the map entry) and assigns it to b.
  • It initializes an empty string c.
  • If num modulo the key is not zero, it recursively calls numberToWords with num modulo the key, appends a space, and assigns the result to c.
  • The method then returns the concatenation of a, b, and c.

Summary

  • The code defines a class NumberToWords with a method numberToWords that converts a number to its word representation.
  • A LinkedHashMap is used to store the mappings of numbers to words, maintaining the order of insertion.
  • The numberToWords method uses recursion to build the word representation for numbers larger than the keys in the map.
  • The main method shows an example usage of the numberToWords method.
