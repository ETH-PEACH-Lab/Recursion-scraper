Easiest Approach || Optimal || O(max(N, M)), No extra space (Fully Explained) || Beats 100%

Intution

You are given two non-empty linked lists representing two non-negative integers. The digits are stored in reverse order, and each of their nodes contains a single digit. Add the two numbers and return the sum as a linked list.

You may assume the two numbers do not contain any leading zero, except the number 0 itself.

Example:

Input: (2 -> 4 -> 3) + (5 -> 6 -> 4)
Output: 7 -> 0 -> 8
Explanation: 342 + 465 = 807.

Approach

The problem can be solved by traversing both linked lists simultaneously and adding the corresponding digits along with any carry. We can create a new linked list to store the result and update it as we iterate through the input lists.

  1. Create a helper function insertAtTail to insert a node at the tail of a linked list. This function takes a reference to the head and tail pointers, along with the value to be inserted.
  2. Initialize the head and tail pointers of the result linked list as NULL.
  3. Initialize a variable carry to store the carry value, initially set to 0.
  4. Iterate through the input lists l1 and l2 until both lists reach the end.
    1. Calculate the sum of the current digits from l1 and l2 along with the carry. Take the modulus of the sum by 10 to get the current digit value to be inserted into the result list.
    2. Insert the current digit at the tail of the result list using the insertAtTail function.
    3. Update the carry by dividing the sum plus the previous carry by 10.
    4. Move the pointers l1 and l2 to their next nodes.
  5. After the above loop, if there are any remaining nodes in either l1 or l2, iterate through them and perform the same steps as above, considering the carry.
  6. If there is still a non-zero carry remaining, insert it at the tail of the result list.
  7. Return the head of the result list.

The solution uses the helper function insertAtTail to simplify the code for inserting nodes at the tail of the result list. It also takes advantage of the modulus operator to extract the current digit and handle carry operations.

Complexity

  • Time complexity: O(max(N, M))
    M => Size of List 1, N => Size of List 2
  • Space complexity: O(max(N, M))

Code

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
void insertAtTail(ListNode* &head, ListNode* &tail, int data){
    if(tail == NULL){
        ListNode* temp = new ListNode(data);
        tail = temp;
        head = temp;
    }
    else{
        ListNode* temp = new ListNode(data);
        tail->next = temp;
        tail = temp;
    }
}

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        std::ios::sync_with_stdio(0);
        std::cin.tie(0);
        ListNode* head = NULL;
        ListNode* tail = NULL;
        int carry = 0;
        while(l1 && l2){
            int sum = (l1->val + l2->val) % 10;
            insertAtTail(head, tail, (sum+carry)%10);
            carry = ((sum+carry)/10 + (l1->val + l2->val)) / 10;
            l1 = l1->next;
            l2 = l2->next;
        }
        while(l1){
            int sum = (l1->val) % 10;
            insertAtTail(head, tail, (sum+carry)%10);
            carry = ((sum+carry)/10 + (l1->val)) / 10;
            l1 = l1->next;
        }
        while(l2){
            int sum = (l2->val) % 10;
            insertAtTail(head, tail, (sum+carry)%10);
            carry = ((sum+carry)/10 + (l2->val)) / 10;
            l2 = l2->next;
        }
        if(carry) insertAtTail(head, tail, carry);
        return head;
    }
};
