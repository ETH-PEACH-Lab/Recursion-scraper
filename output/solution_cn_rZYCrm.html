解析树 + 递归，思路清晰
👤 yi-ge-liang-ge-si-ge-san-ge 👍 0 2022-11-05 🖼 ↗ 查看原 Solution

思路：解析树 + 递归，一步一步来。

  • 第一步，解析树：

    1. 初始化根节点
    2. 遇到运算符，则将运算符作为当前节点的值
    3. 遇到左括号，则创建一个子节点，并跳到子节点
    4. 遇到布尔值，则将该布尔值作为当前节点的值
    5. 遇到逗号，则回到父节点，并创建一个子节点，并跳到子节点
    6. 遇到右括号，则返回父节点。

  • 第二步，通过递归搜索，计算结果：

    1. 如果是叶子节点，则是递归的退出条件，将叶子节点的值返回；
    2. 如果是双亲节点，广度搜索。
    3. 这里有一点细节处理要注意：如果是!运算符，直接替换为not对结果取反；如果是&|运算符，使用join+eval函数
class Node:
    def __init__(self, val=None):
        self.val = val
        self.pre = None
        self.child = []


class Solution:
    def __init__(self):
        self.root = Node()
        self.is_sign = "|&!"
        self.is_bool = "tf"

    def parseBoolExpr(self, expression: str) -> bool:
        self.parse_tree(expression)
        return eval(self.travel_tree(self.root))

    def parse_tree(self, expression: str):
        cur_node = self.root
        for s in expression:
            if s in self.is_sign:
                cur_node.val = s
            elif s == "(":
                new_node = Node()
                cur_node.child.append(new_node)
                new_node.pre = cur_node
                cur_node = new_node
            elif s in self.is_bool:
                if s == "t":
                    cur_node.val = "True"
                else:
                    cur_node.val = "False"
            elif s == ",":
                cur_node = cur_node.pre
                new_node = Node()
                cur_node.child.append(new_node)
                new_node.pre = cur_node
                cur_node = new_node
            elif s == ")":
                cur_node = cur_node.pre

    def travel_tree(self, node: Node):
        # 如果当前节点的值是布尔值，返回
        # 如果不是，递归搜索
        if not node.child:
            return node.val
        else:
            child_node_list = node.child
            if len(child_node_list) == 1 and node.val == "!":
                ret = str(not eval(self.travel_tree(child_node_list[0])))
            else:
                ret = str(eval(f"{node.val}".join([self.travel_tree(child_node) for child_node in child_node_list])))
        return ret
