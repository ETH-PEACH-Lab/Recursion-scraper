swap with additional function, remember before and after nodes, break when kth node none

Pseudo Code

  1. Create a dummy node and point its next to the head of the list.
  2. Initialize a pointer nodeBeforeGroup to the dummy node.
  3. Start a loop that continues as long as there are k nodes left in the list:
    1. Get the kth node from nodeBeforeGroup using the helper function getKth.
    2. If the kth node is None, break the loop because there are less than k nodes left in the list.
    3. Save the node after the kth node and the first node in the group.
    4. Reverse the nodes in the group.
    5. Update the next pointer of nodeBeforeGroup to point to the kth node (which is now the first node in the group after the reversal).
    6. Update the next pointer of the first node in the group (which is now the last node in the group after the reversal) to point to the node after the kth node.
    7. Move the nodeBeforeGroup pointer to the first node in the group (which is now the last node in the group after the reversal).
  4. Return the next node of the dummy node, which is the new head of the list.

Complexity

  • Time complexity: O(n), where n is the number of nodes in the list. This is because we process each node once.

  • Space complexity: O(1), because we only use a constant amount of space to store our variables.

Code

class Solution:
    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        # Create a dummy node and point its next to the head of the list
        dummyNode = ListNode(0, head)
        nodeBeforeGroup = dummyNode

        while True:
            # Get the `k`th node from `nodeBeforeGroup`
            kthNode = self.getKth(k, nodeBeforeGroup)
            if not kthNode:
                break

            # Save the node after the `k`th node and the first node in the group
            nodeAfterGroup = kthNode.next
            firstNodeInGroup = nodeBeforeGroup.next

            # Reverse the nodes in the group
            prevNode, currNode = nodeAfterGroup, nodeBeforeGroup.next
            while currNode != nodeAfterGroup:
                nextNode = currNode.next
                currNode.next = prevNode
                prevNode = currNode
                currNode = nextNode
            print(f"Nodes after reversing the group: {prevNode.val} -> {currNode.val if currNode else None}")

            # Update the next pointer of `nodeBeforeGroup` to point to the `k`th node
            nodeBeforeGroup.next = kthNode
            print(f"Node before group after updating its next pointer: {nodeBeforeGroup.val} -> {nodeBeforeGroup.next.val}")

            # Update the next pointer of the first node in the group to point to the node after the `k`th node
            firstNodeInGroup.next = nodeAfterGroup
            print(f"First node in the group after updating its next pointer: {firstNodeInGroup.val} -> {firstNodeInGroup.next.val if firstNodeInGroup.next else None}")

            # Move the `nodeBeforeGroup` pointer to the first node in the group
            nodeBeforeGroup = firstNodeInGroup
            print(f"Node before group after moving to the next position: {nodeBeforeGroup.val}")

        # Return the next node of the dummy node, which is the new head of the list
        return dummyNode.next

    def getKth(self, k, prevNode):
        while prevNode and k > 0:
            prevNode = prevNode.next
            k -= 1
        return prevNode

Dry Run Structure:

  1. Initialization:
    - Create a dummy node (dummy) with dummy.next pointing to the head of the original linked list.
    - Set node_before_group to point to the dummy node.
    - Print the initial state of the linked list (optional).
  2. Iterate through the linked list:
    - Get the kth node: Call the getKth function to find the kth node from the current group's beginning.
    - Check for end of group/linked list: If kth is None, there are fewer than k nodes remaining, so end the loop.
    - Get the node after the group: Store the node after the current group in node_after_group.
    - Reverse the current group:
    • Initialize prev and curr pointers to node_after_group and node_before_group.next, respectively.
    • Iterate while curr isn't node_after_group:
    • Store the next node in temp.
    • Reverse the link: Set curr.next to prev.
    • Update prev and curr.
    • Connect the reversed group:
    • Connect the previous group's tail to the new group's head (node_before_group.next = kth).
    • Update node_before_group to become the tail of the reversed group.
    • Print the state of the linked list after this iteration (optional).
  3. Return the modified list: Return dummy.next, which is now the head of the reversed groups.

Example (assuming k = 2 and initial linked list 1 -> 2 -> 3 -> 4):

  1. Initialization:
    - dummy points to a node with val = 0 and next pointing to head (1).
    - node_before_group points to dummy.
    - Initial linked list: 0 -> 1 -> 2 -> 3 -> 4 (dummy added)

  2. Iteration 1:
    - getKth returns 3 (the 2nd node) as there are 2 nodes in the first group.
    - node_after_group points to 4.
    - Reversing the group:

    • prev points to 4, curr points to 1.
    • curr.next (originally 2) is reversed to point to prev (previously 4). Now 1 -> 4.
    • prev becomes 1, curr becomes 2.
    • curr.next (originally 3) is reversed to point to prev (previously 1). Now 2 -> 1.
    • prev becomes 2, curr becomes 3. Since curr is now node_after_group, the loop ends.
    • Connecting the group:
    • node_before_group.next (dummy) is connected to 3 (the new head of the reversed group).
    • node_before_group (dummy) becomes the tail of the reversed group.
    • Linked list after iteration 1: 0 -> 3 -> 2 -> 1 -> 4

  3. Iteration 2:
    - getKth returns None as there are fewer than k nodes remaining.
    - The loop ends as there are no more groups to reverse.

  4. Return: Return dummy.next, which is now 3, the head of the modified linked list: 3 -> 2 -> 1 -> 4
