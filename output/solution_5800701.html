Recursive Solution O(log n)
👤 arondsouza983 👍 0 2024-09-17 🖼 ↗ 查看原 Solution

Intuition and Approach

Breaking down pow function till n becomes zero:
For Example:
Example 1:
Input: x = 2.00000, n = 10
Output: 1024.00000

Lets take pow(2, 10)

So from above observation we see that,
1) 2^10 = 2^5 * 2^5 (n is equally dividing, when n is even)
2) 2^5 = 2^2 * 2^2 * 2 (n is not equally dividing, when n is odd)
3) 2^2 = 2^1 * 2^1
3) 2^1 = 2
4) 2^0 = 1 (This is our base case)

Psuedocode:
pow(x, n) {
    if n = 0:
        return 0
    // calculating half (as both the half would be equal other than odd)
    half = pow(x, n/2)

    if n % 2 = 0: // if n is even
        return half * half // as both halfs are equal
    else
        return half * half * x // multiplying extra x if odd
        // 2 ^ 5 = (half would be 2^2 so) half * half * 2 
}

This should work for all x and positive n

Now let's see for all x and negative n
Example 3:

Input: x = 2.00000, n = -2
Output: 0.25000
Explanation: 2-2 = 1/22 = 1/4 = 0.25

Let's take 2 ^ -2 = ((2)^-1)^2 = (1/2)^2
2 ^ -3 = ((2)^-1)^3 = (1/2)^3
x^-n = ((x)^-1)^n) = (1/x)^n
As we can see x is changed from x to 1/x and n is changed from -n to n

Pseudocode:
if n < 0: {
    x = 1/x
    n = -n  //n now would be positive
}
// call the same function that was created for positive n

Code

```java []
class Solution {
public double myPow(double x, int n) {
if (n == 0) {
return 1.0;
}

    if (n < 0) {
        x = 1 / x;
        n = -n;
    }

    return power(x, n);
}
private double power(double x, int n) {
    if (n == 0) {
        return 1.0;
    }
    double half = power(x, n / 2);
    if (n % 2 == 0) {
        return half * half;
    } else {
        return half * half * x;
    }
}

}
```

Complexity

  1. Depth of the recursion is log n in the worst case, As n is getting divided by 2 at each step
    - Time complexity: O(log n)
  1. Auxillary Stack Space will be log n in the worst case
    - Space complexity: O(log n)
