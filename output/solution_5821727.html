Recursive Approach

Intuition

The goal is to determine if a given integer n is a power of three. The recursive approach will check if n can be divided by three repeatedly until we reach 1.

Approach

  1. Base Case: If n is less than or equal to zero, it cannot be a power of three.
  2. Check for 1: If n equals 1, return true, since 3^0 = 1.
  3. Divisibility Check: If n is not divisible by three, return false.
  4. Recursive Call: If the previous checks pass, recursively call the function with n/3.

Complexity

  • Time complexity:
O(log_3 n)
  • Space complexity:
O(log_3 n)

Code

```java []
class Solution {
public boolean isPowerOfThree(int n) {
// Base case: if n is less than or equal to 0, it's not a power of three
if(n <= 0){
return false;
}
// If n is 1, it's a power of three (3^0 = 1)
else if(n == 1){
return true;
}
// If n is not a multiple of three, it can't be a power of three
else if(n % 3 != 0){
return false;
}
// Recursive case: check for n/3
return isPowerOfThree(n / 3);
}
}

# Iterative Approach
# Intuition
<!-- Describe your first thoughts on how to solve this problem. -->
To check if a number is a power of three, we can iteratively divide it by three. If it reduces to 1, then it is a power of three.

# Approach
<!-- Describe your approach to solving the problem. -->
1. Check Positive: First, verify if n is positive. If not, return false.
2. Iterative Division: While n is divisible by three, keep dividing it by three.
3. Final Check: If n equals 1 after the loop, return true; otherwise, return false.

# Complexity
- Time complexity:
<!-- Add your time complexity here, e.g. O(n) -->
    O(log_3 n)

- Space complexity:
<!-- Add your space complexity here, e.g. O(n) -->
    O(1)

# Code
```java []
class Solution {
    public boolean isPowerOfThree(int n) {
        // A power of three must be positive
        if (n <= 0) {
            return false;
        }
        // Keep dividing n by 3 until it's no longer divisible
        while (n % 3 == 0) {
            n /= 3;
        }
        // If n reduces to 1, it is a power of three
        return n == 1;
    }
}
