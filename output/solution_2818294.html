Approach : Recursion

Intuition

As the question it self mentions to find all the possible values of the given algebraic input, this gives us a hint to approach the question in a recursive manner as it generates all the possible ways that we can adjust parenthesis in between the string and thus generating all the possible values.

Interview tip: In a real interview, if you are unsure how to solve the problem, a good first step is to remain calm and reread the problem description looking for hidden clues. If you get a question to generate all possible outcomes then try to think recusively.

There are some critical constraints in the problem description:

  • 1 <= expression.length <= 20
  • expression consists of digits and the operator '+', '-', and '*'.
  • All the integer values in the input expression are in the range [0, 99].

Since the given input is string firstly we can generate a vector of string each storing either a operator ("+","-" or " * " ) or operand("12","2" etc). After generating this vector of string the parenthesis can be put up in between the indexes of the vector, so for that we can call a recursive function where we can pass paremeters like the starting index and ending index of the vector and in result it will return all the possible values corresponding to the algebraic string if the string is only between starting index and ending index.

What do we mean by putting a parenthesis at any index?
It just means that we put a closing parenthesis to the left of that index and opening parenthesis to the right of that index.

For generating all the possible value of string starting at index startInd and ending at index endInd, we need to iterate between each index from startInd and endInd and possible values will be combination of the possible values generated in the left side of iteratable index and right side of iterable index. The combination will be made based on the type of operand at that iterable index. Just one thing we need to keep in mind that parenthesis will be put at a iterable index only if that index corresponds to one of the operator i.e +,-,* . Otherwise go to next index.

As the base case we can consider if startInd and endInd both are same then the possible value generated is only that value corresponding to startInd.

Implementation

Complexity Analysis

Let N be the length of the expression
* Time complexity : O(2^(N/2))
If the length of input expression is N then the number of operators can be at max (N-1)/2. The parenthesis can be put at each of these (N-1)/2 places. Therefore at each of these places there is option either to put a parenthesis or not.

  • Space complexity : O(N)
    The string is separated into operators and operand and stored into expVec vector.
