原理呢？

少年，乘法器的原理懂不懂？
什么？不懂？那教不了(大误。
那换个问题：少年，手工算乘法怎么算？十进制那种，在纸上算那种，把乘数的每位拆开与被乘数相乘然后求和。
十进制能算，那么二进制能不能算呢？当然是可以的。

假如A=bx1101,B=bx1001，其实A展不展开无所谓。
怎么算呢？我们把A*B展开，这一步建议自己手工展开一下哟(>_<)。

对于左移位操作，我们知道在二进制中实际是提升阶，比如(bx1)<<2=bx100=4，右移对应降低阶(bx100)>>1=bx10=2，和10进制中乘10和除10的作用一样(1*10*1=1*10=10, 1*10^2=1*100=100)。
那么这里A*B实际计算如下：
A*B
\=
A*1*2^3+
A*0*2^2+
A*0*2^1+
A*1*2^0
\=
(A<<3)*1+
(A<<2)*0+
(A<<1)*0+
(A<<0)*1
=(A<<3)+(A<<0)
我们用左移代替乘法的升阶操作，那么就只剩下简单的*1和*0，把*1的部分累和起来就行了（二进制的世界真是太方便了XD），那么乘法自然神奇地消失了。图示如下：

阳间版本

我们想办法把这个过程用代码表达出来。以下是未精简的C代码。
```C []
int multiply(int A, int B){
if(B){//B非0才计算
//从0阶(A(B&1)2^0)开始，每次算当前阶(A(B&1)2^n)的乘法并累加起来,算到B为0为止。
if(B&1){//如果B的最后一位是1
//把B的阶放到A上去，递归算B的倒数第2位和A的乘法,然后求和+(1A=A)。
return multiply((long long)A<<1,B>>1)+A;
}else{
//把B的阶放到A上去，递归算B的倒数第2位和A的乘法,然后求和+(0A=0)。
return multiply((long long)A<<1,B>>1);
}
}
// B为0结果当然是0
return 0;
}

然后用三目运算符，再简化一下代码，就变成了一行AC的结果了。是不是非常简单？
时间应该是0ms，内存5.8m的样子（双百/双摆，好耶!），和直接写A*B几乎一模一样。

时空分析

在C/C++语言中，因为int有32位，所以最多递归32层，所以时间和空间复杂度都为O(log(n))=O(log(2^32))=O(32)，可以视作O(1)。
当然如果是其他语言，时间和空间复杂度都为O(log(n))，依据语言的不同结果有所不同，（其实最后的分析结果都是O(1)，这样写只是显得我很严谨，万一以后超级计算机的int定义突破32位了呢？XD）。
最好是用循环实现，只需要若干变量，空间复杂度就是O(1)，但时间复杂度还是O(log(n))。但如果用乘法的话时间和空间复杂度都为O(1)，虽然原理都一样，但据说CPU硬件和指令集上有奇怪的Buff加成（什么超标量啊，什么超流水啊，什么超线程啊，叫人半懂不懂的(+_?)，所以算O(1)（小声说：其实是硬件做了加速哦）。
