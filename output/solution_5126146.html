Intuition

To reorder a singly linked list, we need to divide it into two halves, reverse the second half, and then merge the two halves alternately.

Approach

  1. Find the middle of the linked list using the two-pointer technique (slow and fast pointers).
  2. Split the linked list into two halves at the middle node.
  3. Reverse the second half of the linked list.
  4. Merge the first half with the reversed second half by alternately connecting nodes.

Complexity

  • Time complexity:
  • Finding the middle of the linked list: O(n/2) => O(n)
  • Reversing the second half: O(n/2) => O(n)

  • Merging two lists: O(n)
    Overall, the time complexity is O(n).

  • Space complexity:

  • We only use a constant amount of extra space for pointers.
    Overall, the space complexity is O(1).

To reorder the linked list as described in the problem, you can follow these steps:

  1. Find the middle of the linked list.
  2. Reverse the second half of the linked list.
  3. Merge the first half with the reversed second half.

function reorderList(head):
    // Step 1: Find the middle of the linked list
    middle = findMiddle(head)

    // Step 2: Reverse the second half of the linked list
    secondHalf = reverseList(middle.next)
    middle.next = null // Split the list into two parts

    // Step 3: Merge the first half with the reversed second half
    mergeLists(head, secondHalf)

function findMiddle(head):
    slow = head
    fast = head

    while fast is not null and fast.next is not null:
        slow = slow.next
        fast = fast.next.next

    return slow

function reverseList(head):
    prev = null
    current = head

    while current is not null:
        nextNode = current.next
        current.next = prev
        prev = current
        current = nextNode

    return prev

function mergeLists(l1, l2):
    while l2 is not null:
        nextL1 = l1.next
        nextL2 = l2.next
        l1.next = l2
        l2.next = nextL1
        l1 = nextL1
        l2 = nextL2

Code

class Solution {
    public void reorderList(ListNode head) {
        if (head == null || head.next == null) {
            return; // No need to reorder if the list has 0 or 1 node
        }

        // Step 1: Find the middle of the linked list
        ListNode middle = findMiddle(head);

        // Step 2: Reverse the second half of the linked list
        ListNode secondHalf = reverseList(middle.next);
        middle.next = null; // Split the list into two parts

        // Step 3: Merge the first half with the reversed second half
        mergeLists(head, secondHalf);
    }

    private ListNode findMiddle(ListNode head) {
        ListNode slow = head;
        ListNode fast = head;

        while (fast != null && fast.next != null) {
            slow = slow.next;
            fast = fast.next.next;
        }

        return slow;
    }

    private ListNode reverseList(ListNode head) {
        ListNode prev = null;
        ListNode current = head;

        while (current != null) {
            ListNode nextNode = current.next;
            current.next = prev;
            prev = current;
            current = nextNode;
        }

        return prev;
    }

    private void mergeLists(ListNode l1, ListNode l2) {
        while (l2 != null) {
            ListNode nextL1 = l1.next;
            ListNode nextL2 = l2.next;
            l1.next = l2;
            l2.next = nextL1;
            l1 = nextL1;
            l2 = nextL2;
        }
    }
}
