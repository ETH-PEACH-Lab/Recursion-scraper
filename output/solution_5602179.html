Integer to English Words-daily problem -complete explanation
👤 itachiuchiha14 👍 0 2024-08-07 🖼 ↗ 查看原 Solution

Intuition

The problem involves converting an integer into its English words representation. The key challenge is to handle different scales (thousands, millions, billions) and the peculiarities of English number formatting, such as different words for numbers between 10 and 19, and how to handle zero.

Approach

  1. Helper Function (number):
    - Create a helper function to convert numbers less than 1000 to words.
    - Handle hundreds, tens, and units separately.
    - Use arrays of strings to store word equivalents of numbers for easy lookup.

  2. Main Function (numberToWords):
    - Handle edge case where the number is zero.
    - Divide the number by 1000 repeatedly to handle thousands, millions, and billions. For each division, convert the remainder using the helper function and append the appropriate scale word ("Thousand", "Million", "Billion").
    - Concatenate the results from the helper function and manage the final format, ensuring there are no extra spaces.

Complexity

  • Time Complexity:

  • The time complexity is mainly determined by the number of digits in the input number, which is \( O(\log_{10} n) \). Each digit or group of digits is processed a constant number of times.

  • Space Complexity:

  • The space complexity is \( O(1) \) because no additional space is required that scales with the input size, apart from the space used to store the result string.

Code

class Solution {
public:
    string number(int n) {
        string one[] = {"Zero", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine"};
        string two[] = {"Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"};
        string twos[] = {"", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"};
        string res = "";

        if (n > 99) {
            res += one[n / 100] + " Hundred ";
        }
        n %= 100;
        if (n > 9 && n < 20) {
            res += two[n - 10] + " ";
        } else {
            if (n >= 20) {
                res += twos[n / 10] + " ";
            }
            n %= 10;
            if (n > 0) {
                res += one[n] + " ";
            }
        }
        return res;
    }

    string numberToWords(int n) {
        if (n == 0) {
            return "Zero";
        }
        string b[] = {"Thousand", "Million", "Billion"};
        string r = number(n % 1000);
        n /= 1000;

        for (int i = 0; i < 3; i++) {
            if (n > 0 && n % 1000 > 0) {
                r = number(n % 1000) + b[i] + " " + r;
            }
            n /= 1000;
        }

        return r.empty() ? r : r.substr(0, r.size() - 1);
    }
};
