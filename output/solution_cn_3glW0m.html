最容易理解的思路：本质上是选或不选+完全背包
👤 Memory2002 👍 7 2025-07-24 🖼 ↗ 查看原 Solution

Problem: 10. 正则表达式匹配

[TOC]

思路

定义 $dfs(i, j)$ 为以$s_i$和$p_j$结尾的字符串能否匹配成功

首先对 $p_j$ 分类讨论：

  • $p_j$ 为小写字母，$dfs(i, j) = (s_i == p_j) \land dfs(i - 1, j - 1)$
  • $p_j$ 为'.'，$dfs(i, j) = dfs(i - 1, j - 1)$
  • $p_j$ 为'*'：

现在我们重点分析分析pj为'*'的情况，本质上可以采用选或不选的思路。

  • 如果$s_i
    eq p_{j-1}$且$p_{j-1}
    eq ext{'.'}$，则选不了，即$p_{j-1}*$匹配s中的0个字符，

dfs(i,j)=dfs(i, j - 2)

  • 如果$s_i=p_{j-1}$或$p_{j-1}= ext{'.'}$，则可以选也可以不选，不选就是上式，考虑选的情况：

选的情况本质上就是一个完全背包，虽然选的情况可以匹配s中的一个字符$s_i$,两个字符$s_{i-1}s_i$，三个字符...，但是我们只需要考虑匹配1个字符且$j$不变的这种情况即可，因为匹配多个字符就相当于完全背包中物品可以重复选，所以$j$是不移动的。匹配2个及2个以上字符的情况（状态）会在后面的递归中被遍历到。

选和不选只需要有一个为true，$dfs(i, j)$就为true。

因此，选的情况的状态转移方程为

dfs(i, j) = dfs(i - 1, j) \lor dfs(i, j - 2).

边条：

  • $dfs(-1, -1) = true$，全部匹配完返回true。
  • $dfs(-1, j\geq1) = dfs(-1, j - 2)$，和44. 通配符匹配一样，需要考虑字母或者 '.' 后跟 '*' 可以匹配空字符串的情况。
  • $dfs(i\geq0, -1) = false$。

将 DFS 改为递推

令 $f[i + 1][j + 1]$ 表示 $dfs(i, j)$,将状态转移方程中的 $i$ 换为 $i + 1$, $j$ 换为 $j + 1$。
边条：
- $f[0][0] = true$
- $f[i][0] = false, i >= 1$
- $f[0][j + 1] = f[0][j - 1], j >= 1$.

public boolean isMatch(String S, String P) {
char[] s = S.toCharArray(), p = P.toCharArray();
int n = s.length, m = p.length;
boolean[][] f = new boolean[n + 1][m + 1];
f[0][0] = true;
// 处理空字符串匹配 *
for (int j = 1; j < m; j++) {
if (p[j] == '') {
f[0][j + 1] = f[0][j - 1]; // * 可以匹配空字符串
}
}
for (int i = 0; i < n; i++) {
for (int j = 0; j < m; j++) {
char c = p[j];
if (Character.isLowerCase(c)) {
f[i + 1][j + 1] = s[i] == c && f[i][j];
} else if (c == '.') {
f[i + 1][j + 1] = f[i][j];
} else { // pj为，对p[j-1]分类讨论
// 不选
if (p[j - 1] != '.' && p[j - 1] != s[i]) {
f[i + 1][j + 1] = f[i + 1][j - 1];
} else {
// 可以选
f[i + 1][j + 1] = f[i + 1][j - 1] || f[i][j + 1];
}
}
}
}
return f[n][m];
}
}


 复杂度

- 时间复杂度: $O(mn)$
- 空间复杂度: $O(mn)$

class Solution {
    /*
    2025.7.23  多年以后我看到这个题终于有了全新和最好的思路与解法
    本质上是选或不选和完全背包
    */
    public boolean isMatch(String S, String P) {
        char[] s = S.toCharArray(), p = P.toCharArray();
        int n = s.length, m = p.length;
        boolean[] f = new boolean[m + 1];
        f[0] = true;
        // 处理空字符串匹配 *
        for (int j = 1; j < m; j++) {
            if (p[j] == '*') {
                f[j + 1] = f[j - 1];  // * 可以匹配空字符串
            }
        }
        for (int i = 0; i < n; i++) {
            boolean pre = f[0];
            f[0] = false;
            for (int j = 0; j < m; j++) {
                char c = p[j];
                boolean temp = f[j + 1];
                if (Character.isLowerCase(c)) {
                    f[j + 1] = s[i] == c && pre;
                } else if (c == '.') {
                    f[j + 1] = pre;
                } else {  // pj为*，对p[j-1]分类讨论
                    // 不选
                    if (p[j - 1] != '.' && p[j - 1] != s[i]) {
                        f[j + 1] = f[j - 1];
                    } else {
                        boolean top = f[j + 1];  // 保存 f[i][j + 1]
                        f[j + 1] = f[j - 1];
                        // 可以选
                        f[j + 1] |= top;
                    }
                }
                pre = temp;
            }
        }
        return f[m];
    }
}

复杂度

  • 时间复杂度: $O(mn)$
  • 空间复杂度: $O(m)$
