5 Methods To Solve || ✅Beats 🚀 100% || Time Complexity O(n) || Space Complexity O(1)

Intuition

The Fibonacci sequence is defined recursively, where each number is the sum of the two preceding numbers. Given an integer \( n \), the goal is to compute the n-th Fibonacci number, \( F(n) \). This can be done using several methods, but the key insight is to leverage the relationship \( F(n) = F(n-1) + F(n-2) \).

Complexity

Recursive Approach

  • Time Complexity: \( O(2^n) \)
  • Space Complexity: \( O(n) \) (due to call stack)

Memoization Approach

  • Time Complexity: \( O(n) \)
  • Space Complexity: \( O(n) \) (for memoization array)

Bottom-Up Dynamic Programming

  • Time Complexity: \( O(n) \)
  • Space Complexity: \( O(n) \)

Optimized Space Complexity

  • Time Complexity: \( O(n) \)
  • Space Complexity: \( O(1) \) (only two variables)

Matrix Exponentiation

  • Time Complexity: \( O(\log n) \)
  • Space Complexity: \( O(1) \) (constant space for matrices)

Approach

1. Recursive Approach

This is the simplest and most direct way to calculate Fibonacci numbers, following the recursive definition. However, it has exponential time complexity due to redundant calculations.

Code Example:

public class Solution {
    public static int fib(int n) {
        if (n <= 1) {
            return n; // Base case
        }
        return fib(n - 1) + fib(n - 2); // Recursive calls
    }
}
  • Explanation:
  • If \( n \) is 0 or 1, return \( n \) (base cases).
  • For \( n > 1 \), recursively compute \( F(n-1) \) and \( F(n-2) \).

2. Memoization (Top-Down Dynamic Programming)

To optimize the recursive approach, we can store the results of already computed Fibonacci numbers to avoid redundant calculations.

Code Example:

public class Solution {
    private int[] memo;

    public int fib(int n) {
        memo = new int[n + 1];
        return fibonacci(n);
    }

    private int fibonacci(int n) {
        if (n <= 1) {
            return n; // Base case
        }
        if (memo[n] != 0) {
            return memo[n]; // Return cached result
        }
        memo[n] = fibonacci(n - 1) + fibonacci(n - 2); // Cache result
        return memo[n];
    }
}
  • Explanation:
  • We create a memo array to store results for Fibonacci numbers.
  • The recursive function checks if the result is already computed before calculating it.

3. Bottom-Up Dynamic Programming

This approach builds the solution iteratively from the base cases up to \( n \), eliminating the need for recursion.

Code Example:

public class Solution {
    public int fib(int n) {
        if (n <= 1) {
            return n; // Base case
        }

        int[] dp = new int[n + 1];
        dp[0] = 0;
        dp[1] = 1;

        for (int i = 2; i <= n; i++) {
            dp[i] = dp[i - 1] + dp[i - 2]; // Build the sequence
        }

        return dp[n]; // Return the n-th Fibonacci number
    }
}
  • Explanation:
  • We create an array dp to store Fibonacci numbers up to \( n \).
  • Use a loop to compute each Fibonacci number from the previously computed numbers.

4. Optimized Space Complexity

By observing that we only need the last two Fibonacci numbers to compute the next one, we can reduce space complexity.

Code Example:

public class Solution {
    public int fib(int n) {
        if (n <= 1) {
            return n; // Base case
        }

        int a = 0; // F(0)
        int b = 1; // F(1)
        int result = 0;

        for (int i = 2; i <= n; i++) {
            result = a + b; // F(n) = F(n-1) + F(n-2)
            a = b; // Update F(n-2)
            b = result; // Update F(n-1)
        }

        return result; // Return the n-th Fibonacci number
    }
}
  • Explanation:
  • Maintain only two variables, a and b, to store \( F(n-2) \) and \( F(n-1) \).
  • Iterate to compute the next Fibonacci number until reaching \( n \).

5. Matrix Exponentiation

Using matrix exponentiation allows us to compute Fibonacci numbers in logarithmic time. This method is particularly useful for very large \( n \).

Code Example:

public class Solution {
    public int fib(int n) {
        if (n <= 1) {
            return n; // Base case
        }

        int[][] result = matrixPower(new int[][]{{1, 1}, {1, 0}}, n - 1);
        return result[0][0]; // F(n) is in the top left corner
    }

    private int[][] matrixPower(int[][] matrix, int n) {
        int[][] result = {{1, 0}, {0, 1}}; // Identity matrix
        while (n > 0) {
            if ((n & 1) == 1) {
                result = multiply(result, matrix); // Multiply when n is odd
            }
            matrix = multiply(matrix, matrix); // Square the matrix
            n >>= 1; // Divide n by 2
        }
        return result;
    }

    private int[][] multiply(int[][] a, int[][] b) {
        return new int[][]{
            {a[0][0] * b[0][0] + a[0][1] * b[1][0], a[0][0] * b[0][1] + a[0][1] * b[1][1]},
            {a[1][0] * b[0][0] + a[1][1] * b[1][0], a[1][0] * b[0][1] + a[1][1] * b[1][1]}
        };
    }
}
  • Explanation:
  • The Fibonacci sequence can be expressed using matrix multiplication.
  • The transformation matrix is raised to the power \( n-1 \), and the resulting matrix contains \( F(n) \) in the top left cell.

These various methods provide flexible options depending on the constraints and performance requirements of the problem. The recursive method is intuitive but inefficient for larger values of \( n \), while matrix exponentiation offers the best performance for very large inputs.
