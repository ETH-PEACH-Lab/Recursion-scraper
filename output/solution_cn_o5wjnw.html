解题思路

迭代

每次迭代一共会涉及四个节点操作，除了两个交换的节点，两个节点前的节点需要改变指针，后面的节点需要被记录，防止丢失

递归

入参：两个要交换的节点，node和node.next。
返回值：node.next。
终止条件：node.next.next为空，即入参为最后两个节点；或node.next为空，即node为单个的尾结点。
递归操作：先让后面的节点进行交换，并记录下已完成交换的子链表的尾结点，最后完成当前两个节点的交换操作。

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode(int x) { val = x; }
 * }
 */

    //递归
    public ListNode swapPairs(ListNode head) {
        if (head == null) {
            return head;
        }
        return helper(head, head.next);
    }

    /***
     * @Description:递归函数
     * @Param [n->第一个节点, next->下一个节点] 交换n和next
     * @return ListNode
     **/
    public ListNode helper(ListNode n, ListNode next) {
        //判断n是否是最后一个节点
        if (next == null) {
            return n;
        }
        //判断n和next是否是最后两个节点
        //只需要交换，不需要递归操作
        if (next.next == null) {
            next.next = n;
            n.next = null;
            return next;
        }
        //先让后面的节点交换，并记录完成交换的头结点，最后交换当前两个节点
        ListNode finish = helper(next.next, next.next.next);
        next.next = n;
        n.next = finish;
        return next;
    }
}
