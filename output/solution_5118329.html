# Intuition (Approach 2: Stack)

Let's break it down step by step in simpler terms.

1. Problem: We have a linked list, and for each node, we need to remove all nodes to its right that have larger values. This is inefficient to do with nested loops.
2. Idea for Efficiency: We want our resulting linked list to be in decreasing order. But if we reverse a list in decreasing order, it becomes increasing order.
3. Using a Stack: Since reversing a linked list directly is tricky, we can use a stack. Think of a stack like a stack of books - you add books on top of each other, and the last book you add is the first one you remove.
4. The Plan:
- We put all the nodes of our linked list onto a stack.
- Then, we create a new linked list to store our result.
- While doing this, we keep track of the maximum node value encountered.
- We start popping nodes from the stack.
- If a popped node's value is not smaller than the maximum, we add it to our result linked list.
- Since our linked list will be reversed because of using the stack, we add new nodes to the beginning.
5. In Simple Terms:
- We're using a clever trick with a stack to make things easier.
- We stack up all the nodes.
- Then, we pick them off one by one, checking if they should be in our final list.
- If they should, we add them to our list, building it backward.

So, instead of tediously checking each node with nested loops, we're using a stack to simplify the process and build our result efficiently.

```Java []
/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode removeNodes(ListNode head) {
        Stack<ListNode> stack = new Stack<>();
        ListNode current = head;

        // Add nodes to the stack
        while (current != null) {
            stack.push(current);
            current = current.next;
        }

        current = stack.pop();
        int maximum = current.val;
        ListNode resultList = new ListNode(maximum);

        // Remove nodes from the stack and add to result
        while (!stack.isEmpty()) {
            current = stack.pop();
            // Current should not be added to the result
            if (current.val < maximum) {
                continue;
            }
            // Add new node with current's value to front of the result
            else {
                ListNode newNode = new ListNode(current.val);
                newNode.next = resultList;
                resultList = newNode;
                maximum = current.val;
            }
        }

        return resultList;
    }
}

Intuition (Approach 3: Reverse Linked List)

So, the problem we're dealing with is about deleting nodes in a linked list. We want to delete nodes that have a larger value to their right, and we need to do this efficiently.

One way to solve this is by reversing the linked list and then traversing it to delete the nodes with smaller values. But reversing a linked list directly can be tricky. That's where stacks come in.

Think of a stack like a stack of plates. You add plates on top of each other, and when you take a plate, you take the one from the top. Similarly, with a stack in programming, you add elements on top and remove them from the top.

So, we can use a stack to reverse our linked list. We push all the nodes onto the stack. Then, we pop them off one by one. Since stacks are Last-In-First-Out (LIFO), popping them off reverses the order.

While popping off the nodes, we keep track of the maximum value encountered so far. If a node's value is not smaller than the maximum, we keep it, otherwise, we discard it.

Then, we use these selected nodes to create our new linked list. But remember, since we used a stack, our linked list is in reverse order. So, we need to build our new linked list from back to front.

In simple terms, we're flipping the linked list, finding the nodes we want to keep, and then flipping it back. This method is more efficient than directly iterating through the list multiple times.

Complexity

  • Time complexity: O(N)
  • Space complexity: O(1)

class Solution {
ListNode reverse(ListNode head) {
ListNode prev = null, next = null;
while (head != null) {
next = head.next;
head.next = prev;
prev = head;
head = next;
}
return prev;
}
public ListNode removeNodes(ListNode head) {
head = reverse(head);
int x = head.val;
ListNode tmp = new ListNode(0), prev = tmp;
while (head != null) {
while (head != null && head.val < x) {
head = head.next;
}
if (head == null) {
tmp.next = null;
break;
}
x = head.val;
tmp.next = head;
tmp = tmp.next;
head = head.next;
}
return reverse(prev.next);
}
}
