暴力代码

class Solution {
public:
    string invert(string s){
        string ans="";
        for(auto i:s){
            ans+=(i=='1')?'0':'1';
        }
        return ans;
    }
    char findKthBit(int n, int k) {
        string s="0";
        for(int i=2;i<=n;i++){
            string ss=s;
            ss+="1";
            string sss=invert(s);
            reverse(sss.begin(),sss.end());
            ss+=sss;
            cout<<i<<" : "<<ss.size()<<endl;
            s=ss;
        }
        return s[k-1];
        // return '0';
    }
};

递归（杀鸡焉用牛刀）

首先可以确定的一点：第n个字符串正中间的那个字符一定是'1'.
那么我们再研究一下n与字符串长度之间的关系，很容易能看出：第n个字符串的长度是2^n-1.

那么第一个答案就来了：

int len=(1<<n)-1; //位运算方式计算2^n
if(k==(len+1)/2) return '1';

然后再排除一个特殊情况：

if(n==1) return '0'; //S1=“0”

剩下的就要分析一波了，举个例子，我想知道第3个字符串的第2个字符。(n=3,k=2)
首先看一下S3：0111001.

len=7   k=2   k<4((len+1)/2)

所以我们要找S3的前半段，而根据规则，S3的前半段就是S(3-1)=S2，所以第3个字符串的第2个字符也是第2个字符串的第2个字符(findKthBit(n,k)=findKthBit(n-1,k)).

if(k<(len+1)/2){
    return findKthBit(n-1,k);
}

然后在看第2个字符串的第2个字符，这就满足第一个答案了，解决。

那现在我想知道第3个字符串的第6个字符(n=3,k=2).

len=7   k=6   k>4((len+1)/2)

那我们就得看S3的后半段了。根据构建规则，S3的后半段其实是S2的变形+倒置。
那么我们把S3的后半段称为S2.5。
我把S2.5按照invert的要求变回去，S2.5就会变成S2的倒置罢了。
那么S2.5的第一个字符就是S2的最后一个字符。
那我就可以通过求S2中的字符，就知道S2.5的字符（对称一下）。

搞定。

递归代码（推荐）

class Solution {
public:
    char invert(char s){
        return (s=='0')?'1':'0';
    }
    char findKthBit(int n, int k) {
        int len=(1<<n)-1;

        if(n==1) return '0';
        if(k==(len+1)/2) return '1';
        else{
            if(k>(len+1)/2){
                return invert(findKthBit(n-1,len-k+1));
            }
            else{
                return findKthBit(n-1,k);
            }
        }
        return '0';
    }
};
