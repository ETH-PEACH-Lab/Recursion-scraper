Intuition

Recursive Approach

Approach

  1. Finding Bracket Pairs:
    I start by looping through the string until I find a closing bracket ']' because it signals the end of a bracket pair.
    The while loop works till it gets "]", and then it

  2. Extracting Encoded Substring:
    Once I find a closing bracket, I know that the corresponding opening bracket '[' must have occurred earlier. So, I locate the opening bracket, and everything in between is the encoded substring.

  3. Finding the Repeating Number:
    Before each opening bracket, there's a number indicating how many times the substring within the brackets should be repeated. To find this number, I traverse backward from the opening bracket until I encounter a non-digit character, collecting the digits encountered along the way. This forms the repeating number.

  4. Decoding and Replacing:
    With the encoded substring and the repeating number identified, I decode the substring by repeating it the specified number of times. Then, I replace the original encoded substring, along with the preceding number and brackets, with the decoded string.
    Repeat Until No More Brackets:

I continue this process iteratively until there are no more brackets left in the string, ensuring all encoded substrings are decoded properly.

Complexity

  • Time complexity:O(n^2)
  • Space complexity: O(n)


Code

class Solution:
    def decodeString(self, s: str) -> str:
        while("[" in s):            
            var1 = 0
            while(var1 < len(s)):
                if s[var1] == "[":
                    op_index = var1
                elif s[var1] == "]":
                    cl_index = var1
                    break
                var1 += 1

            str_btw = s[op_index+1:cl_index]

            var2 = op_index-1
            num = ""
            var3 = 0 # to keep count of len of num, so that we can omit it 
            while (s[var2] in "0123456789" and var2>-1):
                num += s[var2]
                var2 -= 1
                var3 += 1

            num = int(num[::-1])

            s = s[:op_index-var3] + str_btw*num + s[cl_index+1:]

        return s
