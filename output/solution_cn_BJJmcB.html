24. 两两交换链表中的节点
👤 Dine 👍 4 2020-10-13 🖼 ↗ 查看原 Solution

解题思路

题目要求两两交换链表中的节点（实际的节点交换），返回交换后的链表。这样就不能通过只交换链表中节点的值来做了，那该怎么做呢？如果链表中只有一两个节点还好，节点多了，麻脑壳。

当链表为空或者链表中只有一个或两个节点时，相对简单，那就从简单的入手。
1. 链表为空或者只有一个节点，不需要交换，直接返回；

  1. 链表只有两个节点，通过交换将链表中的第二个节点作为头节点即可。

既然只有两个节点的时候，这么简单，是不是可以扩展到多个节点呢？

方法一：递归

https://leetcode.cn/problems/remove-linked-list-elements/solution/203-yi-chu-lian-biao-yuan-su-you-ya-di-gui-c-yu-ya/，提到链表具有天然的递归性，如下图所示，这里就不再赘述了。

可以把示例 1 中的链表 1--2--3--4，看成头节点（值为 1 的节点）后面挂接了一个更短的链表（比该链表少一个值为 1 的节点），即：1--（一个更短的链表（以值为 2 的节点作为头节点）），依次类推。

这样就相当于把这个链表看成只有两个节点的链表了，就很容易能够解决了。

边界条件

  1. 链表为空；

  2. 链表只有一个节点。

举栗

以链表 1->2->3->4 为例子，其交换过程如下图示：
1. 记录值为 2 的节点为 next；

2. 交换值为 3 和 4 的节点；

3. 将交换后的更短的链表挂接在头节点（值为 1 的节点）后面；

4. 将值为 2 的节点作为头节点，后面挂接 3 中交换好的链表；

5. 交换完成之后的链表。

```c []
struct ListNode swapPairs(struct ListNode head){
if (head == NULL || head->next == NULL) {
return head;
}

/* 设置 next 指针，在断开链表前，记录头节点的下一节点*/  
struct ListNode* next = head->next;  
/* 头节点后面挂接已完成交换的更短的链表 */
head->next = swapPairs(next->next); 
/* 将原链表头节点的下一节点指向原链表的头节点，实现原链表的头节点与其下一节点交换 */
next->next = head;                   
return next;

}

```python3 []
class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
        node = head.next
        head.next = self.swapPairs(node.next)
        node.next = head
        return node

# 方法二：虚拟头节点
以**链表 1->2->3->4 为例子**，如下图示：
原链表 
![image.png](https://pic.leetcode.cn/1610987384-iCAzFP-image.png)

要想两两交换该链表中的节点，需要**将值为 1 的前一个节点指向值为 2 的节点，值为 2 的节点指向值为 1 的节点，然后将值为 1 的节点指向值为 2 的节点下一节点**；
![image.png](https://pic.leetcode.cn/1610987971-FTriJO-image.png)

**值为 1 的前一个节点是哪个节点？**
![image.png](https://pic.leetcode.cn/1610988209-OQXDPR-image.png)

**由于头节点没有前一个节点，所以可以增加一个虚拟头节点来做。**
![image.png](https://pic.leetcode.cn/1610988455-JsUxEG-image.png)

由于需要**交换值为 1 的节点和值为 2 的节点**，因此需要**设置两个指针 cur/next**，还需要**将值为 1 的节点指向值为 2 的节点的下一个节点**，因此还需要**设置一个指针 nNext**。

# Show me the Code
```c++ []
class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        /* 设置虚拟头节点 */
        ListNode* dummyHead = new ListNode(0);
        /* 将虚拟头节点指向头节点 */
        dummyHead->next = head;

        ListNode* pre = dummyHead;
        /* 确保有节点可交换,以链表 1->2->3->4 为例子 */
        while (pre->next && pre->next->next) {
            /* cur 值为 1 的节点*/
            ListNode* cur = pre->next;
            /* next 值为 2 的节点*/
            ListNode* next = cur->next;
            /* nNext 值为 3 的节点*/
            ListNode* nNext = next->next;

            /* 交换 cur(值为 1) 和 next(值为 2) 指向的节点 */
            next->next = cur;
            /* 将 cur(值为 1) 指向的节点指向 nNext(值为 3) 指向的节点 */
            cur->next = nNext;

            /* 将 pre 指向的节点指向 next(值为 2) 指向的节点， 链表变为 pre->2->1->3->4 */
            pre->next = next;
            /* 遍历（pre 指向的节点指向下一对要交换的节点之前的节点(值为 1)）*/
            pre = cur;
        }
        //  释放虚拟头节点
        ListNode* retNode = dummyHead->next;
        delete dummyHead;
        return retNode;
    }
};

```java []
class Solution {
public ListNode swapPairs(ListNode head) {
ListNode dummyHead = new ListNode(0);
dummyHead.next = head;

    ListNode pre = dummyHead;
    while (pre.next != null && pre.next.next != null) {
        ListNode cur = pre.next;
        ListNode next = cur.next;
        ListNode nNext = next.next;

        next.next = cur;
        cur.next = nNext;
        pre.next = next;
        pre = cur;
    }
    return dummyHead.next;
}

}
