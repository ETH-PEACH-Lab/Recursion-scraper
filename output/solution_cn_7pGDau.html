两数相加 by O(n) 迭代

解题思路

解题方法共计两种：1. 递归 + 栈 2. 线性迭代

最优解为 2：O(n) 的线性迭代

递归 + 栈

  1. 两次递归遍历 l1 and l2 链表，在遍历的过程中将链表元素存入栈中 （正序存储）
    eg: l1 [ 1 -> 2 -> 3] l1_stack [ 1, 2, 3 ]
  2. 循环遍历两个 stack 中最长的那个，遍历过程中进行元素求和

第 2 步需要注意的点：
1. 循环边界以 stack 中最长的那个为边界
2. 两个 stack 长度可能不同
3. 当两者长度相同，末尾存在进位时

eg: 98 + 9
8 [ 8 ] = [ 8 ]
9 [ 9 ] = [ 9 ]

8 + 9 = 17 > 10 --分解--> 7 和 进位 1
但此时，我们已经将 stack 循环完毕。。。
所以，我们必须在循环之外，追加是否存在进位的判断
（PS：[Q]-进位？[A]-两数求和时不需要考虑进位吗）

时间复杂度:
两次递归 -> 2 N
一次循环 -> 1 N
产生新链表 -> 1 N

Total: 4 N -> O(N)
嘛，虽然同为 O(N) ，但是实际的执行效率可不是能够同语的。

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        if (nullptr == l1 && nullptr == l2) return nullptr;
        if (nullptr == l1) return l2;
        if (nullptr == l2) return l1;

        vector<int> LL, RR;

        // l: 1->2->3 [321] 
        // LL: 1 2 3 正序存储
        foo(l1, LL);
        foo(l2, RR);

        auto& big = LL.size() >= RR.size() ? LL : RR;
        auto& small = (big == LL ? RR : LL);

        int bigSize = big.size();
        int smallSize = small.size();
        int x = 0;  // result = x + big[i] + small[i]
        for (int i = 0; i < bigSize; i++) {
            if (i >= smallSize) {
                big[i] += x;
                if (big[i] >= 10) {
                    big[i] -= 10;
                    x = 1;
                }
                else x = 0;
                continue;
            }

            auto result = x + small[i] + big[i];
            if (result < 10) {
                x = 0;
            }
            else {
                result -= 10;
                x = 1;
            }
            big[i] = result;
        }

        if (1 == x) big.push_back(1);

        bigSize = big.size();
        ListNode* heap = new ListNode(big[0]);
        ListNode* tmp = heap;
        for (int i = 1; i < bigSize; i++) {
            tmp->next = new ListNode(big[i]);
            tmp = tmp->next;
        }

        return heap;
    }

private:
    void foo(ListNode* ll, vector<int>& vstack) {
        if (nullptr == ll) return;

        vstack.push_back(ll->val);
        foo(ll->next, vstack);
    }
};

O(n) 的线性迭代

核心：直接对两个链表进行循环迭代，同时注意两条链表谁先到达 nullptr。

时间复杂度：新链表的产生和目标链表的遍历都是在同一循环中进行的 —— 所以：O(MAX_n)

这里我默认 big 指针永远指向最长的那个链表。
如果当 big 指针为 nullptr 时，便将其与 small 进行交换。

具体内容请参考下方代码：

class Solution {
public:
    ListNode* addTwoNumbers(ListNode* l1, ListNode* l2) {
        if (nullptr == l1 && nullptr == l2) return nullptr;
        if (nullptr == l1) return l2;
        if (nullptr == l2) return l1;

        auto* big = l1;
        auto* small = l2;
        ListNode* ptr = new ListNode;
        ListNode* head = ptr;
        int x = 0;  // 进位标志位
        int result = 0;

        while (nullptr != big || nullptr != small) {
            if (nullptr == big) swap<decltype(big)>(big, small);
            if (nullptr == small)
                result = big->val + x;
            else result = big->val + small->val + x;

            x = 0;
            if (10 <= result) {
                x = 1;
                result -= 10;
            }

            ptr->next = new ListNode(result);
            ptr = ptr->next;
            big = big->next;
            if (nullptr != small) small = small->next;
        }

        if (1 == x) ptr->next = new ListNode(1);

        ptr = head;
        head = head->next;
        delete(ptr);
        return head;
    }
};
