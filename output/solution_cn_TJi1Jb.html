双指针法反转链表

双指针法反转链表

  1. 初始化三个指针：
    • prev：最初指向None，因为反转后的链表的第一个节点将指向None。
    • current：最初指向链表的头节点，即值为1的节点。
    • next_node：在遍历过程中用来临时存储current的下一个节点。故next_node又称为reserve节点
  2. 遍历链表：移动current指针遍历整个链表，对于每个节点：
    • 临时保存current.next到next_node，因为一旦我们改变current.next的指向，我们将失去对原链表中下一个节点的引用。
    • 将current.next指向prev，实现反转。
    • 移动prev和current指针前进到下一位置，准备下一次迭代。

图例演示

通过具体的图例来看看这个过程：

初始状态：

None   1 -> 2 -> 3 -> None
^      ^
prev   current

第一次迭代：

  • 保存current.next（即2）到next_node。
  • 将current.next指向prev（即None）。
  • 移动prev到current，current到next_node。
None <- 1    2 -> 3 -> None
        ^    ^
       prev current

第二次迭代：

  • 重复上述步骤，继续反转。
None <- 1 <- 2    3 -> None
              ^    ^
             prev current

第三次迭代：

  • 继续反转直到current为空。
None <- 1 <- 2 <- 3
                    ^
                   prev

最终结果：

  • 当current为空时，prev指向了原链表的最后一个节点，现在成为反转后链表的头节点。

Definition for singly-linked list.

class ListNode:

def init(self, val=0, next=None):

self.val = val

self.next = next

class Solution:
def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
prev = None
current = head
while current: # current不为空则继续向下遍历
next_node = current.next # next_node又叫reserve_node
current.next = prev # 改变cur->next的指向，反转current的下一个节点
prev = current
current = next_node
return prev # current为空跳出循环的时候，prev指向的刚好是之前的最后一个非空节点（即反转后的头结点）



时间复杂度:
$O(n)$，n为链表长度

空间复杂度:
$O(1)$

## 递归法反转链表
考虑使用递归法遍历链表，当越过尾节点后终止递归，在回溯时修改各节点的 next 引用指向。

### 代码：
可以看作双指针法的改写，思路都是一样的，只是在回溯的时候修改
```Python3 []
class Solution:
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        """递归解法"""
        def reverse(current, prev):
            if current == None: # 递归出口：cur为空
                return prev
            next_node = current.next # 保存current到next
            current.next = prev #  反转current的下一个节点
            return reverse(next_node, current) # 用递归来代替节点移动过程
        return reverse(head, None) # 初始化依然是current指向head，prev指向None

递归解法分析

  1. 基本思想：递归解法将大问题分解为小问题。在这里，大问题是反转整个链表，而小问题是反转链表的一小部分，最终通过递归调用来解决整个问题。

  2. 递归函数：reverse(current, prev)是一个内部定义的递归函数，它接受当前节点current和前一个节点prev作为参数。这个函数的目的是在遍历链表的过程中，逐个反转节点的指向。

  3. 递归出口：当current为空时，递归达到出口。这表示已经遍历到链表的末尾，此时prev指向反转后链表的头节点，应将其返回。

  4. 反转操作：在每次递归调用中，函数先保存current的下一个节点next_node，然后将current.next指向prev，实现反转。随后，递归调用reverse(next_node, current)，以next_node作为当前节点继续递归，直到链表完全反转。

  5. 初始化调用：最初调用reverse(head, None)时，head是链表的头节点，None表示反转后链表尾部应指向None。

与双指针方法的区别

  • 空间复杂度：递归方法的空间复杂度主要由递归调用栈的深度决定，对于长度为n的链表，其空间复杂度为O(n)。而双指针方法的空间复杂度为O(1)，因为它只需要修改指针，不需要额外的栈空间。

  • 实现复杂度：递归方法的代码通常更简洁、更易于理解，尤其是在逻辑较为复杂的情况下。双指针方法虽然空间效率更高，但在某些情况下代码的编写可能稍显复杂。

  • 性能考虑：对于非常长的链表，递归方法可能会导致栈溢出错误，因为每一层递归调用都会消耗一定的栈空间。双指针方法不会有这个问题，因为它不依赖于调用栈。
