206. 反转链表

解法一：迭代

这种方法可以在O(1)的空间复杂度下反转链表，其中时间复杂度为O(n)
方法不难，我们只需要注意改变链表节点指向这一点
要时刻记住我是谁，我前面是谁，我后面是谁

步骤
+ 定义一个cur指针，指向头结点，再定义一个pre指针，初始化为null。
+ 首先要把 cur->next 节点用tmp指针保存一下，也就是保存一下这个节点，为了后面更新 cur 指针。
+ 更新 pre 和 cur 指针。

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        //if(head==nullptr) return nullptr;
        ListNode* p=head;
        ListNode* q=nullptr;
        //大致思路就是访问一个链表的元素，然后将该元素用头插法的方式插入另一个空链表中，注意其中的一些小问题即可。
        while(p)
        {
            //要临时存储要访问正向链表此时节点的下一个节点
            ListNode* pTemp=p->next;
            p->next=q;
            q=p;
            p=pTemp;
        }
        return q;
    }
};

解法二：利用栈结构解题

反转链表，我们很容易可以想到先从头节点依次入栈，入栈完之后依次出栈，那么就顺利的把链表反转了。我们把栈的类型设置为节点类型，也可以设置为节点里面的数据类型。

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        //巧用栈解题
/*
        stack<ListNode*> s;
        ListNode* cur=head;
        while(cur)
        {
            s.push(cur);
            cur=cur->next;
        }
        //出栈即反转
        ListNode* p=new ListNode(0);
        ListNode* ans=p;
        while(!s.empty())
        {
            p->next=s.top();
            p=p->next;
            s.pop();
        }
        p->next=nullptr;
        return ans->next;
*/    
        //想一想能不能存储节点数据
        stack<int> s;
        ListNode* cur=head;
        while(cur)
        {
            s.push(cur->val);
            cur=cur->next;
        }
        //出栈即反转
        ListNode* p=new ListNode(0);
        ListNode* ans=p;//记录头节点
        while(!s.empty())
        {
            p->next=new ListNode(s.top());
            s.pop();
            p=p->next;
        }
        p->next=nullptr;
        return ans->next;
    }
};

时间复杂度：O(n)

空间复杂度：O(n)

解法三：利用构造函数解决

链表中的构造函数ListNode(int x, ListNode *next) : val(x), next(next) {}可以简单的理解为头插法，我们把构造一个新节点指向ans，然后把新节点赋值给ans.

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* ans=nullptr;
        for(ListNode* cur=head;cur!=nullptr;cur=cur->next)
        {
            ans=new ListNode(cur->val,ans);
        }
        return ans;
    }
};

时间复杂度：O(n)

空间复杂度：O(n)

解法四：递归

相当于从头开始，依次递归相邻的两个节点，直到到达最后两个节点为止，然后开始执行ListNode* res=recur(cur->next,cur)的语句，此时ptr就是链表的倒数第二个节点，cur是链表的倒数第一个节点，然后就可以修改他们的指向，我们使用res的意义在于记录反转过后链表的头节点，即刚开始链表的尾节点。
过程如下图

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        return recur(head,nullptr);         //调用递归并返回
    }
protected:
    ListNode* recur(ListNode* cur,ListNode* ptr)
    {
        if(cur==nullptr) return ptr;        //终止条件
        ListNode* res=recur(cur->next,cur); //递归后继节点
        cur->next=ptr;                      //修改节点指向
        return res;                         //返回反转链表的头节点
    }
};

时间复杂度：O(n)

空间复杂度：O(n)：其中n是链表的长度。空间复杂度主要取决于递归调用的栈空间，最多为 n层。
