Approach

  1. Make a function factorial(n) to find n!
  2. One more function get_sequence(n,k) to find index sequence. It will help us to find the index of elements in the result.
    + seq : the result requence
    + Reverse iterable (n-1) times to find each quotient corresspoding each factorial(i), then append it to seq
    + Return seq
  3. Initialize empty string res to save result, array = ['1', '2', '3', ..., 'n'] to choice what char will next add to res by seq
  4. Run while loop when seq is not empty :
    + Pop left the seq to get the current index
    + Add array[index] to res , then delete it from the array
  5. After the loop, the array will contain one last element, add it to the end of res and return

def factorial(n):
    if n == 0 : return 1
    return n*factorial(n-1)

def get_sequence(n,k):
    seq = []
    k = k - 1
    for i in range(n-1,0,-1):
        quotient,remainder = k//factorial(i),k%factorial(i)
        seq.append(quotient)
        k = remainder
    return seq

class Solution:
    def getPermutation(self, n: int, k: int) -> str:
        sequene = get_sequence(n,k)
        res = ''
        array = [str(i) for i in range(1,n+1)]
        while sequene :
            index = sequene.pop(0)
            res +=array[index]
            del array[index]
        res +=array[0]
        return res
