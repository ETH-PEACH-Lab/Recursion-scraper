约瑟夫环问题（递归+数学+迭代优化空间）
👤 huang-bin-bin-7 👍 71 2022-05-04 🖼 ↗ 查看原 Solution

基本同题题解链接：剑指 Offer 62. 圆圈中最后剩下的数字
- 【⚠ 注意！！】需要注意的是由于该题下标是 [1, n] ，该题解下标是从 [0, n - 1]
- 不过不影响答案，将最后得到的答案 +1 即可！~

首先给出公式后面进行解释

公式

f(n, m) = (f(n−1, m) + m) % n

f(n, m)表示，n个人报数，每报到m时杀掉那个人，返回最终胜利者的编号

核心思路

因为我们知道最后剩下一个人的情况时胜利者的下标是0，也就是我们已知胜利者最后的位置，逆推到最初的时候胜利者所在的位置：
1. 关注胜利者的下标位置是怎么变的
2. 每杀掉一个人，其实就是把这个数组向前移动了m位
- 为什么是向前移动了m位
因为每次都会从杀掉的人后面一个开始重新报数（C为被杀的，G为最后胜利者）

把A和B接到H后面形成一个新的队列，并且以D为新的队伍头

可以看到G的位置向左移动了m位，也就是减少了m，所以逆推G的位置时就要加上m就是公式中的 (f(n - 1) + m) % n
- 为什么% n（注意n是会随着人数的变化而改变）
因为当+ m后超过当前的总人数n时，需要回到队伍头计数

实现

【递归做法】

class Solution {
    int f(int n, int m) {
        if (n == 1) return 0;
        return (f(n - 1, m) + m) % n;
    }
public:
    int lastRemaining(int n, int m) {
        return f(n, m);
        //【注意！！】因为下标原因，该题返回的答案需要 +1 
    }
};

【迭代优化空间】

class Solution {
public:
    int lastRemaining(int n, int m) {
        int f = 0;//最后剩下一个人的情况时胜利者的下标是0
        //开始逆推
        for (int i = 2; i != n + 1; ++i) {
            f = (f + m) % i;//循环右移m位
        }
        return f;
        //【注意！！】因为下标原因，该题返回的答案需要 +1 
    }
};
