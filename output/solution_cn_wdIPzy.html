四种方法解决合并有序链表
👤 edte 👍 0 2021-12-11 🖼 ↗ 查看原 Solution

题意

将两个升序链表合并为一个新的 升序 链表并返回

原地归并

这题就是归并排序的基础，也是非常常见的操作之一。最直接的自然是开双指针遍历，然后取较小值归并。

我们可以原地归并，直接找一个链表为基础，然后遍历零一个链表，如果比当前小，则插入到前一个元素（头插），如果大，则结果链表前移。

最后再把下后面没有遍历完的节点加到后面去即可。

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode *dummy=new ListNode(0,list1);
        ListNode *p1=dummy;
        ListNode *p2=list2;
        ListNode *t1=nullptr;
        ListNode *t2=nullptr;

        while(p2&&p1->next){
            if (p2->val<=p1->next->val){
                t1=p1->next;
                t2=p2->next;
                p1->next=p2;
                p2->next=t1;
                p1=p2;
                p2=t2;
            } else {
                p1=p1->next;
            }
        }

        if (!p1->next){
            p1->next=p2;
        }

        return dummy->next;
    }
};

时间复杂度：$O(n)$，空间复杂度：$O(1)$

新链表归并

原地归并其实已经很简单了，不过涉及到头插，可能不太容易理解，更简单的直接开新链表，然后双指针每次取较小值插入即可。

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        ListNode *p1=list1;
        ListNode *p2=list2;
        ListNode *dummy=new ListNode();
        ListNode *cur=dummy;

        while(p1&&p2){
            if (p1->val>=p2->val){
                cur->next=new ListNode(p2->val);
                p2=p2->next;
            } else {
                cur->next=new ListNode(p1->val);
                p1=p1->next;
            }
            cur=cur->next;
        }
        if(p1){
            cur->next=p1;
        }
        if(p2){
            cur->next=p2;
        }

        return dummy->next;
    }
};

时间复杂度：$O(n)$，空间复杂度：$O(n)$

优先队列

类似于开空间暂存，干脆直接找个有序的数据结构，还不用我们手动维护有序性了，小顶堆就行，先全部插入进去，再弹出来即可。两个链表合并显得有点复杂了，不过很多链表合并就比较适合了。

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
    struct cmp{
        bool operator() (ListNode *a,ListNode* b){
            return a->val > b->val;
        }
    };

public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        priority_queue<ListNode*,vector<ListNode*>,cmp> q;
        ListNode *dummy=new ListNode();
        ListNode *cur;        

        while(list1){
            q.push(list1);
            cur=list1->next;
            list1->next=nullptr;
            list1=cur;
        }

        while(list2){
            q.push(list2);
            cur=list2->next;
            list2->next=nullptr;
            list2=cur;
        }

        cur=dummy;

        while(!q.empty()){
            cur->next=q.top();
            cur=cur->next;
            q.pop();
        }

        return dummy->next;
    }
};

时间复杂度：$O(nlog^n)$，空间复杂度：$O(n)$

递归

除了迭代双指针或数据结构维护有序性，更巧妙的是使用递归。这题递归不难，但是非常巧妙，我初见时直呼 666.

首先，递归一半分为前序和后序，后序递归我们通常用在需要方向遍历的题中，而另一个常见的操作就是，返回的一个头节点。我们只需要记住一点：当前返回的节点，就是上一个节点的下一个节点。

我们经常根据这一点，去删掉某些节点，或选择特定的节点，这道题也是这样。

我们来思考每次处理的子结构要干些什么，即递归函数的作用是什么：

其实很简单，就是从两个链表里面选取最小值，作为上一个节点的下一节点

由于链表已经有序，所以我们只考虑第一个节点，那么如果有一个链表为空，显然最小值就只能是另一个节点的头节点，直接返回即可。（这就是递归出口）

然后，假设链表 l1 的头节点比较小，显然我们应该返回 l1 的这个头节点。反过来同理。

但是，上一个节点没问题，下一个节点却还需要设置一下。由于 l1 去掉了一个节点，所以它的下一个节点，就应该是去除了这个节点的两链表的最小值。

就这样，我们每次在当前子结构得到上一个节点的下个节点该是什么，也设置了下一个节点的值，最后整个链表就设置好了。

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* mergeTwoLists(ListNode* list1, ListNode* list2) {
        if (!list1){
            return list2;
        }
        if(!list2){
            return list1;
        }
        if(list1->val<list2->val){
            list1->next=mergeTwoLists(list1->next,list2);
            return list1;
        }
        list2->next=mergeTwoLists(list1,list2->next);
        return list2;            
    }
};

时间复杂度：$O(n)$，空间复杂度：$O(n)$
