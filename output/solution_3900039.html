Intuition

The problem aims to add two numbers represented as linked lists. Each node in the linked list contains a single digit, and the digits are stored in reverse order. We need to compute the sum of the two numbers and return it as a linked list.

Approach

The provided code implements a recursive approach to solve the problem. The addTwoNumbers function takes two linked lists (l1 and l2) as input, along with a carry value (initialized to 0). It recursively traverses the linked lists, adding the corresponding digits of l1 and l2, along with the carry.

The algorithm performs the following steps:

  1. Initialize l1Val and l2Val to the values of the current nodes in l1 and l2, respectively. If a node is null, the value is considered as 0.
  2. Compute the sum of l1Val, l2Val, and carry, storing it in the total variable.
  3. If both l1 and l2 are null, check if the carry is 0. If it is, return null since there are no more digits to process. Otherwise, create a new node with the carry value and return it.
  4. If either l1 or l2 is not null, get the next nodes (l1Next and l2Next).
  5. Create a new node with the value total % 10 (to obtain the digit) and recursively call addTwoNumbers with l1Next, l2Next, and an updated carry value (total >= 10 ? 1 : 0).
  6. Return the newly created node.

Complexity

  • Time complexity: The time complexity of this algorithm is O(max(N, M)), where N and M are the lengths of the input linked lists l1 and l2, respectively. The algorithm traverses each node once.
  • Space complexity: The space complexity is also O(max(N, M)), as the recursive calls consume additional space on the call stack.

Code

function addTwoNumbers(
    l1: ListNode | null,
    l2: ListNode | null,
    carry: number = 0
): ListNode | null {
    const l1Val: number = l1 && l1.val ? l1.val : 0;
    const l2Val: number = l2 && l2.val ? l2.val : 0;
    const total: number = l1Val + l2Val + carry;
    if (l1 === null && l2 === null) {
        return carry === 0 ? null : new ListNode(carry, null);
    } else {
        const l1Next: ListNode | null = l1 && l1.next ? l1.next : null;
        const l2Next: ListNode | null = l2 && l2.next ? l2.next : null;
        return new ListNode(
            total % 10,
            addTwoNumbers(
                l1Next,
                l2Next,
                total >= 10 ? 1 : 0
            )
        );
    }
}
