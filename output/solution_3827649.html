Intuition

Both the players will try to get the optimal score and NOT optimal steps at every choice.
The real challenge is how will you calculate player2's score and compare with player1. If unable to think of, read ahead.

Still any doubts, feel free to ask.

Approach

keep a boolean player, true means player1's turn, false means player2's. If player1 is playing it can pick either first or last. Pick left/right whichever gives the max then switch to player2.
!!!! IMP !!!!
if player2 is playing, instead of using a separate variable to store P2's score, subtract the value P2 picks from P1's score and move ahead.

Q : But why min, we are finding max of player 2??
A : We used -ve values to denote max of what player2 picks. -ve values, max is obtained by picking the smaller of 2.

Q : Still not clear T__T
A : Take the first TC {1,5,2}
P1 takes 1, P1's current score is 1, now P2 can choose from 5 and 2. if the reader feels P2 must pick 5, so if it picks -5 then P2's score is 5, but we need to compare with P1, so we take 1 - 5.
(IMP!!) we are not picking between -5 and -2 rather we are picking one of 'em and moving until we reach the base case and return back, then we go back and pick the other and go towards the base case. From the both the values P2 picks min of them. For P1, the larger the value, the better. For P2, the smaller the value the better.

Q : But P1's score is -ve!!!!!!! this doesn't make any sense.
A : Well no but yes..
How do you verify if P1 or P2 wins? If P1 - P2 is -ve then it means P2 scored more. So instead of using 2 variables to keep track of P1 and P2, just subtract those values that P2 picks and move ahead.
See the pic for more understanding.

Q : Okay but then it returns P1 max score. How to know if P1 won or not?
A : P1 wins if it finds a way to get a score >= 0. If P1 and P2 collect same amount, then the difference of their score is 0, and P1 wins as mentioned in description. If there exist any one way where P1 gets a final -ve score and a final +ve score at topmost level. It will always return the max of whatever it can get. Similarly P2 the min of what it can to P1.

At the first recursion call, just compare if score is >= 0.

Recursion

class Solution {
public:

    int f(bool player, vector<int>& nums, int left, int right){

        if(left==right) return nums[left];

        else{

            if(player){
                return max(
                    nums[left] + f(!player, nums, left+1, right),
                    nums[right] + f(!player, nums, left, right-1)
                );
            }

            else{
                return min(
                    -nums[left] + f(!player, nums, left+1, right),
                    -nums[right] + f(!player, nums, left, right-1)
                );
            }

        }

    }

    bool PredictTheWinner(vector<int>& nums) {
        return f(1, nums, 0, nums.size()-1) >= 0;
    }
};

Memoized Recursion

class Solution {
public:

    vector<vector<int>> dp;

    int f(bool player, vector<int>& nums, int left, int right){

        if(left==right) return nums[left];

        else if(dp[left][right] != -1) return dp[left][right];

        else{

            if(player){
                dp[left][right] = max(
                    nums[left] + f(!player, nums, left+1, right),
                    nums[right] + f(!player, nums, left, right-1)
                );
            }

            else{
                dp[left][right] = min(
                    -nums[left] + f(!player, nums, left+1, right),
                    -nums[right] + f(!player, nums, left, right-1)
                );
            }

        }

        return dp[left][right];

    }

    bool PredictTheWinner(vector<int>& nums) {
        dp.resize(nums.size()+1, vector<int>(nums.size()+1, -1));
        return f(1, nums, 0, nums.size()-1) >= 0;
    }
};
