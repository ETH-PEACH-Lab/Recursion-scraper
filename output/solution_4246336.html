Intuition

I solved this problem using dynamic programming .Its time complexity was O(len(s)*len(p)). However this post doesn't explain that solution. I am sure there are many more posts to explain that.

Thereafter I found a solution in linear time using 2 pointer approach. I have made some visualisations using python to understand this solution. Here is the link to the blog post for this solution by Yu:

Approach

  1. Start by setting up some placeholders: We set up some variables that keep track of positions and states (s_cur, p_cur, match, star) as we move through the string and pattern.
  2. (Loop) While we haven't reached the end of the string, we check the following:
    1. If the current character in the pattern matches the current character in the string or if the pattern character is a question mark, we move forward in both the string and pattern.
    2. If we encounter a '*' in the pattern, we note down the current positions in the string and pattern and move the pattern position forward.
    3. If none of the above conditions are met, but we have seen a '' before, we reset the pattern position after the '' to the next character, increment the match counter, and move the string position to the new match.
    4. If none of the conditions are met mainly (p_cur reaches the end) and we have no '*' to fall back on, we know the pattern doesn't match the string, so we return False.
  3. After going through the string, we check if there are any '*' characters left in the pattern. If there are, we move the pattern position forward.
  4. Finally, if we've reached the end of the pattern at this point, we know the pattern matches the string, so we return True. Otherwise, we return False.

Complexity

  • Average Time complexity: O(n)
  • Worst Case Time complexity: O(mn) (Eg String (s): "aaaaaaaaaaab"
    Pattern (p): "*aab")
  • Space complexity: O(1)

class Solution:
    def isMatch(self, s, p):
        s_cur = 0
        p_cur= 0
        match = 0
        star = -1
        while s_cur<len(s):
            if p_cur<len(p):
                print("Pattern Char",p[p_cur])
            if p_cur< len(p) and (s[s_cur]==p[p_cur] or p[p_cur]=='?'):
                s_cur = s_cur + 1
                p_cur = p_cur + 1
            elif p_cur<len(p) and p[p_cur]=='*':
                match = s_cur
                star = p_cur
                p_cur = p_cur+1
            elif (star!=-1):
                p_cur = star+1
                match = match+1
                s_cur = match
            else:
                return False
        while p_cur<len(p) and p[p_cur]=='*':
            p_cur = p_cur+1

        if p_cur==len(p):
            return True
        else:
            return False
