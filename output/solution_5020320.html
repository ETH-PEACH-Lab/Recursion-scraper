Intuition

Approach

The algorithm adds two numbers represented by linked lists, where each node contains a single digit:
- A dummy node (dummyNode) is used to simplify the management of the result linked list, avoiding the need to handle special cases for the head node.
- Two pointers (temp1 and temp2) are initialized at the heads of the two input lists.
- A carry variable is used to keep track of the carry from one digit to the next.
- The list nodes are traversed simultaneously in a loop. At each step, the corresponding digits (and any existing carry) are added.
- A new node with the resulting digit is appended to the result list.
- If there is a carry after the last addition, a new node is created for this remaining carry.

Complexity

  • Time complexity: O(max(m, n)): where m and n are the lengths of the two linked lists. The loop iterates once for each element in the longer of the two lists, hence the complexity depends on the length of the longer list.
  • Space complexity: O(max(m, n)): The space complexity is also determined by the size of the longer list, as a new node is potentially created for each node in the input lists, plus possibly one additional node for an extra carry.

Code

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode addTwoNumbers(ListNode l1, ListNode l2) {
        ListNode dummyNode = new ListNode(); // Create a dummy node to simplify handling of the result list.
        ListNode curr = dummyNode; // This will be used to build the result list.
        ListNode temp1 = l1; // Pointer for traversing the first input list.
        ListNode temp2 = l2; // Pointer for traversing the second input list.
        int carry = 0; // Initialize carry to zero.

        // Traverse both lists until both are fully processed.
        while (temp1 != null || temp2 != null) {
            int sum = carry; // Start with the carry from the previous operation.

            // Add the value from the first list, if available.
            if (temp1 != null) {
                sum += temp1.val;
                temp1 = temp1.next; // Move to the next node in the list.
            }

            // Add the value from the second list, if available.
            if (temp2 != null) {
                sum += temp2.val;
                temp2 = temp2.next; // Move to the next node in the list.
            }

            // Create a new node with the digit part of the sum.
            curr.next = new ListNode(sum % 10);
            curr = curr.next; // Move to the newly created node.

            // Update the carry.
            carry = sum / 10;
        }

        // If there's any carry left after the last addition, add a new node for it.
        if (carry > 0) {
            curr.next = new ListNode(carry);
        }

        // The result list starts after the dummy node.
        return dummyNode.next;
    }
}
