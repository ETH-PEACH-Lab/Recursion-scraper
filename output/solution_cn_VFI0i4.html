class Solution {
public double myPow(double x, int n) {
double abs = (x < 0 ? x * -1 : x);
double res;

    if (n >= 0) { 
        res = getPositivePow(abs, n);
    } else {
        n *= -1;
        res = getNegativePow(abs, n);
    }
    if (x < 0 && n % 2 != 0) { 
        res *= -1;
    }

    return res;
}

double getPositivePow(double x, int n) { 
    if (1 == n) { 
        return x;
    }
    if (0 == n) { 
        return 1;
    }
    if (n % 2 != 0) { 
        return x* getPositivePow(x, n/2) * getPositivePow(x, n/2);
    } else {
        return getPositivePow(x, n/2) * getPositivePow(x, n/2);
    }
}

double getNegativePow(double x, int n) { 
    if (n == 1) {
        return 1 / x;
    }
    if (n % 2 != 0) { 
        return 1/x * getNegativePow(x, n/2) * getNegativePow(x, n/2);
    } else {
        return getNegativePow(x, n/2) * getNegativePow(x, n/2);
    }
}

看了其他大佬的解题思路后, 总算有点开窍, 本题可用快速乘法解决, 和后面的题目 [剑指 Offer 64. 求1+2+…+n](https://leetcode.cn/problems/qiu-12n-lcof/) 有共通点
对于快速乘法, 我的理解如下
## 快速乘法
对于乘法 res = x * y, 我们以二进制的方式看待其中一个因子 y
**y = 2^0 * bit0 + 2^1 * bit1 + 2^2 * bit2... + 2^n-1 * bitn-1**(其中 biti 表示 y 的二进制bit位)
将 y 代入上述乘法表达式, 即可将乘法转换为易懂的加法运算
**res = x * 2^0 * bit0 + x * 2^1 * bit1 + x * 2^2 * bit2...+x * 2^n-1 * bitn-1**
其中, 对于 2^0, 2^1, 2^2...2^n-1 这些乘法因子, 可以对应的转换为左移运算(乘法的拆分为位运算真的太奇妙了)
<< 1, << 2, << 3... << n-1


### 优势
快速乘法有一个好处: 如果要求 x * y 取模后的值, 但是直接的乘法 x * y 会溢出, 则利用位运算可以依次取模,防止结果溢出

**实现思路：**
定义一个数 factor, 初始值设为 x 的1次幂； 定义 res 为结果，初始值设为 1;
为了依次查看 q0,q1...可以每次将n右移1位，并且factor要以2的指数次幂递增, factor*=factor
所以每次检查n的最低位, 如果为1, 则 res *= factor

**其他处理**
为了使计算简单, 不论 x 是否为负数，都当作正数(absOfX)处理, 只有在返回结果时再进行符号处理
n为偶数时，结果必定为正数
n为0时，结果为1
n如果小于0，则应当乘上 x 的倒数次幂, 所以一开始对n进行判断

```java []
class Solution {
public double myPow(double x, int n) {
if (0 == n) {
return 1;
}

    double absOfX = (x < 0 ? x * -1 : x);
    if (n < 0) { 
        absOfX = 1 / absOfX;
        n *= -1;
    }
    boolean isEvenPow = (n % 2 == 0);
    boolean isNegative = x < 0;

    double res = 1;
    double factor = absOfX;
        while(n != 0) { 
            if (n % 2 == 1) { 
                res *= factor;
            }
            factor *= factor;
            n = n >>> 1;
        }


    if (isNegative && !isEvenPow) { 
        res *= -1;
    }

    return res;
}

}
```
