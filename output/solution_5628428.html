Easy Solution, Explanation and Clean Code - O(log n) Solution

Overall Performance

Intuition

My first thought was to make a dict with the numbers and their respective numbers in word form.

First, do this for the number from 0 to 19. Now I have to do it with other numbers with different names, like tens (Twenty, Thirty, Forty, [...], Ninety).

After that, I would start with suffix words like hundreds, thousands, millions, etc. But I can't do it forever, so I read the Constraints and the number limit is 0 <= num <= 2\xB3\xB9 - 1, where the highest suffix is billion, so let's work with it.

Approach

  • 1\xBA Step: Make a list of the numbers from 0 to 19 in words version, so that the index 0th result in "Zero", the 10th in "Ten" and 19th in "Nineteen".
  • 2\xBA Step: Make a list of tens like te first one, so the 4th is "Forty" and the sixth is "Sixty", so to do that make a list with empty arrays until the 2th index:
self.tens = ["", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"]
  • 3\xBA Step: Make suffix list, with Billion, Million, etc.
  • 4\xBA Step: create a string copy of num, so we can better manipulate the passed number.
  • 5\xBA Step: Make if/else block to verify the value of the number, if it's tens, hudreds, millions, etc, and use it to create each part of the number in word form.
  • 6\xBA Step: Break the string copy of num in 2 parts, x and y, x is a range and y the rest, recursive call numberToWords in Y until it's a unit, and x if x isn't a ten or a unit.

x = 1

  • Recursive call y

    • y is in thousand range so take off new x and new y:
      x = 234

        y = 34
      • x is from the thousand range so put the thousand suffix after it, and call it
        • x is a hundred so put Hundred suffix after it
          x = 2

            • x is a unit so take it from the zero_to_nineteen list 2th index
              x = 2 -> x = Two
              y = None
          • Recursive Call y:
            y = 34
            • x is a ten so take it from ten's list's 3th index

        • Recursive Call x:
          x = 5

Complexity

  • Time complexity: O(log n)
  • Space complexity: O(log n)

Code


class Solution:
    def __init__(self):
        self.zero_to_nineteen = ["Zero", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"]
        self.tens = ["", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"]
        self.postfix_word = [" Billion", " Million"," Thousand", " Hundred", ""]
    def numberToWords(self, num: int) -> str:
        new_number = str(num)
        if 0 <= num < 20: 
            return self.zero_to_nineteen[num]
        elif 20 <= num < 100: 
            x = int(new_number[0]) 
            y = int(new_number[1]) 
            w = -1 #is a ten
        elif 100 <= num < 1000: 
            x = int(new_number[0]) 
            y = int(new_number[1:]) 
            w = -2  #is a hundred
        elif 1000 <= num < 10**6: 
            x = int(new_number[:-3]) 
            y = int(new_number[-3:])
            w = -3 #is a thousand
        elif 10**6 <= num < 10**9: 
            x = int(new_number[:-6]) 
            y = int(new_number[-6:]) 
            w = -4 #is a million
        elif 10**9 <= num < 2**31: 
            x = int(new_number[:-9]) 
            y = int(new_number[-9:]) 
            w = -5 #is a billion
        a = self.numberToWords(x) if w < -1 else self.tens[x]
        b = " " + self.numberToWords(y) if y else ""
        return a + self.postfix_word[w] + b
