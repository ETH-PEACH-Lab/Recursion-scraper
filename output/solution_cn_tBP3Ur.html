解题过程

使用递归的方法：
我们就必须知道两个递归的重要的部分：一个是终止的条件，另外一个就是每一部分应该进行的工作。对于这个题目终止的条件就是两个链表都遍历完成，每一部分应该进行的操作就是在自己处理的部分找出小的结点，在回溯的过程中再把结点链接起来。

先进行递归的过程，每一个next的指针等待下一步递归完成返回一个指向的位置再把链表链接起来。

复杂度

递归算法的时间复杂度 = 「单次递归调用的操作时间」 × 「递归调用的总次数」
单次递归调用的时间：比较数值大小，给next赋值，返回结点用时为常数级别$O(1)$
递归调用的总次数：每一个数字都要进行一次大小的比较调用的次数为n+m

最坏情况：两个链表长度相近，需要遍历所有节点（比如 list1:1→3→5，list2:2→4→6），时间复杂度仍为 O(m + n)
最好的情况：一个链表为空，$O(1)$

  • 时间复杂度: $O(m+n)$

递归算法的空间复杂度主要由「递归调用栈」的深度决定（栈会保存每一层递归的函数上下文），而非代码中显式创建的变量
最坏情况：每次递归都只处理一个节点，递归层数等于总节点数 m + n此时递归栈深度为 O(m + n)
最好情况：其中一个链表很短，递归层数等于较短链表的长度 O(min(m, n))

  • 空间复杂度: $O(m+n)$

Code

```C++ []
/
* Definition for singly-linked list.
* struct ListNode {
* int val;
* ListNode next;
* ListNode() : val(0), next(nullptr) {}
* ListNode(int x) : val(x), next(nullptr) {}
* ListNode(int x, ListNode next) : val(x), next(next) {}
* };
/
class Solution {
public:
ListNode mergeTwoLists(ListNode list1, ListNode list2) {
//首先判断终止条件
//自然当链表1和链表2都处理完了以后为空就返回
if(list1 ==nullptr)return list2;
if(list2 ==nullptr)return list1;

    //操作过程
    //这个部分只负责找出最小的节点
    if(list1->val<list2->val)
    {
        list1->next=mergeTwoLists(list1->next,list2);
        return list1;
    }
    list2->next=mergeTwoLists(list1,list2->next);
    return list2;
}

};
```
