1 Brute Force Approach

Intuition

  • The problem revolves around constructing strings based on recursive rules and finding a specific character in this pattern.
  • The strings grow based on reversing, inverting, and appending operations.
  • We can either construct the entire string or use a more optimized backtracking approach to avoid excessive string generation.

Approach 1: Construct and Manipulate the Entire String

  • We construct the string up to n by following the given pattern.
  • For each string s[i], it is constructed as s[i-1] + '1' + reverse(inverse(s[i-1])).
  • Once we have the string, we can directly access the k-th bit.

Complexity

  • Time complexity: O(2^n), as we build strings that double in length with each step.
  • Space complexity: O(2^n), due to the storage of each string.

Code - Brute force approach

```java []
class Solution {
public char findKthBit(int n, int k) {
if(n==1) return '0';
String s[] = new String[n];
s[0] = "0";
for(int i=1; i<n; i++) {
s[i] = s[i-1] + "1" + reverse(inverse(s[i-1]));
}
String res = s[n-1];
return res.charAt(k-1);
}

public String inverse(String s) {
    StringBuilder sb = new StringBuilder();
    for(int i=0; i<s.length(); i++) {
        char c = s.charAt(i);
        sb.append(c == '0' ? "1" : "0");
    }
    return sb.toString();
}

public String reverse(String s) {
    StringBuilder sb = new StringBuilder(s);
    return sb.reverse().toString();
}

}

#  Optimized approach - Backtracking
![image.png](https://assets.leetcode.com/users/images/89c5cdec-693c-427e-845a-33dd21c17c02_1729353668.711088.png)

# Intuition
The string in this problem grows recursively, and instead of building the entire string, we can leverage its structure to find the `k`-th bit without constructing the string. The middle of the string is always `'1'`, and the right half is an inverted and reversed copy of the left half. Using this, we can backtrack to find the required bit.

# Approach: Backtracking (Optimized)
1. The length of the `n`-th string is `(2^n - 1)`.
2. The middle of this string is always `'1'`, and it's at position `mid = (2^n - 1) / 2 + 1`.
3. If `k` is less than the middle, the answer lies in the left half, and we recursively find the answer for `n-1`.
4. If `k` is greater than the middle, the answer lies in the right half, which is an inverted and reversed version of the left half. We reduce the problem size by transforming `k` and solving recursively for `n-1`.

# Complexity
- Time complexity: O(n), because we reduce the problem size recursively by one level each time.
- Space complexity: O(n), due to the recursive call stack.

# Code - Optimized Approach
```java []
class Solution {
    public char findKthBit(int n, int k) {
        if(n==1) return '0';  // Base case: The first string is "0"

        int length = (1 << n) - 1;  // Length of the nth string (2^n - 1)
        int mid = length / 2 + 1;  // Middle character position

        if(mid == k) return '1';  // Middle character is always '1'

        if(k < mid) return findKthBit(n-1, k);  // Left half: same as (n-1)-th string

        // Right half: find in (n-1)-th string and invert the result
        return findKthBit(n-1, length - k + 1) == '0' ? '1' : '0';
    }
}
