✅ EASY || 💯 BEATS - PROOF || 🌟 JAVA || 🧑‍💻 BEGINNER FRINDLY

Intuition

The problem requires us to decode an encoded string that may have nested structures. Each k[encoded_string] format means the encoded_string inside the brackets needs to be repeated k times. To tackle this, we can use recursion to handle nested brackets seamlessly. By breaking down each bracketed substring, we simplify the decoding process, especially when nested structures are involved.

Approach

  1. Initialize Variables:

    • sb as a StringBuilder to accumulate the decoded result.
    • count to keep track of the current multiplier k.
    • temp to temporarily store the result of recursive calls when we encounter nested brackets.

  2. Iterate through Each Character in the String:

    • Digits: If we encounter a digit, we update count to build the multiplier k for the next bracketed substring.
    • Opening Bracket '[':
      • We recursively call decodeString to get the decoded substring inside the brackets.
      • Append temp to sb exactly count times and reset count to 0.
    • Closing Bracket ']':
      • Return the built sb string for the current level of recursion.
    • Alphabetic Characters:
      • Directly append to sb as they’re part of the decoded result.

  3. End of Function:

    • After processing all characters, sb contains the fully decoded string. Return this as the result.

Complexity

  • Time complexity:

O(n), where is the length of the string, since we process each character once.
- Space complexity:

O(n), due to the recursive call stack and storage in StringBuilder.

Code

```java []
class Solution {
int i = 0;

public String decodeString(String s) {

    StringBuilder sb = new StringBuilder();
    int count = 0;
    String temp = "";

    while (i < s.length()) {
        char c = s.charAt(i);

        i++;

        if (c == '[') {
            temp = decodeString(s);

            int j = 0;

            while (j < count) {
                sb.append(temp);
                j++;
            }

            count = 0;
        } else if (c == ']')
            break;
        else if (Character.isAlphabetic(c))
            sb.append(c);
        else
            count = count * 10 + c - '0';
    }

    return sb.toString();
}

}
```
