题目

21. 合并两个有序链表 Easy
剑指 Offer 25. 合并两个排序的链表 Easy

题解

既然给定两个链表都有序，那可以判断两个链表头节点值大小，将较小值结点添加到结果中，然后将对应链表节点指针后移一位，循环往复，直至有一个链表空为止。由于链表有序，所以循环终止时，非空链表中的元素都比前面已经合并的链表中的元素大。所以只需简单将非空链表接在合并链表后面，并返回合并链表即可

方法一：递归，隐式栈占空间
递归终止条件：当有一个链表为空时
如何递归：判断list1和list2头节点哪个更小，然后较小节点的next指针调用递归，指向其余节点的合并结果

方法二：非递归，不额外占空间
首先我们需要先创建一个哑节点prehead，然后将prehead指向链表l1和l2中比较小的一个。如果相等的话，指向任意一个即可。然后将较小值对应的链表的指针后移一位



哑结点

哑结点也叫做哨兵节点，对于链表相关的题目，为了方便处理边界条件，一般我们都会引入哑结点来方便求解。首先我们先来看一下什么是哑结点，哑结点是指数据域为空，指针域指向链表头节点的节点，它是为了简化边界条件而引入的。下面我们来看一个具体的例子，例如要删除链表中的某个节点操作。常见的删除链表的操作是找到要删元素的前一个元素，假如我们记为 pre。我们通过：pre->next=pre->next->next来执行删除操作。如果此时要删除的是链表的第一个结点呢？就不能执行这个操作了，因为链表的第一个结点的前一个节点不存在，为空。如果此时你设置了哑结点，那么第一个结点的前一个节点就是这个哑结点。这样如果你要删除链表中的任何一个节点，都可以通过pre->next=pre->next->next的方式来进行，这就简化的代码的逻辑

3. 串联剩余部分。p指针不为空，用r指针将p串联起来，即r->next=p;。注意这里只是把这个指针连上即可，剩余节点不需要再处理。释放Lb节点空间，即delete Lb。两个有序链表合并结果如图所示

// merge two sorted linked lists
void mergelinklist(LinkList La, LinkList Lb, LinkList &Lc)
{
    LinkList p, q, r;
    p = La->next; // p指向La的第一个数据元素节点
    q = Lb->next; // q指向Lb的第一个数据元素节点
    Lc = La;      // Lc指向La的头节点
    r = Lc;       // r指向新链表Lc的尾部
    while (p && q) 
    {
        if (p->data <= q->data) // 把p指向的节点串起来
        {
            r->next = p;
            r = p;
            p = p->next;
        }
        else // 把q指向的节点串起来
        {
            r->next = q;
            r = q;
            q = q->next;
        }
    }
    // 如果p非空，则把p后面剩余节点连接起来，即r->next = p;，否则r->next=q;
    r->next = p ? p : q; // 相当于if (p) r->next = p; else r->next = q;
    delete Lb;  
}

```C++ []
/
* Definition for singly-linked list.
* struct ListNode {
* int val;
* ListNode next;
* ListNode() : val(0), next(nullptr) {}
* ListNode(int x) : val(x), next(nullptr) {}
* ListNode(int x, ListNode next) : val(x), next(next) {}
* };
/
// code1 recursion递归
class Solution
{
public:
ListNode mergeTwoLists(ListNode list1, ListNode list2)
{
if (list1 == nullptr)
{
return list2;
}
else if (list2 == nullptr)
{
return list1;
}
else if (list1->val < list2->val)
{
list1->next = mergeTwoLists(list1->next, list2);
return list1;
}
else
{
list2->next = mergeTwoLists(list1, list2->next);
return list2;
}
}
};

```C++ []
/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
// code2 非递归/辅助指针
class Solution
{
public:
    ListNode *mergeTwoLists(ListNode *list1, ListNode *list2)
    {
        // 合并后链表的哨兵节点
        ListNode *head = new ListNode(-1);
        ListNode *pre = head;
        // 循环遍历，将两个链表中较小值插入到合并后的链表
        while (list1 && list2)
        {
            if (list1->val < list2->val)
            {
                pre->next = list1;
                list1 = list1->next;
            }
            else
            {
                pre->next = list2;
                list2 = list2->next;
            }
            pre = pre->next;
        }
        // 将剩余非空链表插入到合并链表后面
        if (list1)
            pre->next = list1;
        else
            pre->next = list2;
        return head->next;
    }
};

复杂度

  • 递归：时间复杂度为O(m+n)，其中m和n分别是两个链表长度。因为每次调用递归都会去掉list1或list2的头节点（直到至少有一个链表为空），函数mergeTwoList至多只会递归调用每个节点一次，因此时间复杂度为合并后的链表长度。空间复杂度O(m+n)，递归调用mergeTwoLists函数时需要隐式栈，隐式栈取决于递归调用的深度，最多为m+n次
  • 非递归/辅助指针：链表合并不需要再创建空间，只需要“穿针引线”，把两个单链表中的节点按非递减顺序串联即可。因此最坏情况下，需要串联每一个节点。时间复杂度O(m+n)，空间复杂度为O(1)
