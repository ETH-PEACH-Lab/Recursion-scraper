Intuition

I will help you with realtime example:

Imagine you have a row of people, each holding a number. You want to remove anyone who has a taller person standing to their right.

To solve this:
1. Start from the end of the row.
2. Keep track of the tallest person you've seen so far.
3. If someone shorter than the tallest person is found, remove them from the row.
4. Continue this process until you reach the beginning of the row.

By doing this, you'll remove anyone who has a taller person to their right, leaving only those who are taller than everyone to their right.

Methods to Solve the Problem

  1. Reversal and Traversal (Space Optimal)
  2. Iterative Traversal and Removal (Vector based)

Method 1: Reversal and Traversal↩️

  1. Reverse the linked list: First reverse the linked list. This is done to enable traversal from right to left, which is necessary for this problem.
  2. Traverse the reversed list: After reversing the list, we traverses it from right to left.
    During this traversal:
    • It keeps track of the maximum value encountered so far.
    • If a node's value is greater than or equal to the maximum value encountered so far, it updates the maximum value and advances to the next node.
    • If a node's value is less than the maximum value encountered so far, it removes that node by updating the next pointer of the previous node to skip over the current node.
  3. Reverse the list again: After completing the traversal and removing nodes as needed, we reverses the list again to restore its original order.
  4. Return the modified list: Finally, we returns the modified list, which now contains only the nodes where each node has a greater value to its right.

This approach effectively removes nodes with smaller values that have a greater value to their right without using an extra space, as required by the problem statement.

Code

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* removeNodes(ListNode* head) {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        head=reverse(head);
        ListNode* temp=head->next;
        ListNode* temp1=head;
        int max=head->val;
        while(temp!=NULL){
            if((temp->val)>=max){
                temp1->next=temp;
                max=temp->val;
                temp1=temp1->next;
            }
            temp=temp->next;
        }
        temp1->next=NULL;
        head=reverse(head);
        return head;
    }
private:
    ListNode* reverse(ListNode* head){
        if (head == NULL || head->next == NULL)
            return head;
        ListNode* rest = reverse(head->next);
        head->next->next = head;
        head->next = NULL;
        return rest;
    }
};

Method 2: Iterative Traversal and Removal ( Vector based)️

  1. Traverse the linked list and store nodes: Traverse the given linked list and store each node in a vector.
  2. Identify nodes to be removed: Iterate over the vector from right to left. Keep track of the minimum value encountered so far. If a node's value is less than the minimum value encountered so far, remove that node from the vector.
  3. Reconstruct the linked list: After identifying the nodes to be kept, reconstruct the linked list using the remaining nodes in the vector. Set the head of the linked list to the first node in the vector. Then, iterate over the remaining nodes in the vector, setting the next pointers accordingly.
  4. Terminate the list properly: Ensure that the last node's next pointer is set to null to terminate the list.
  5. Return the modified list: Return the head of the modified list.

This approach effectively removes nodes with smaller values that have a greater value to their right, as required by the problem statement. However, note that this approach involves additional space complexity due to the vector used to store the nodes.

class Solution {
public:
    ListNode* removeNodes(ListNode* head) {
        ios::sync_with_stdio(false);
        cin.tie(nullptr);
        ListNode* temp=head;
        vector<ListNode*>a;
        while(temp!=NULL){
            a.push_back(temp);
            temp=temp->next;
        }
        int min=a[a.size()-1]->val;
        for(int i=a.size()-2;i>=0;i--){
            if(a[i]->val<min) a.erase(a.begin()+i); // deleting the smaller one
            else min=a[i]->val;
        }
        head=a[0];
        temp=head;
        for(int i=1;i<a.size();i++){
            temp->next=a[i]; // inserting the next taller one 
            temp=temp->next;
        }
        temp->next=NULL;
        return head;
    }
};
