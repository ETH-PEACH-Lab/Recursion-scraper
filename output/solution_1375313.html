Problem Description:
Given an input string s and a pattern p, implement regular expression matching with support for '.' and '' where:
'.' Matches any single character.
'' Matches zero or more of the preceding element.

According to the second description ['' Matches zero or more of the preceding element.],
we must process two characher in pattern p when the following character conatains ''.

That's separate the problem into 4 cases using pattern 'p':

Case1: This case took me lots time to understand the testcase....

Enter condition
If p.length()>=2 && p.charAt(0)==‘.’ && p.charAt(1)==‘*’
Testcase:
1. s=‘’, p=., true
1. s=ab, p=., true
1. s=abc, p=., true
1. s=abcd, p=.e, false (s is not endswith ‘e’)

Testcase Conclusion:
If p=‘.*’ , no matter s is, is all true

Case2:

Enter condition
If p.length()>=2 && p.charAt(0)!=‘.’ && p.charAt(1)==‘*’
Testcase:
1. s=‘’, p=a, true
1. s=a, p=a, true
1. s=aa, p=a, true
1. s=ab, p=a, false (p is not endswith ‘e’)

Testcase Conclusion:
a\* means empty string or sequential a (‘’ or aaaaaa)

Case3:

Enter condition
If p.length()>=2 && p.charAt(1)!=‘*’
Conclusion
Just compare two char is equal or not
If p[0]==‘.’ , then is always true. (‘.’ can be any char)

Case4:

Enter condition
If p.length()<2
Conclusion
p.length() is 1 so… , if s.length()!=1, the result is false
If p[0]==‘.’ or p[0]==s[0], the result is true
else return false

After understanding 4 cases below, we can implemtent the first version of coding (Not the best solution, but it works):
Hint: if p[1]=='*', we process two chars
Hint: It's important to fully understand the String.substring(int) function

After we complete the first vesrion of codeing, we can add memo(like hashmap or int[][]) to increase our efficiency.
Or we can apply those concepts and implement the dynamic programming.

class Solution {
    public boolean isMatch(String s, String p) {
        int slen = s.length();
        int plen = p.length();

        if(slen==0 && plen==0)
            return true;

        if(plen>=2){
            if(p.charAt(1)=='*'){
                if(p.charAt(0)=='.'){
                    //Case1 for p= .*
                    for(int i=0;i<=slen;i++){
                        if(isMatch(s.substring(i),p.substring(2))){
                            return true;
                        }
                    }
                    return false;
                }else{
                    //Case2 for p= a*
                    for(int i=0;i<=slen;i++){
                        if(isMatch(s.substring(i),p.substring(2))){
                            return true;
                        }
                        if(i<slen && s.charAt(i)!=p.charAt(0)){
                            //if next char is not equal
                            //ab vs a*, we stop the loop when (ab) b!=a (a*)
                            break;
                        }
                    }
                    return false;
                }
            }else{
                //p do not startwith .* or a* or * (Those cases will be processed in case1 and case2)
                //The possibility of p is .a or a or . or a.
                //if slen is 0, there is no possibility of matching
                if(slen==0)
                    return false;
                //Case3 for p= aa .a a.
                if(p.charAt(0)=='.' || s.charAt(0)==p.charAt(0)){
                    return isMatch(s.substring(1),p.substring(1));
                }else{
                    return false;
                }
            }
        }else{
            if(slen!=plen)
                return false;
            //Case4 for p= . or a
            if(p.charAt(0)=='.' || s.charAt(0)==p.charAt(0))
                return true;
            return false;
        }
    }
}
