Intuition

Approach

Main goal is to swap every 2 nodes. But we can't do it in the same way as we do it in arrays. Each node contains a link to the next node. Basically, we need to swap links and be careful to not lose the subsequence.

Then we basically recursively repeat algorithm for the next subsequence.

This will over and over again change the subsequence, calling the function for the next subsequence and so on. In the end we get the node with fully rearranged subsequence.

Complexity

  • Time complexity: appropriate

  • Space complexity: good

Code

/**
 * Definition for singly-linked list.
 * type ListNode struct {
 *     Val int
 *     Next *ListNode
 * }
 */

func swapPairs(head *ListNode) *ListNode {

    if head == nil || head.Next == nil{
        return head
    }

    left := head
    mid := left.Next
    right := mid.Next

    left.Next = right //first picture
    mid.Next = left   //first picture

    mid.Next.Next = swapPairs(mid.Next.Next)

    return mid
}
