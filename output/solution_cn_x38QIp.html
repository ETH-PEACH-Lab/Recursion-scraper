数字1的个数（数学排列组合的方法）

解题思路

  1. 假设数字 n 有 i 位，每一位从高到低对应 [x0,x1,x2,x3,...,x(i-1)]
  2. 将 n 看成两部分，最高位 x0 以及次高位到个位组成的数字 [x1,x2,x3,...,x(i-1)]，分别对应 x010(i-1)，n % 10*(i-1)
  3. 我们可以想象一个长度为 i 的数组，当第一位填入 1 的时候，后面的 i-1 为可以从 0-9 中选择一个数任意填充，因此，第一位有 1 的数字就有 10**(i-1) 个；同理，数组第2位到第 i 位填入1时，也可以用排列组合方式计算出对应的数字个数，要注意的是：
    • 数组第2位到第 i 位填入1时，第一位只能填入 0 - x0-1 这个范围的数字
    • 第一位 x0 == 1 时，10(i-1) 个以1开头的数字不能计算在内，但是对应的有 n % 10(i-1) 个是符合以1开头的数字
  4. 由此计算完 0 - x010(i-1) 的数字中 1 的个数，再计算 0 - n % 10*(i-1) 中 1 的个数

以 n=2121 为例：

  1. 分为两部分： 2000 和 121
  2. 计算 0000-2000 中 1 的个数：
    ① 当第一位填入1，则第 2-4 位可以从 0-9 中选择一个数任意填入，相当于有1000个数，即1000-1999；
    ② 当第 2 位填入1时，第一位只能填入 0 或 1 两个数(<2)，其他两位（第3、4位）可以填入 0-9 中任意一个数，对应的数字有 2x10x10=200 个
    ③ 第 3、4 填入 1 时与 ② 同理
    ④ 因此 0000-2000 中 1 的个数为 1000 + 3 * 200 = 1600
  3. 计算 2000-2121 中 1 的个数，等价于计算 0-121 中 1 的个数
  4. 依然分为两部分 100 和 21
  5. 计算 000-100 中 1 的个数：
    ① 当第一位填入1，则第 2-3 位可以从 0-9 中选择一个数任意填入，相当于有100个数，即100-199；
    ② 此时需要注意，最大的数字是 121，而我们计算到了199，因此减去 122-199 中 1的个数，这样计算反而变复杂了
    ③ 可以发现，当第一位数字是 1 时，从 100 开始到 121 ，第一位包含 1 的个数刚好等于 21+1（包含100），而不用做多余的计算；
    ④ 当第 2 位填入1时，第一位只能填入 0 (<1)，第3位可以填入 0-9 中任意一个数，对应的数字有 1x10 = 10 个
    ⑤ 第 3 位 填入 1 时与 ② 同理
    ⑥ 因此 000-100 中 1 的个数为 22 + 2 * 10 = 42
  6. 计算 0-21 中 1 的个数（12个）......
  7. 计算 0-1总 1 的个数（1个）......
  8. 综上 0-2121 中 1 的个数为 1600 + 42 + 12 + 1 = 1655

/**
 * @param {number} n
 * @return {number}
 */
var countDigitOne = function(n) {
    if(n == 0) return 0;
    if(n < 10) return 1; # 小于10的数字直接输出
    const a = n.toString().length; # 计算数字位数
    const m = 10 ** (a-1); # 0-最高位所包含的数字1的个数
    let x1 = n % m, x0 = (n - x1) / m; # 获取最高位数字以及，次高位到个位组成的数字
    let ans = m + x0*(a-1)*m/10;
    if(x0 == 1) ans = ans - m + x1 + 1; #当最高位为1时的特殊情况
    ans += countDigitOne(x1); # 进入递归
    return ans;
};

复杂度计算

时间复杂度：O(a)，a为数字 n 的位数
空间复杂度：O(a)，递归 a 次
