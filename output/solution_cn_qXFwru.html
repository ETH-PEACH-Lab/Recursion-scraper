#通配符匹配
👤 xdeng7 👍 0 2020-08-21 🖼 ↗ 查看原 Solution

通配符匹配与正则化匹配是相似问题，花了好久才解出来这两个，分享一下心路历程，大神勿喷。
正则化比通配符问题要复杂，所以先解决通配符问题。这两个问题可以通过动态规划或递归解决。

动态规划

该问题难点在于符号‘ * ’，因为‘ * ’可以匹配任意多个字符串包括空字符，所以我们要穷举出它能匹配的所有字符的个数。我们通过动态规划的表格记录匹配过程。vector<vector<int>> dp(s_size+1,vector<int>(p_size+1))，返回 dp[s_size][p_size]。
Base Cases:
1. 首先空字符与空字符是匹配的则初始化dp[0][0]=true。
2.dp[0][j] for j in (1:p.size);当s为空字符串时，只有当p为‘’字符可以匹配，则只有第一个‘’为true，其他为false
3. dp[i][0] for i in (1:s.size);当p为空字符串，只有s同为空字符串可以匹配，其他情况都不可以。
我们以示例4为例，演示匹配过程**

外层循环为字符串s，内层循环为字符串p。所以整个匹配过程即为s中每一个字符匹配p中的每一个字符。我们已知该问题为动态规划问题，则在匹配过程中，我们要解决每一个字符前的所有子问题。解决dp[i][j]前我们需要解决dp[i][:j]。同理，也要解决dp[:i][j]。
1. if p[j-1]==s[i-1] or p[j-1]=='?':dp[i][j]=dp[i-1][j-1];即当dp[i][j]的子问题都为true时当前字符匹配才成功。

    if(p[j-1]==s[i-1]&&p[j-1]=='?')
    {
        dp[i][j]=dp[i-1][j-1]
    }

2. if p[j-1]=='*':dp[i][j]=dp[i-1][j] or dp[i][j-1];当p[j-1]=' * '为该问题的主要难点，我们需要列出‘’匹配的所以情况。
○ 当‘ * ’前的不包含‘ * ’p中字符段与s当前字符段匹配上，则‘ * ’可能与后续字符发生匹配，或者不匹配任何字符，此时该问题为真。即dp[i][j]=dp[i][j-1]（if [N,a,d]==[N,*,d,]->[N,a,d]=[N,*,d,*]）
○ 当包含‘ * ’的p中当前字符段与s中当前字符之前的字符段发生匹配，则此问题为真。即dp[i][j]=dp[i-1][j]。(if [N,a,d]==[N,*,d,*]->[N,a,d,e]=[N,*,d,*])
○ 当‘ * ’为p的第一个字符，则‘’可以匹配空字符,或者s的后续字符中有可以与‘’后p中第一个字母字符相匹配,则''可以匹配当前字符。换言之，当只要s的后续字符段有可以完全匹配''后的字符段，则‘’可以匹配任意长度的字符段。(if [N,a,d]==[N,a,d,*]->[N,a,d,c,e,b]=[N,a,d,*])
因为我们使用动态规划解决该问题，所以我们只考虑当前问题之前的子问题是否为true，不考虑当前问题的后续问题，后续问题交给算法继续处理，我们只保证当前问题与之前子问题获得解。所以我们先分析前两种情况。第一种情况，若‘ * ’前p的字符段都与s中i-1以前的字符串匹配，则该‘*’可以与s[i-1]的字符匹配。若‘ * ’前p的字符段不与s中i-1以前的字符段完全相匹配，则‘ * ’可能匹配了s中i-1以前的字符段，如若不然，字符串匹配失败。最后，我们来看看第三种情况，若‘ * ’不与当前s的字符发生匹配，且s当前字符与p中‘ * ’后第一个字母字符发生匹配，则‘ * ’有两种选择，与s中当前字符前的字符段发生匹配，或不与任何字符匹配，则将后续字符段继续交给算法继续处理。第三种情况。若‘ * ’为第一个字符，它可以匹配s中的空字符。若s第一个字符与‘ * ’后第一个字母字符没有匹配上，则此时‘ * ’可以匹配s中当前字符。换言之，‘ * ’可以匹配s中所有字符，都为true，即第三种情况包含在第二种情况里。
if(p[j-1]=='*') dp[i][j]=dp[i][j-1]||dp[i-1][j]== p[j-1]

完整代码

class Solution {
public:
    bool isMatch(string s, string p) {
        int m = s.size();
        int n = p.size();
        vector<vector<int>> dp(m + 1, vector<int>(n + 1));
        dp[0][0] = true;
        for (int i = 1; i <= n; ++i) {
            if (p[i - 1] == '*') {
                dp[0][i] = true;
            }
            else {
                break;
            }
        }
        for (int i = 1; i <= m; ++i) {
            for (int j = 1; j <= n; ++j) {
                if (p[j - 1] == '*') {
                    dp[i][j] = dp[i][j - 1] | dp[i - 1][j];
                }
                else if (p[j - 1] == '?' || s[i - 1] == p[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1];
                }
            }
        }
        return dp[m][n];
    }
};

递归

在动态规划中，我们已经分析了当出现‘ * ’字符的处理情况，当‘ * ’字符在字符段中间时，' * '字符无非就是匹配当前字符或者不匹配当前字符两种情况
• 若‘ * ’不匹配当前字符，我们将用s中当前字符与‘’后续字符匹配
• 若‘ * ’匹配当前字符，我们就用s中后续字符匹配‘’的后续字符
若‘*’在字符段开始位置或者结尾位置，
• 结尾处，若s的指针已经迭代完成，则‘ * ’不发生匹配，我们直接返回true。若s的指针不在结尾处‘ * ’匹配后续s的字符段，这与‘ * ’在字符段中间情况一样。
• 开始处，‘ * ’的匹配情况于在字符段中间一样，不再讨论。
Base Cases:
1. ‘ * ’字符不与s种任何字符匹配，则j将迭代到尾部，且i不在s的尾部，则if(j==p.length()) return s==s.length();
2. i已经迭代到尾部，j没有迭代到p的尾部。若p的剩余字符为‘ * ’则返回true。否则，匹配失败。

class Solution {
public:
    unordered_map<int,bool> dict;
    bool dp(int i,int j,string & s,string & p)
    {
        if(dict.find(i*100+j)!=dict.end())
            return dict[i*100+j];
        if(j==p.length())
            return i==s.length();
        if(i==s.length())
            return p[j]=='*'&&j==p.length()-1;
        bool ans=false;
        bool first=s[i]==p[j]||p[j]=='?';
        if(first)
        {
            ans=dp(i+1,j+1,s,p);
        }
        else if(p[j]=='*')
        {
            ans=dp(i+1,j,s,p)||dp(i,j+1,s,p);
        }
        dict[i*100+j]=ans;
        return ans;
    }
    bool isMatch(string s, string p)
    {
        if(p.find('*')!=p.npos)
        {
            string nodup;
            nodup+=p[0];
            for(int i=1;i<p.length();++i)
            {
                if(p[i-1]==p[i]&&p[i]=='*')
                    continue;
                else
                    nodup+=p[i];
            }
            p=nodup;
        }
        return dp(0,0,s,p);    
    }
};

class Solution {
public:
    bool isMatch(string s, string p)
    {
        int m=s.length();
        int n=p.length();
        int iStar=-1;
        int jStar=-1;
        int i=0,j=0;
        while(i<m)
            if(j<n&&(p[j]==s[i]||p[j]=='?'))
            {
                i++;
                j++;
            }
            else if(j<n&&p[j]=='*')
            {
                iStar=i;
                jStar=j++;
            }
            else if(iStar>=0)
            {
                i=iStar++;
                j=jStar+1;
            }
            else
                return false;
        while(j<n&&p[j]=='*') j++;//过滤掉p结尾处的‘*’，或中间出现的连续‘*’
        return j==n;
    }
};
