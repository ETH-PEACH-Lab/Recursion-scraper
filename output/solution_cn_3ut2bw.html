解题思路

方法一: 迭代+栈
整体思路:利用栈存储k[encoded_string]
1. 遍历字符串
2. 如果遇到数字,将数字和[encoded_string]入栈
3. 如果遇到']', 说明已经匹配了一个模式k[encoded_string],此时要出栈,将模式展开
4. 如果此时栈为空, 说明这个模式不属于k[encoded_string]的子串, 直接将展开的结果追加到最终字符串的后面
5. 否则,说明这个模式是属于k[encoded_string]的子串, 将展开的结果重新入栈
6. 如果遇到小写字母, 需要判断栈是否为空, 如果为空,直接将小写字母追加到最终字符串的后面
7. 否则,说明这个模式是属于k[encoded_string]的子串, 将小写字母入栈

class Solution {
public:
    string decodeString(string s) {
        string ans;
        stack<char> st;
        int n=s.size();
        for(int i=0;i<n;i++){
            //将数字和k[encoded_string]入栈
            if(s[i]>='0'&&s[i]<='9'){
                while(s[i]!=']'){
                    st.push(s[i]);
                    i++;
                }                
            }
            //如果遇到']', 说明已经匹配了一个模式, 此时要将模式展开
            if(s[i]==']'){
                char c=st.top();
                string tmp;
                while(c!='['){
                    tmp+=c;
                    st.pop();
                    c=st.top();
                }
                reverse(tmp.begin(),tmp.end());
                st.pop();
                //展开数字,数字可能是300的样式,包含多位                
                string num;
               while(!st.empty()){
                   c=st.top();
                   if(c>='0'&&c<='9'){
                    num+=c;
                    st.pop();
                   }
                   else{
                       break;
                   }
               } 
               reverse(num.begin(),num.end());
               int count=stoi(num);
               //根据数字大小, 展开模式
               string tmp_ans;
               for(int i=0;i<count;i++){
                   tmp_ans+=tmp;
               }
                //判断展开的字符串是否是一个模式的子串,如"3[a2[c]]"中的2[c]是另一个模式的子串
                //不是模式的子串,直接追加
               if(st.empty()){
                   ans+=tmp_ans;
               }
                //是模式的子串,重新入栈
               else{
                   for(char v:tmp_ans){
                       st.push(v);
                   }
               }
            }
            if(s[i]>='a'&&s[i]<='z'){
                if(st.empty()){
                  ans+=s[i];
                }
                else{
                    st.push(s[i]);
                }
            }
        }
        return ans;
    }
};

方法二:递归+栈
1. 定义一个函数get_decodeString, 获取k[encoded_string]的展开结果
2. 定义栈,用于暂存数字
3. 遍历字符串
4. 如果遇到数字,将数字入栈
5. 如果遇到字母,加入到结果字符串
6. 如果遇到']', 说明已经扩展完了一个k[encoded_string]模式,返回结果和模式的长度
7. 如果遇到'[', 说明遇到了一个模式, 获取模式中[encoded_string]结果和encoded_string的长度,并且利用栈中的数字,将模式扩展
8. 递归步骤7得到最终的结果

代码

class Solution {
public:
string get_decodeString(string s, int &len) {
        string ans;
        stack<char> st;
        int n=s.size();
        int i=0;
        while(i<n){
            if(s[i]>='a'&&s[i]<='z'){
                ans+=s[i];
            }
            if(s[i]>='0'&&s[i]<='9'){
                st.push(s[i]);
            }
            if(s[i]==']'){
                len=i;
                return ans;
            }
            //获取模式中[encoded_string]结果和encoded_string的长度,并且利用栈中的数字,将模式扩展
            if(s[i]=='['){
                int len=1;
                string subs=get_decodeString(s.substr(i+1),len);
                string num;
                while(!st.empty()){
                    num+=st.top();
                    st.pop();
                }
                reverse(num.begin(),num.end());
                int count=stoi(num);
                string tmps;
                for(int i=0;i<count;i++){
                    tmps+=subs;
                }
                ans+=tmps;
                i+=len;
                i++;
            }
            i++;
        }
        len=n;
        return ans;
}
    string decodeString(string s) {
        int len=1;
        return get_decodeString(s,len);
    }
};
