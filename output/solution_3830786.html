class Solution
{
    public:

        LOGIC

        KARNA KYA HAIN❓
        1. 2 Players hain jo ki ek game khel rahe hain.
        2. Dono 0 score se start karenge. 
        3. Game:- Ek array "nums" diya hain usme se ham "front" and "back" 2 jagah
        se number nikal sakte. Jo player number nikalega wo apne score mein wo num
        dal lega.
        4. Now our "task" is to make sure that at the end the "player 1" score
        is >= "player 2" means we want that "player 1 wins".
        5. Both players are optimally . Matlab❓->Meaning ki dono players apni
        apni baari mein apna score badhana chahenge.
        6. Aur shuruat hamesha "player 1" karega.

        THINGS TO BE CLEARED
        1. Problem mein hame p1 ka "final score nahin nikalna hain".
        2. Our main focus is to that "p1 ka score end mein p2 se bada aaye".
        3. So our focus is on difference of score of p1 and p2.

        INTUITION &APPROACH
        1. Ab isme har player ke paas 2 choice hain ya to "front" se no nikale ya
        "back" se.
        2. To ab yahan choices involved hain to ham use karenge RECURSION.
        3. Ab hamari is kahani mein "p1 hain hero" and "p2 hain villain".
        4. Ham pure recursive pattern mein "MaxDiff" leke chalenge.
        5. Why MaxDiff❓
        - Yeh puri kahani mein har koi jeetna chahta hain.
        - Jab p1 ki baari ayegi to vo apna score max karna chahega
        - Jab p2 ki baari ayegi vo apna score max karega.
        - So ham extreme cases leke chal rahe hain.
        - "front" ya "back" dono mein se jo elem nikalne per player ke jeetne
        ke chances badhenge vo player choose karega and hence usse maxDiff ayega.
        6. Is kahani mein p1 hero hain to uska "diff +" hoga aur p2 villain to 
        uska "diff -" hoga.
        7. RECURRENCE RELATION❓
        - Think in terms of index.
        - Do all stuff on indexes.
        - Yahan max diff se matlab hain, maanlo main player1 hu mere paas 2 choice
        hain "x" ya "y". Ham game ke beech mein hain.
        - Abhi tak players ka max diff chalta aa raha "dif"(positive, neg) kuch
        bhi ho sakta hain.
        - To main apna max chahunga so,
        return max(x-dif,y-dif)
        - Idhar alternate chal rahe hain pehle p1 and next p2.
        - Agar last time p2 ka max diff nikalke jo score hua hoga usse bada p1
        chah raha hain to vo max nikal raha iska p2 ki baari se.
        - To +,-,+,- chalta rahega
        - More clearly: (x-(z-(e-(maxDiff(left,right)))))...
        - maxDiff(left,right) ->subarray nikal rahe.
        - BASE CASE: Agar left==right hogaya to num[left] return karenge
        Kyo❓-> Kyoki ab vohi hain hamare paas max diff koi front, back choice 
        hain hi nahin.
        8. Ab if we notice more clearly then there will "overlapping subproblems".
        9. So we will use DP.
        10. RECURSION -> MEMOIZATION -> TABULATION -> SPACE OPTIMIZATION
        11. Memoization steps
        - Check what parameters are changing.(Here "starting and end" are changing.)
        - According to params declare the dp array.("2D ARRAY")
        - In the recursive call check if that problem has been previously solved.
        - Store the result in a dp array.
        12. What does dp[left][right] denote❓->It denotes the max difference upto that
        left and right index choices. This diff can be either "+ve" or "-ve" at any point.
        13. NOTE:- This is "DP(MIN-MAX)" pattern
        Why❓- Player 1 apna score max karna chah raha aur Player 2
        Player 1 ka score min.
        //==============================================================================================
        //MEMOIZATION
        int maxDiff(vector<vector < int>> &dp, int left, int right, vector< int > &nums)
        {
            if (left == right)
                //ek hi choice hain jo elem bacha hain use lelo
                return nums[left];
            if (dp[left][right] != -1)
                //Agar pehle se solved hain
                return dp[left][right];

            int leftChoice = nums[left] - maxDiff(dp, left + 1, right, nums);
            //Agar player ne starting se elem uthaya
            int rightChoice = nums[right] - maxDiff(dp, left, right - 1, nums);
            //Agar player ne ending se elem uthaya
            return dp[left][right] = max(leftChoice, rightChoice);
            //Storing the max diff with left and right index choices
        }
    bool PredictTheWinner(vector<int> &nums)
    {
        int n = nums.size();
        vector<vector < int>> dp(n + 1, vector<int> (n + 1, -1));
        return maxDiff(dp, 0, n - 1, nums) >= 0;
    }
};

Complexity

  • Time complexity:$O(n^2)$ great improvement from $O(2^n)$

  • Space complexity: $O(n^2)$
