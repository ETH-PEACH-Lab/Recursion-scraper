Intuition

This problem involves breaking down the given arithmetic expression into all possible combinations of different operations and then evaluating each one. The key idea is to use divide and conquer to recursively split the expression into subexpressions around each operator (+, -, *) and compute all possible results.

Approach

  1. Recursive Splitting:
    For each operator in the expression, recursively solve the subexpression on the left and right of the operator. Once the subexpressions are evaluated, combine the results using the current operator.

  2. Memoization:
    To optimize the process, memoize the results of subproblems to avoid recomputing results for the same expression multiple times.

  3. Base Case:
    If the expression is a single number, simply return that number as the result.

  4. Combining Results:
    After obtaining results from the left and right subexpressions, apply the operator to every combination of results from both sides.

Complexity

  • Time complexity:
    The time complexity is approximately O(n^3), where n is the length of the string. This comes from evaluating all possible ways to split the expression at every operator, with recursive calls on both sides and combining the results.

  • Space complexity:
    The space complexity is O(n^2) due to storing intermediate results in the memoization table (dynamic programming dp map) and recursion depth.

Beats

Code

class Solution {
public:
    unordered_map<string, vector<int>> dp; // Memoization map

    // Recursive function to evaluate all possible results
    vector<int> f(string s) {
        if (dp.find(s) != dp.end()) return dp[s]; // Return cached result if exists
        int n = s.size();
        vector<int> ans;

        // Iterate through the string to find operators
        for (int i = 0; i < n; i++) {
            if (s[i] == '-' || s[i] == '+' || s[i] == '*') {
                // Split the string around the operator
                vector<int> left = f(s.substr(0, i));
                vector<int> right = f(s.substr(i+1));

                // Combine results from both sides
                for (auto x : left) {
                    for (auto y : right) {
                        if (s[i] == '+') ans.push_back(x + y);
                        else if (s[i] == '-') ans.push_back(x - y);
                        else ans.push_back(x * y);
                    }
                }
            }
        }

        // If no operators, it's a single number
        if (ans.empty()) ans.push_back(stoi(s));

        // Cache the result for this expression and return the ans.
        return dp[s] = ans;
    }

    vector<int> diffWaysToCompute(string expression) {
        return f(expression); // Compute all possible results
    }
};

Explanation:

  1. Recursive Function:
    The function f(string s) recursively computes the possible values by splitting the expression at every operator. It returns a vector of possible results for a given subexpression.

  2. Memoization:
    The dp map stores the results for each subexpression, avoiding recomputation and improving efficiency.

  3. Combination of Results:
    After splitting the expression at an operator, the function recursively computes the results for the left and right parts, then combines these results using the operator.

This approach ensures all possible outcomes for different ways of adding parentheses in the expression are evaluated efficiently.
