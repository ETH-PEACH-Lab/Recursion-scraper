一、暴力破解
一看到题目时，就首先尝试暴力破解，首先求出第N行的字符串，再得到第K个字符，果不其然超出时间限制

```java []
class Solution {
public int kthGrammar(int N, int K) {
if (N == 1)
return 0;
StringBuilder sBuilder = new StringBuilder();
sBuilder.append("01");
for (int i = 2; i < N; i++) {
int len = sBuilder.length();
for (int j = len >> 1; j < len; j++) {
sBuilder.append(sBuilder.charAt(j));
sBuilder.append(1 - Integer.parseInt(sBuilder.charAt(j) + ""));
}
}
return Integer.parseInt(sBuilder.charAt(K - 1) + "");
}
}

时间复杂度：O(2^N),因为没一行都是前一行的2倍
空间复杂度：O(2^N)


居然上一种暴力破解超出时间限制，那就尝试优化时间复杂度
认真分析一下其实是有规律的
N ------ 字符串
1 ------ 0
2 ------ 01
3 ------ 0110
4 ------ 01101001
5 ------ 0110100110010110
6 ------ 01101001100101101001011001101001

每一行的前一半的字符串都等于上一行，后一半中的前一半等于上一行的后一半，后一半中的后一半等于前一行的后一半

如第3行和第4行
![44cbc650c91608711787d68069b2047.jpg](https://pic.leetcode.cn/1966d3dd2820b1f221dfed1f13373100318fb7e650e8274ebd0e39610c153c9a-44cbc650c91608711787d68069b2047.jpg)
```java []
class Solution {
    public int kthGrammar(int N, int K) {
        if (N == 1)
            return 0;
        StringBuilder sBuilder = new StringBuilder();
        sBuilder.append("01");
        for (int i = 2; i < N; i++) {
            String hou = sBuilder.toString().substring(sBuilder.length() / 2);
            String qian = sBuilder.toString().substring(0, sBuilder.length() / 2);
            sBuilder.append(hou).append(qian);
        }
        return Integer.parseInt(sBuilder.charAt(K - 1) + "");
    }
}

时间复杂度：O(N)
空间复杂度：O(2^N)
很显然这样是优化了时间复杂度，但还存在一个bug就是超出内存限制，所以我们还得寻找更优懂得算法；

二、递归
经过前面两种算法我们很清楚，有些事用暴力是解决不了问题的，所以我们不在这钻牛角尖了
只好再去分析是否有其他奇妙之处

每一行都是上一行的2倍，0转为01，1转为10，这不就是完全二叉树嘛

需要查找那位字符就去寻找他的根，但不需要特意去创建一个二叉树，只需要使用递归到第一行（0），开始不断返回，还需要判断是左子树还是右子树，通过判断奇偶来就是，奇为左，偶为右。

java [] class Solution { public int kthGrammar(int N, int K) { //已知条件N=1时为0 if (N == 1) return 0; //寻找上一行的根，因为一位字符可以生成两位数，使用每一行的字符都是上一行的(K + 1)/2位生成的 int i = kthGrammar(N - 1, (K + 1) >> 1); if (i == 0) //0转为01 return (K & 1) == 0 ? 1 : 0;//判断K的奇偶 else //0转为10 return (K & 1) == 0 ? 0 : 1;//判断K的奇偶 //return (~K & 1) ^ kthGrammar(N - 1, (K + 1) / 2);可以直接采用位运算计算 } }
时间复杂度：O（N）
空间复杂度：O（1）
