Reverse Nodes in k-Group 🚦 Optimal Implementation in Swift
👤 lebon 👍 0 2024-05-08 🖼 ↗ 查看原 Solution

Intuition

The problem involves reversing every group of k nodes in a given linked list. We'll approach this by iterating through the list and using a helper function to reverse each group of k nodes. By maintaining pointers to the head (curHead) and tail (curTail) of each group, we can connect the reversed groups to form the final modified linked list.

Approach

  1. Edge Case Handling: Check if head is nil or if k is less than or equal to 1. If true, return head as it is.
  2. Initialization: Create a dummy node to serve as the previous tail (preTail). Set curHead and curTail to the start of the list (head).
  3. Iteration: Traverse the linked list using curHead. For each iteration:
    - Check if there are at least k nodes remaining to reverse.
    - If fewer than k nodes remain, break out of the loop.
    - Identify the nextHead for the next iteration.
    - Reverse the current group of k nodes using the reverse helper function.
    - Connect the previous tail (preTail) to the new head of the reversed group.
    - Connect the end of the reversed group (curTail) to nextHead.
    - Update pointers (preTail, curHead, curTail) for the next iteration.
  4. Return: Return the modified linked list starting from dummy.next.

The reverse function takes a head node and reverses the first k nodes in the linked list. It uses an iterative approach by manipulating pointers (preNode, curNode, nextNode) to reverse the nodes in-place.

Complexity

  • Time complexity: O(n), where n is the number of nodes in the linked list. We traverse each node at most twice (once for reversal and once for traversal), resulting in a linear time complexity.
  • Space complexity: O(1), as we use only a constant amount of extra space regardless of the size of the input linked list. We modify the list in-place without additional data structures, using a few pointers for traversal and reversal.

/*
* Definition for singly-linked list.
* public class ListNode {
* public var val: Int
* public var next: ListNode?
* public init() { self.val = 0; self.next = nil; }
* public init( val: Int) { self.val = val; self.next = nil; }
* public init( val: Int, _ next: ListNode?) { self.val = val; self.next = next; }
* }
/

class Solution {
func reverseKGroup(_ head: ListNode?, _ k: Int) -> ListNode? {
// Edge case: if head is nil or k is less than or equal to 1, return head as is
guard let head = head, k > 1 else {
return head
}

    // Create a dummy node to serve as the previous tail
    let dummy = ListNode(0)
    dummy.next = head
    var preTail: ListNode? = dummy

    var curHead: ListNode? = head
    var curTail: ListNode? = head

    var nextHead: ListNode? = nil

    while curHead != nil {
        // Check if there are at least k nodes remaining to reverse
        var count = 0
        var temp: ListNode? = curHead
        while temp != nil && count < k {
            temp = temp?.next
            count += 1
        }

        // If there are less than k nodes remaining, break the loop
        if count < k {
            break
        }

        // Store the next head for the next iteration
        nextHead = temp

        // Reverse the current group of k nodes
        let newHead = reverse(curHead, k)

        // Connect the previous tail to the new head of the reversed group
        preTail?.next = newHead

        // Connect the end of the reversed group to the next head
        curTail?.next = nextHead

        // Update pointers for the next iteration
        preTail = curTail
        curHead = nextHead
        curTail = nextHead
    }

    return dummy.next
}

private func reverse(_ head: ListNode?, _ k: Int) -> ListNode? {
    var preNode: ListNode? = nil
    var curNode: ListNode? = head
    var nextNode: ListNode? = nil
    var count = 0

    // Reverse the first k nodes in the group
    while curNode != nil && count < k {
        nextNode = curNode?.next
        curNode?.next = preNode
        preNode = curNode
        curNode = nextNode
        count += 1
    }

    return preNode
}

}
