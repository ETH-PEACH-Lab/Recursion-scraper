思路一

  1. 中心思想：先求出player1的最大分数socre1，然后用总分减去socre1就是player2的分数score2，最后比较两个分数即可。

  2. 如何求出score1呢？player1有两个选择，要么选择nums[L]，要么选择nums[R]，然后在player2也选完后的剩下区间里继续选.

  3. 这明显是个递归的问题，那么就明确递归的要素

    • 递归函数的目标是什么（或者说返回是什么）？求出（返回）player1能获得的最大分数socre1.
    • 递归函数的参数是什么？剩余可选择的区间。
    • 递归的出口是什么？当没有数可以选时，返回0分；只有1个数可选时，只能选它。
    • 递归下去能到出口吗？可以，因为每次选择都会少一个数，区间减小，必然能到出口。

  4. 定义递归函数recur(L, R)，返回player1在区间[L, R]中能获得的最大分数。

recur(L, R) =
\begin{cases}
0, & ext{if L > R} \
nums[L] & ext{if L = R} \
max {nums[L] + max {recur(L + 2, R), recur(L + 1, R - 1) } \
\space \space \space \space \space \space \space \space \space \space
nums[R] + max {recur(L + 2, R), recur(L + 1, R - 1) }} & ext {if L < R}
\end{cases}

代码

public boolean PredictTheWinner(int[] nums) {
        int size = nums.length;
        if (size <= 2) {
            return true;
        }
        int player1 = getMaxScore(nums, 0, size - 1);   
        int sum = 0;
        for (int i = 0; i < size; i++) {
            sum += nums[i];
        }
        int player2 = sum - player1;
        return (player1 >= player2) ? true : false;
    }

    public int getMaxScore(int[] nums, int L, int R) {
        if (L > R) {
            return 0;
        }
        int selectLeft = 0, selectRight = 0;
        if (L == R) {
            return nums[L];
        }
        selectLeft = nums[L] + Math.min(getMaxScore(nums, L + 2, R), getMaxScore(nums, L + 1, R - 1));
        selectRight = nums[R] + Math.min(getMaxScore(nums, L + 1, R - 1), getMaxScore(nums, L, R - 2));
        return Math.max(selectLeft, selectRight);
    }
}

算法分析

每一次选择都产生两个子问题，时间和空间复杂度都是以2为底的指数级的。
可以自行改为备忘录式递归。

思路二

  1. 中心思想：零和博弈问题。由于总分不变，一个玩家的分越高，另一个玩家的分就越低。

  2. 先手优势和后手劣势：先手玩家可以选择最优分数导致后手玩家陷入更差的局面。虽然后手玩家也会在最差的局面中尽可能地选择最优以便给先手玩家留下更差的局面，但是先手的人已经决定了整个游戏的走势。

  3. 如果我们取后手玩家得到的两个结果中较小的那个，那么用总分减去这个结果不就是先手玩家的最大结果吗

基础代码

class Solution {

    public boolean PredictTheWinner(int[] nums) {
        int size = nums.length;
        if (size <= 2) {    // 元素个数不超过2，由于元素都非负，玩家1必胜
            return true;
        }
        int score1 = getMaxScore(nums, 0, size - 1);
        int score2 = sumFromLR(nums, 0, size - 1) - score1;
        return score1 >= score2 ? true : false;
    }

    public int getMaxScore(int[] nums, int L, int R) {
        if (L == R) {
            return nums[L];
        }
        int optimal = sumFromLR(nums, L, R) - Math.min(getMaxScore(nums, L + 1, R), getMaxScore(nums, L, R - 1));
        return optimal;
    }

    public int sumFromLR(int[] nums, int L, int R) {
        int sum = 0;
        for (int i = L; i <= R; i++) {
            sum += nums[i];
        }
        return sum;
    }
}

思路三

  1. 中心思想：不求总得分，直接求两个玩家之间的最大分差。

  2. player1的两个选择，最终对应两个分差。

  3. 定义递归函数的返回为两个玩家的最大分差。

代码

class Solution {

    public boolean PredictTheWinner(int[] nums) {
        int size = nums.length;
        if (size <= 2) {
            return true;
        }
        return getMaxDifference(nums, 0, size - 1) >= 0 ? true : false;
    }

    public int getMaxDifference(int[] nums, int L, int R) {
        if (L == R) {
            return nums[L];
        }
        // 由于先手getMaxDifference(nums, L, R)是player1比player2多的分
        // 那么getMaxDifference(nums, L + 1, R)是player2比player1多的分
        int selectLeft = nums[L] - getMaxDifference(nums, L + 1, R);
        int selectRight = nums[R] - getMaxDifference(nums, L, R - 1);
        return Math.max(selectLeft, selectRight);
    }
}

            return true;
        }

                record[i][j] = -1;
            }

        if (L == R) {
            return nums[L];

            return record[L][R];

动态规划版本

class Solution {
    public boolean PredictTheWinner(int[] nums) {
        int size = nums.length;
        /*if (size <= 2) {    // 元素个数不超过2，由于元素都非负，玩家1必胜
            return true;
        }*/
        // 初始化
        int[][] dp = new int[20][20];
        for (int i = 0; i < size; i++) {
            dp[i][i] = nums[i];
        }
        // 填表
        for (int i = size - 2; i >= 0; i--) {
            for (int j = i + 1; j < size; j++) {
                dp[i][j] = Math.max(nums[i] - dp[i + 1][j], nums[j] - dp[i][j - 1]);
            }
        }
        // 根据dp数组定义，应该根据该值判断是否能赢
        return dp[0][size - 1] >= 0 ? true : false;
    }
}
