突破点

二叉搜索树的特点之一：中序遍历是单调递增（升序）

解题

先看一下一颗二叉树：

     根
    /  \
   左   右

中序遍历：左->根->右
后序遍历：左->右->根

解法1 递归

只要是二叉搜索树就一定就满足：
左 < 根 && 右 > 根

在后序遍历也是要满足该特性。那么只要在 后序遍历 中找到对应的 根 左 右 三个节点来对比是否满足就行。

如：

          10
        /    \
       8     12
      / \    / \
     5   9  11  13
    / \
   3   6

中序遍历： [3,6,5,9,8,11,13,12,10]
           \______/  \____/   |
              左        右    根

如果 左 < 根 && 右 > 根 成立。那么就有：
1. 左集里面的每一个节点值都 小于 根
2. 右集里面的每一个节点值都 大于 根

伪代码：

    bool helpe(postorder, 左边界, 右边界) {
        if (左边界 >= 右边界) return true;
        root    // 找到 根
        leftSet // 找到 左集
        rightSet // 找到 右集
        for (leftSet里面的每一个节点) { // 比较 左集 的每一值是否都 小于 根
            if (每一个节点都 > 根) return false;
        }
        for (rightSet里面的每一个节点) { // 比较 右集 的每一值是否都 大于 根
            if (每一个节点都 < 根) return false;
        }
        // 递归比较 左集/右集 里面的子集是否都满足
        return helpe(leftSet, lefSet的左边界, leftSet的右边界) &&
            helpe(rightSet, rightSet的左边界, rightSet的右边界)
    }

先看一下代码：
```C++ [group1-C++ 递归]
class Solution {
public:
bool verifyPostorder(vector& postorder) {
return helpe(postorder, 0, postorder.size() - 1);
}

private:
bool helpe(vector &postorder, int l, int r) {
if (l >= r) return true;
int p = l, m = 0;
while (postorder[p] < postorder[r]) ++p;
m = p; // 切割点
while (postorder[p] > postorder[r]) ++p;
return p == r && helpe(postorder, l, m - 1) &&
helpe(postorder, m, r - 1);
}
};


代码处理逻辑：
1. 找根节点
在后续遍历中，最后一个节点一定是 **根节点**。
2. 找左/右集
在剩下的数组中，我们使用指针，在从头开始查找到 **第一个大于根**  的位置来做 左/右集的**切割点**。
3. 递归判断 左/右集的子集

## 解法2 迭代

在二叉搜索树中，通过我们的观察发现，如图：
![image.png](https://pic.leetcode.cn/1634709136-UexLuN-image.png)
**红色**的部分，总是 `根 < 右` 成立。

那么能用这个逻辑遍历完 二叉搜索树 么？
是可以的，如图：
![image.png](https://pic.leetcode.cn/1634709311-QeWBFM-image.png)

从上到下，**红色括号**的部分都是 **单调递增**。


> 再来看一下题目给出来信息：**后序遍历数组**
> 也就是顺序：左->右->根
> 
> 而通过上面的2张图，我们观察到的 **单调递增** 的顺序是：`根->右`
> 而通过 **移动** `左` 会变成 `根`。所以我们最终的遍历顺序是：
> 根->右->左
> 
> 刚好是 中序遍历 的 **逆序**。

那么，我们逆序遍历，找到里面的单调递增的部分，通过**递增来判断**是否是二叉搜索树。

这里我们使用 **单调栈** 来装 逆序的节点。
会有2个状态需要我们理解和处理的：
1. 当前节点比栈顶节点 **大** 。说明还是在 根->右 的逻辑范围（递增），我们需要继续 **压栈**。
2. 当前节点比栈顶节点 **小** 。说明一边的**递增逻辑**已经遍历完，我们需要**向左移动**，**切换遍历节点**，继续进行递增逻辑。不过在这之前，我们需要清除上一次**递增逻辑**留下来的节点，所以我们需要把 **大于** 当前节点的值 **出栈**。

代码：
```C++ [group2-C++ 迭代]
class Solution {
public:
    bool verifyPostorder(vector<int>& postorder) {
        vector<int> sub;
        int root = INT_MAX;
        for (auto i = postorder.rbegin(); i < postorder.rend(); ++i) { // 中序的逆序遍历
            if (*i > root) return false;
            while (sub.size() && *i < sub.back()) // 切换遍历节点，清除上次遍历数据，出栈
                root = sub.back(), sub.pop_back();
            sub.push_back(*i); // 单调递增逻辑，压栈
        }
        return true;
    }
};
