Intuition

The problem requires converting an integer into its English word representation. The approach should account for various ranges like units, tens, hundreds, thousands, millions, and billions. The solution must recursively break down the number into smaller parts and concatenate their English equivalents.

Approach

  • Define Arrays for Words: Use arrays for words representing numbers less than 20, multiples of ten (like twenty, thirty), and large values (thousand, million, billion).
  • Helper Method (Find): This method recursively handles numbers less than 1000:
  • For numbers less than 20, return the corresponding word directly from the array.

* NOTE - n / 10 gives the integer part of dividing n by 10. This value represents the tens digit of the number.

For example, if n = 43, n / 10 is 4.

* NOTE - n % 10 gives the remainder when n is divided by 10. This value represents the ones digit of the number.

For example where n = 43, n % 10 is 3
* For numbers less than 100, break them into tens and units.
* For numbers less than 1000, break them into hundreds and the remaining part.
* Main Method (numberToWords): This method handles the entire number:
* If the number is zero, return "Zero".
* Loop through the number in chunks of 1000, and for each chunk, use the helper method to convert and concatenate the appropriate word for thousands, millions, etc.
* Trim any extra spaces before returning the final result.

Complexity

  • Time complexity:
    (log 1000())O(log 1000(n)) because the number is processed in chunks of 1000. In the worst case, the time complexity can be approximated as O(log 10(n)).
  • Space complexity:
    O(1) since no additional space proportional to the input size is used beyond constant space.

class Solution {

String [] lessThan_20 = {"", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"};
String [] Tens = {"", "Ten", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"};
String [] Thousand = {"", "Thousand", "Million", "Billion"};

public String Find(int num) {
    if(num == 0){
        return "";
    }
    if (num < 20){
        return lessThan_20[num] + " ";
    }
    else if (num < 100){
        return Tens[num/10] + " " + Find(num % 10); 
    }
    else {        
        return lessThan_20[num/100] + " Hundred " + Find(num % 100);
    }
}

public String numberToWords(int num){
    if(num == 0){
        return "Zero";
    }
    String word = "";
    int count = 0;

    while(num > 0){
        if(num % 1000 != 0){
            word = Find(num % 1000) + Thousand[count] + " " + word;
        }
        num = num / 1000;
        count++;
    }
    return word.trim();
}

}
