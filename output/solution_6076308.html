Intution:

First let us understand the question in depth, As per the que, we need to reverse the linked list, but not completely instead just the particular number of consecutive sequence of k number of elements in the linked list.Then leave the elements untouched that are not present in K-number groups.

Subdiving the problem

so my first intution was like to reverse the linked list, but each part seperately, As we all know how to reverse a linked list, (if not pls just have a look, it merely takes 5 to 10 mins max), so we can count the number of segments and reverse then seperately then linking back again to form a linked list.

Approach

My approach was first to calculate the number of subdivisions with k elements that i can seperate, like literally counting number of k element groups.

This is done by diving the number of elements by the k value given.(counting the number of elements is done by traversing completely thro the linked list).

then i have made a helper function solver, that recursively reverses and links to for a complete linked list.

In this helper function to only reverse k number of groups i have set the base case as

if(it==0){return head;}

This return the head if the segment values decreased to zero du to recursive calling.

The arguments sent are head,segments count,k-value.

ListNode* solver(ListNode* head,int it,int  k)

Here like we do in normal linked list reversal, we have previous,next and current variables initilased with nullptr for prev and nxt and head for cur variable.

now in a forloop i reverse the linked list upto k elements

for(int i=1;i<=k;i++){
            nxt=cur->next;
            cur->next=prev;
            prev=cur;
            cur=nxt;
        }

as the reversed list will be present in prev variable as we need to add i.e link the remaining elements to the end of this reversed k elements, using while loop iam traversing to the edge of the prev variable value;

after this iam recursively calling the function by assigning the value returned by the recursive call in this way i can link my just reversed linked list with the other linked lists too

This is done by 

_->next=solver(nxt,it-1,k);

As u see the other reversed values returned by the recursive calls are returned and linked.

Dry-Run:

Eg:
1 -> 2 -> 3 -> 4 -> 5
k=2
Main Function call

prev = 2 -> 1 -> nullptr
nxt = 3 -> 4 -> 5 -> nullptr

_ -> next i.e 1 -> next = solver(nxt,it-1,k)

1st Recursive Call

prev = 4 -> 3 -> nullptr
nxt = 5 -> nullptr

_ -> next i.e 3 -> next = solver(nxt,it-1,k)

2nd Recursive Call

will return the head
5 -> nullptr

as the it value i.e the segments value has reached 0!

Backtracking

2nd to 1st Recursive call

3 -> next = 5 -> nullptr

that makes

4 -> 3 -> 5 -> nullptr

prev variable holds these values as _ -> next here _ is ntng but a reference of the prev variable.

so at last return the prev variable.

Main function call

as _ -> next was waiting for the recursive functions to return the other values, it gets the values as
4 -> 3 -> 5 -> nullptr

this will be linked with the first reversesd K-valued group which then transoforms into

2 -> 1 -> 4 -> 3 -> 5 -> nullptr

As we see the desired output is attained! now we can return the prev variable!✨

Complexity

  • Time complexity:
    Time complexity for this is O(N), As we know N is the input size...
  • Space complexity:
    Actual Space complexity is O(N/K) as recursion stack involves but almost this is under O(1)

Code

```cpp []
/
* Definition for singly-linked list.
* struct ListNode {
* int val;
* ListNode next;
* ListNode() : val(0), next(nullptr) {}
* ListNode(int x) : val(x), next(nullptr) {}
* ListNode(int x, ListNode next) : val(x), next(next) {}
* };
/
class Solution {
public:
ListNode reverseKGroup(ListNode head, int k) {
ios::sync_with_stdio(false);
cin.tie(nullptr);
ListNode cur=head;
int seg=0;
while(cur){
seg++;
cur=cur->next;
}
seg=(seg/k);
return solver(head,seg,k);
}
ListNode solver(ListNode head,int it,int k){
if(it==0){return head;}

    ListNode* prev=nullptr;
    ListNode* nxt=nullptr;
    ListNode* cur=head;

    for(int i=1;i<=k;i++){
        nxt=cur->next;
        cur->next=prev;
        prev=cur;
        cur=nxt;
    }
    ListNode* _=prev;
    while(_->next){
        _=_->next;
    }

    _->next=solver(nxt,it-1,k);
    return prev;
}

};
```
