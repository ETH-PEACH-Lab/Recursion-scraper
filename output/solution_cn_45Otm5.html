解题思路

实际上，如果读者对于笔者在【LeetCode 单链表专项】两两交换链表中的节点（24）中给出的递归解法分析也有所体会的话，本题使用递归解法也很简单。

如笔者在上述博文中所述：在使用递归解法时，只需要假定更深层的递归都已经成功返回，只关注当前递归所在层所要做的事情即可。对于本题，只要假定除了第一组 k 个元素没有反转，而后续所有可以 k 个一组进行反转的节点都已经完成了翻转，因此问题就简化为了给定 k + 1 个节点，要求翻转前 k 个节点。

对于反转前 k 个节点的操作，这里可以复用【LeetCode 单链表专项】反转链表（206）中的解答，即下列实现中的 _reverse_list() 方法。

下面通过给定 k = 3 作为示例，图解如果通过递归进行实现：

截至目前，我们还没有指明递归的出口是什么？实际上，根据题目的要求即如果节点总数不是 k 的整数倍，那么请将最后剩余的节点保持原有顺序这一点，也很容易知道如果当前层的递归时发现剩余节点数量小于 k ，则直接返回当前层的输入头节点。

代码

# Definition for singly-linked list.
# class ListNode:
#     def __init__(self, val=0, next=None):
#         self.val = val
#         self.next = next
class Solution:
    def _reverse_list(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head
        predecessor, current = None, head
        while current:
            successor = current.next
            current.next = predecessor
            predecessor = current
            current = successor
        return predecessor

    def reverseKGroup(self, head: Optional[ListNode], k: int) -> Optional[ListNode]:
        cursor = head
        for _ in range(k):
            if cursor:
                cursor = cursor.next
            else:
                return head
        prev, current = None, head
        for _ in range(k):
            prev = current
            current = current.next
        prev.next = None
        rev_head = self._reverse_list(head)
        head.next = self.reverseKGroup(current, k)
        return rev_head
