题目：

    将两个升序链表合并为一个新的 升序 链表并返回。新链表是通过拼接给定的两个链表的所有节点组成的。
示例1：

输入：l1 = [1,2,4], l2 = [1,3,4]
输出：[1,1,2,3,4,4]

示例2：

输入：l1 = [], l2 = []
输出：[]

示例3：

输入：l1 = [], l2 = [0]
输出：[0]

解题思路

    初学者请注意：凡是涉及链表的操作，一定要在纸上画图，先把过程画下来，写程序才能顺畅，空想很容易暴毙。

方法一：迭代，简单双指针
    1.由于我们不知道l1,l2两链表谁的头结点值更小，所以我们需要使用虚拟头结点ans，
使用ans->next返回拼接好的新链表的头结点，并用cur=ans备份虚拟头结点，利用cur进行链表拼接。
    2.不断判断l1->val和l2->val的值，将cur->next指向更小的链表指针。并且让cur和更小的链表向后遍历一个结点。
    3.不断判断直至一边判断为空（NULL），此时将cur和另一边不为空的链表拼接起来。

代码

class Solution {
public:
    ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
        ListNode* ans=new ListNode(0);
        ListNode* cur=ans;
        while(l1&&l2)
        {
            if(l1->val<=l2->val)
            {
                cur->next=l1;
                cur=cur->next;
                l1=l1->next;
            }
            else{
                cur->next=l2;
                cur=cur->next;
                l2=l2->next;
            }
        }
        if(l1==nullptr)
            cur->next=l2;
        else cur->next=l1;
        return ans->next;
    }
};

方法二：递归
    本题可以通过递归，使得我们不需要建立新的虚拟头结点。
    既然要使用递归，就要将递归的三要素弄清楚，才能写。
    1.返回，每一层都返回排序好的头结点。
    2.终止条件：与方法一相同，如果l1或l2空时，返回，由1，当一条链表空时，返回另一链表的头结点。
    3.递归内容，如果l1->val相对更小，则将l1与排序好的链表相接，并继续判断l1->next和l2的val值大小
递归算法的图解，将在之后更新上来。

代码

class Solution {
public:
    ListNode* mergeTwoLists(ListNode* l1, ListNode* l2) {
        if(!l1)
            return l2;
        if(!l2)
            return l1;
        if(l1->val<l2->val)
        {
            l1->next=mergeTwoLists(l1->next,l2);
            return l1;
        }
        else{
            l2->next=mergeTwoLists(l1,l2->next);
            return l2;
        }
    }
};

算法复杂度：
    由于构建新链表需要将两链表基本都遍历一边，时间复杂度O(m+n)，空间复杂度O(1)；
