递归求解1~n整数中1出现的个数

本题想了好久，说下过程
1、首先看到说1的个数，想到了采用二进制去求解，无果。
2、去拆解整数，当时n的话，怎么拆计算比较好，比如我是90，怎么拆，把控不准。
参考各路大神的题解，其中K神的就不多说了，那种规律老实讲，下次遇到我可能还是推不出来，那就罢了罢了。
参考xujunyi童鞋的，发现他的思路比较符合人的思维，可以考虑。

推导数据：

n=1024:   int pow=1000; int last=n-pow=1024-1000=24;
    0~999       f(999)=f(pow-1) 
    1000~1024   24+1+f(24)= last+1+f(last);
    总计：f(pow-1)+last+1+f(last);

n=2024:   int pow=1000; int last=n-pow=2024-1000*2=24;
    0~999      f(999)=f(pow-1) 
    1000~1999  (1999-1000+1)+f(999)=pow+f(pow-1);
    2000~2024  f(last)
    总计：f(pow-1)*2+pow+f(last);

n=3024:   int pow=1000; int last=n-pow=3024-1000*3=24;
    0~999      f(999)=f(pow-1) 
    1000~1999  (1999-1000+1)+f(999)=pow+f(pow-1);
    2000~2999  f(999)=f(pow-1) 
    3000~3024   f(24);
    总计：f(pow-1)*3+pow+f(last);

递归每层的逻辑：high是最高的值

if(high==1){
    return f(pow-1)+last+1+f(last);
}else{
    return f(pow-1)*high+pow+f(last);
}

递归条件：

n<=0 return 0;
n<9  return 1;
n=9  1的个数是1；
n=99 1的个数是20；
n=999 1的个数是300；
假设num为n的位数，只要n的值等于 num*(Math.pow(10,num)；

递归的参数和返回值：
参数每次都是缩小规模的last或者pow-1，返回值就是我们要求的1的个数值。

完整代码:

class Solution {
   public  int countDigitOne(int n) {
          //计算是几位数
        int num = 0;
        int k = n;
        while (k != 0) {
            num++;
            k /= 10;
        }
        if (n <= 0) return 0;
        if (n <= 9) return 1;
        //n=9 则1的个数是1
        //n=99 则1的个数是20
        //n=999 则1的个数是300
        if (n == (Math.pow(10, num) - 1)) {
            return num * (int) (Math.pow(10, num - 1));
        }
        int pow = (int) (Math.pow(10, num - 1));
        int high = n / pow;
        int last = n - high * pow;
        if (high == 1) {
            return countDigitOne(pow - 1) + last + 1 + countDigitOne(last);
        } else {
            return countDigitOne(pow - 1) * high + pow + countDigitOne(last);
        }
    }
}
