Problem: 面试题 08.06. 汉诺塔问题

[TOC]

思路

一个非常经典的分治问题
首先思考几个简单的问题
1.如果A上只有一个圆盘该怎么移动？
2.如果A上有两个圆盘该怎么移动?
3.如果A上有三个圆盘该怎么移动？
这三个问题都是非常易解的
1 -> 直接移动到C柱
2 -> 先将A顶部的一块移动到B,再将底部最大的移动到C，最后把B上的圆盘移动到C
3 -> 先将A底部上的两块移动到B,再将A剩下的一块移动到C，最后把B上的两快圆盘移动到C

那么对于n个圆盘呢？
我们试着从上面的简单案例得出解
1. -> 先将A顶部的 n - 1个圆盘移动到B (借助C)
2. -> 再将A剩下的一个圆盘移动到C
3. -> 最后将B上的n - 1个圆盘移动到C (借助A)
至此,n个圆盘的解已经得到了,跟着思路写代码便是一个很简单的过程了

答疑

也许你在思考,如何把A上的i - 1个圆盘移动到C?
当你在思考这个问题的时候,这就已经是答案了,你在思考i - 1个圆盘的时候
接踵而至的是 i - 2 , i - 3... 直到1,我们始终在重复这个过程。
这就是分治的一种思想,你在思考如何将 i - 1个圆盘移动的时候 ,自然就会先想到
i - 2。至于如何移动盘子,那不是我们所关心的问题,我们需要的是分割问题,将它分解成多个子问题。再到子问题中寻求最终解。

时间复杂度及其空间复杂度分析

时间复杂度 -> 在汉诺塔问题中,时间复杂度是非常高的,我们每开启一个子问题都会会开启另外两个子问题(移动的操作为常数级,不计),那么时间复杂度是2的n次方
空间复杂度 -> 对于n个圆盘,我们在递归的过程中会开启一颗高度为n的递归树
所以空间复杂度是n
附上递归树的图片(手画有点潦草)

复杂度

时间复杂度:

$O(2^n)$

空间复杂度:

$O(n)$

```Java []
class Solution {
public void hanota(List A, List B, List C) {
DFS(A.size(), A, B, C);
}
// move -> 移动圆盘
void move(List A, List C) {
// 从A栈顶取出
Integer temp = A.remove(A.size() - 1);
// 放入C栈顶
C.add(temp);
}
// 分解子问题 f(n) -> f(1) + f(n - 1) + f(n - 1)
void DFS(int i, List A, List B, List C) {
// 如果A只剩一个圆盘 -> 直接移动到C
if (i == 1) {
move(A,C);
return;
}
// 子问题1 -> 将A顶部i - 1个圆盘移动到B
DFS(i - 1, A, C, B);
// 子问题2 -> 将A剩下的1个圆盘移动到C
move(A,C);
// 子问题3 -> 将B顶部i - 1个圆盘移动到C
DFS(i - 1,B, A, C);
}
}


```python3 []
class Solution:
    def hanota(self, A: List[int], B: List[int], C: List[int]) -> None:
        """
        Do not return anything, modify C in-place instead.
        """
        self.DFS(len(A), A, B, C)
    # 将A栈顶元素移动到C
    def move(self, A: List[int], C:List[int]) -> None:
        # 取出
        temp = A.pop()
        # 入C栈
        C.append(temp)
    def DFS(self, i: int, A: List[int], B: List[int], C: List[int]) -> None:
        if i == 1:
            self.move(A, C)
            return
        # 子问题1 -> 将A顶部 i - 1个圆盘移动到B(C为缓冲柱,B为目标柱)
        self.DFS(i - 1, A, C, B)
        # 子问题2 -> 将A剩下的1个圆盘移动到C
        self.move(A, C)
        # 子问题3 -> 将B顶部的 i - 1个圆盘移动到C(A为缓冲柱,C为目标柱)
        self.DFS(i - 1,B, A, C)
