206. 反转链表
👤 Dine 👍 5 2021-03-09 🖼🎞 Slide ↗ 查看原 Solution

解题思路

题目要求反转一个单链表，可以通过迭代和递归方法去做。

方法一：迭代

以链表 1->2->3 为栗，如下图示：

反转前

反转后

如上图示，要实现链表中 1->2 之间反转，需要先保存值为 3 的节点（设置一个指针 next），否则将值为 2 的节点指向值为 1 的节点后（反转 1->2），值为 2 的节点和值为 3 的节点之间的链接就断开了，后面就无法实现 2->3 之间的反转了。

同时，要想实现 1->2 之间反转，需要两个指针分别指向它们，当然其中一个也可以直接用头节点指针。

因此，需要设置两个指针:
1. pre（初值设置为空）：记录当前节点反转时被指向的那个节点。

  1. next（初值设置头节点的下一节点）：记录当前节点反转前，其下一节点。

如下图示：

head 指针不断右移（直到其指向尾节点的下一节点），同时 next 指针记录 head 节点反转前其下一节点，将 head 指针指向 pre 指针，实现 next 指针前面的子链表的反转。

head->next = pre head 指向的节点指向 pre 指向的节点，断开 1->2 之间的连接，让值为 1 的节点成为尾节点

pre、head 和 next 指针右移，用于遍历以及后续反转



head 指向的节点指向 pre 指向的节点，实现 1->2 之间的反转，同时断开 2->3 之间的连接

pre、head 和 next 指针继续右移，用于遍历以及后续反转



head 指向的节点指向 pre 指向的节点，实现 2->3 之间的反转

head 指针继续右移，用于遍历

遍历完成，链表完成反转

Show me the Code

```c++ []
class Solution {
public:
ListNode reverseList(ListNode head) {
ListNode pre = nullptr;
while (head) {
ListNode next = head->next;
head->next = pre;
pre = head;
head = next;
}
return pre;
}
};

```java []
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode cur = head;
        ListNode pre = null;
        while (null != cur) {
            ListNode next = cur.next;
            cur.next = pre;
            pre = cur;
            cur = next;
        }
        return pre;
    }
}

复杂度分析

时间复杂度：O(n)，其中 n 为链表的长度，需要遍历一遍数组；

空间复杂度：O(1)，未开辟额外存储空间；

方法二：递归

还是以链表 1->2->3 为栗，如下图示：

可以把链表 1->2->3 看成值为 1 的头节点后面挂接一个更短的链表，这个更短的链表就是 2->3，同理，这个更短的链表 2->3 也可以看出是值为 2 的头节点后面挂接一个更更短的链表，这个更更短的链表就是值为 3 的节点。如下图示：

因此，可以先反转更短（更更短）的链表

再将原链表的头节点挂接在已反转的更短（更更短）的链表的尾节点后面，这样就实现了链表的反转。

示例

以链表 1->2->3->null 为例子，其递归反转过程如下动图示：

```c++ []
class Solution {
public:
ListNode reverseList(ListNode head) {
/ 递归终止条件 /
if (!head || !head->next) {
return head;
}

    /* 反转当前节点后面的更短（更更短）的链表 */
    ListNode* pHead  = reverseList(head->next);
    /* 原链表的第二个节点（head->next）现链表的尾节点后面挂接原链表的头节点*/
    head->next->next = head;
    /* 原链表头节点指向空 */
    head->next = nullptr;
    return pHead;
}

};

```java []
class Solution {
    public ListNode reverseList(ListNode head) {
        if (null == head || null == head.next) {
            return head;
        }

        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}
