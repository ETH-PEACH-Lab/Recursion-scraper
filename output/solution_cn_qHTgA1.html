Problem: 273. 整数转换英文表示

思路

核心思路就是“先算数，最后加单位”，跟我们上学老师教的方法是一样的

1、准备基础数据：

定义基本的单词表示，包括个位数（如 "One" 到 "Nine"）、十几（如 "Ten" 到 "Nineteen"）、
整十数（如 "Twenty" 到 "Ninety"）和大数单位（如 "Hundred", "Thousand", "Million", "Billion"）。
处理特殊情况：

2、对于个位和十位数，直接利用预定义的数组进行转换。
如果数字是0，直接返回 "Zero"。
递归处理大数：

3、对于百位及以上的数，通过递归将数字按三位一组分割，从最低位开始处理。
在每个递归层次，处理当前三位数，并根据递归的深度添加相应的大数单位（如 "Thousand", "Million", "Billion" 等）。
辅助函数处理十位数：

4、单独定义一个辅助函数来处理十位数，特别是十几的特殊情况。
对于20及以上的整十数，通过组合对应的整十和个位的单词来表示。
结果字符串的清理：

5、使用字符串操作方法链，移除多余的连接词（如 "And"）和不必要的字符（如 "-"），并确保单词之间的空格处理正确。
整合并返回结果：

递归处理所有三位组后，将结果整合成一个完整的英文单词字符串。
返回最终的结果字符串。

解题方法

base_bigs = ["Hundred", "Thousand", "Million", "Billion"]
英语数词中只有：
10^3 (千): Thousand
10^6 (百万): Million
10^9 (十亿): Billion
10^12 (万亿): Trillion

因为英语中是每三位数就进行单位的改变，所有解决方法是：
    三位数三位数的拆分，先解决掉当前的三位数，然后进行递归解决下一个三位数，
    单位也需要随之前进（base_bigs）第一个三位是 Hundred、
    第二个是 Thousand.....(小学知识不赘述了)

知识扩展

英文数词规律：
    从右到左，每三位一组。
    确定每组对应的数词单位。
    逐组转化为英文。
    从大到小组合成最终表达。

英文数词规律：
    规律一：每三级（即每增加三个零）换一个单位，单位依次为 thousand, million, billion, trillion。
    规律二：大数词通过组合基数词和单位构成，先大单位后小单位。
    规律三：大数词内部按顺序表示千位、百位、十位和个位。
        例如 123,456,789 是 “one hundred twenty-three million four hundred fifty-six thousand seven hundred eighty-nine”。
    这样每个单位的增加都是三个数量级的增加，形成了一个规律性的模式。这就是英语中数词的基本规律。

class Solution:
def numberToWords(self, num: int) -> str:
# single digit
base_singles = ["", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine"]
# tens digit
base_tens = ["Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"]
# whole
base_wholes = ["", "", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"]
# big
base_bigs = ["Hundred", "Thousand", "Million", "Billion"]

    str_num = str(num)
    def dfs(val, digit):
        nonlocal base_singles, base_tens, base_wholes, base_bigs
        # 先算数，最后加单位
        res = ""
        curr = int(val) if len(val) < 3 else int(val[len(val) - 3:])
        if curr < 10:
            # 分组之后，当前为个位
            res = base_singles[curr]
        elif curr < 100:
            # 分组之后，当前为十位
            res = tens_digit_handle(curr)
        else:
            # 分组之后，当前组是百位
            hundred = int(curr / 100)
            surplus = curr - hundred * 100
            ten = ""
            if surplus < 10:
                ten = base_singles[surplus]
            else:
                ten = tens_digit_handle(surplus)
            res = base_singles[hundred] + " Hundred And " + ten
        # 最后是单位
        if res != "":
            res += "" if digit == 0 else " " + base_bigs[digit]
        # 下一次递归
        next = "" if len(val) - 3 < 1 else val[:len(val) - 3]
        if len(next) > 0:
            res = dfs(next, digit + 1) + (" " + res if res != "" else "")
        return res
    def tens_digit_handle(curr):
        # 处理十位数
        nonlocal base_singles, base_tens, base_wholes
        sun = ""
        if curr == 0:
            pass
        elif curr < 20:
            # 特殊十位
            ten = curr - 10
            sun = base_tens[ten]
        else:
            # 组合十位
            ten = int(curr / 10)
            single = curr - ten * 10
            sun = base_wholes[ten] + " - " + base_singles[single]
        return sun

    sun = ""
    if num == 0:
        # 零特殊处理
        sun = "Zero"
    elif len(str_num) == 1:
        # 个位
        sun = base_singles[num]
    elif len(str_num) == 2:
        # 十位
        sun = tens_digit_handle(num)
    else:
        # 大位数，进行递归
        sun = dfs(str_num, 0)

    # 多个 replace 方法链式调用时，可能会遇到意外的结果
    # sun = (sun.replace(" And", "").replace(" -", "").replace("  ", " "))
    # 移除 And 和 -
    sun = str.join("",str.join("", sun.split(' And')).split(" -"))
    # 移除前后空格
    sun = sun.strip()
    # 移除连续空格
    sun = str.join(" ", list(filter(lambda a: a != "", sun.split(' '))))
    return sun
