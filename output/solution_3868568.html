C++ Using Dynamic Programming and Memoization
👤 mohitakh 👍 0 2023-08-05 🖼 ↗ 查看原 Solution

Intuition

Separate the operands and operators into different arrays. Then proceed as follows :

In the above image, Let nums array be {v0,v1,v2,v3,v4}. Now grouping will be done from left to right. For v0, grouping of v1,v2,v3,v4 is as follows.
(i) let (v1)(v2 v3 v4) , (v2 v3 v4) can be grouped as : ((v2)(v3 v4)) , ((v2 v3)(v4)). => Therefore 2 is contributed to original array.
(ii) Let (v1 v2) (v3 v4) , here no more grouping is possible so 1 is contributed.
(iii) Let (v1 v2 v3)(v4) = similar grouping done for left hand side as in point 1. Hence 2 is contributed from this grouping.
(iv) Therefore total is 2+1+2= 5

Similarly, next time we take (v0 v1)(v2 v3 v4) , try grouping of v2,v3,v4 and answer will be 2.

Follow the same procedure for other combinations, we get answers for rest of them as : 2 , 5

So total answers which would be possible for (v0,v1,v2,v3,v4) will be 5+2+2+5 = 14

Approach

1) First separate the operands and operators into nums and ops.
2) Call the calc function as calc(nums,ops,left-most index, right-most index) => (nums,ops,0,nums.size()-1).
3) Now the calc function works as follows :
(i) Check for base cases of length of vector 'v' for 1,2 and 3. If length is 1, simply return the number at v[0].
(ii) If length is 2, answer would be simply (v[0] ops[0] v[1]). Hence create a operation function for simplicity and return answer returned from it in form of vector.
(iii) If length is 3, answer would be as discussed in intution above. Calculate them ( 2 possible answers ), and return them in form of vector.
(iv) For rest of cases, create three vectors 'ans' to store final answer, 'ans1' to store answer of left subpart and 'ans2' to store answer of right subpart.
(v) Run a loop from i=l to i=r, to consider each grouping as discussed in intuition above. Now for i=c ( where c is some index between l and r both inclusive), the left subpart would be (l,i) and right subpart would be (i+1,r). Now when both answers are calculated iterate through their array and add the final answer to 'ans' vector.
(vi) The left subpart and right subpart have the operator op[i] between them. This can be explained by the following example :
v[0] v[1] v[2] v[3] v[4] => op[0] op[1] op[2] op[3]

Hence If left subpart is v[0] v[1] v[2] and right subpart is v[3] v[4], we can see that operator between them is op[2] ( rightmost index of left subpart ). Hence in the loop op[i] is taken as the left subpart ( rightmost-index) is 'i'.

Now finally, to optimize we can take a dp, in form of map where key is {l,r} index pair and value is 'ans' vector for this configuration. Pass dp to calc function and store answer calculated into dp. Check if mp[{l,r}].size()!=0 ( means answer is calculated for this config). So return it else proceed for further calculation.

Finally, return 'ans'.

Code

class Solution {
public:
    vector<int> calc(vector<int>v,vector<char>op,int l,int r,map<pair<int,int>,vector<int>>&dp)
    {
        if(dp[{l,r}].size()!=0) return dp[{l,r}];
        if(r-l+1==1)
        {
            return dp[{l,r}] = {v[l]};
        }
        if(r-l+1==2)
        {
            return dp[{l,r}] = {operation(v[l],v[r],op[l])};
        }
        if(r-l+1==3)
        {
            int res1=operation(operation(v[l],v[l+1],op[l]),v[r],op[l+1]);
            int res2=operation(v[l],operation(v[l+1],v[r],op[l+1]),op[l]);
            return dp[{l,r}] = {res1,res2};
        }
        vector<int>ans;
        vector<int>ans1,ans2;
        int i;
        for(i=l;i<r;i++)
        {
            for(auto it1:calc(v,op,l,i,dp))
            {
                for(auto it2:calc(v,op,i+1,r,dp))
                {
                    ans.push_back(operation(it1,it2,op[i]));
                }
            }
        }
        return dp[{l,r}] = ans;
    }
    int operation(int num1,int num2,char op)
    {
        if(op=='+')
            return num1+num2;
        if(op=='-')
            return num1-num2;
        return num1*num2;
    }
    vector<int> diffWaysToCompute(string expression) {
        vector<int>ans;
        vector<int>nums;
        vector<char>ops;
        string s="";
        int len=expression.length();
        int i;
        for(i=0;i<len;i++)
        {
            if(expression[i]>='0' && expression[i]<='9')
                s.push_back(expression[i]);
            else
            {
                nums.push_back(stoi(s));
                ops.push_back(expression[i]);
                s="";
            }
        }
        nums.push_back(stoi(s));
        // for(auto it:nums) cout << it << " " ;
        // cout << endl;
        // for(auto it:ops) cout << it << " " ;
        // cout << endl;
        map<pair<int,int>,vector<int>>dp;
        if(nums.size()==2)
        {
            return calc(nums,ops,0,1,dp);
        }
        else if(nums.size()==3)
        {
            return calc(nums,ops,0,2,dp);
        }

        ans=calc(nums,ops,0,nums.size()-1,dp);
        return ans;
    }
};
