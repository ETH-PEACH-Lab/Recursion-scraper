Intuition

Given the head of a singly linked list, reverse the list, and return the reversed list.

Example 1:

Input: head = [1,2,3,4,5]
Output: [5,4,3,2,1]

Example 2:

Input: head = [1,2]
Output: [2,1]

Example 3:

Input: head = []
Output: []

Constraints:

The number of nodes in the list is the range [0, 5000].
-5000 <= Node.val <= 5000

First Approach

Here's an explanation of the code:

  1. You have a struct ListNode that defines a singly-linked list node. It contains an integer val and a pointer to the next node, which is ListNode *next.

  2. In the Solution class, you have a private function called insert, which is used to insert an integer item at the end of a linked list. It takes an integer and a double pointer to the root of the linked list as parameters.

  3. The reverseList function is a public member of the Solution class. It takes a pointer to the head of a singly-linked list as input and returns a pointer to the head of the reversed list.

  4. Inside the reverseList function, the code first iterates through the input linked list and stores its elements in a vector arr.

  5. Then, it uses the reverse function from the C++ Standard Library to reverse the order of elements in the arr vector, effectively reversing the linked list.

  6. Next, it initializes a pointer temp to NULL, which will be used to build the reversed linked list.

  7. It then iterates through the reversed arr and calls the insert function to insert each element at the end of the temp linked list.

  8. Finally, the temp linked list, which now contains the reversed elements, is returned as the result.

While this code works, it uses extra memory to store the linked list elements in an array, which is not an optimal approach for reversing a linked list. A more efficient in-place reversal can be achieved without using additional memory. Code

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
    private:
    void insert(int item, ListNode **root){
        ListNode* tempRoot = new ListNode;
        tempRoot -> val = item;
        tempRoot -> next = NULL;
        ListNode* ptr;

        if(*root == NULL){
            *root = tempRoot;
        }else{
            ptr = *root;
            while(ptr -> next != NULL){
                ptr = ptr -> next;
            }

            ptr -> next = tempRoot;
        }
    }
public:
    ListNode* reverseList(ListNode* head) {
        vector<int> arr;
        while(head){
            arr.push_back(head -> val);
            head = head -> next;
        }

        reverse(arr.begin(), arr.end());

        ListNode* temp = NULL;
        for(int i=0; i<arr.size(); i++){
            insert(arr[i], &temp);
        }

        return temp;
    }
};

Second Approach:-

Here's an explanation of the code:

  1. You have a struct ListNode that defines a singly-linked list node. It contains an integer val and a pointer to the next node, which is ListNode *next.

  2. In the Solution class, you have a public member function called reverseList, which takes a pointer to the head of a singly-linked list as input and returns a pointer to the head of the reversed list.

  3. Inside the reverseList function, there are two main parts: the base case and the recursive reversal.

  • Base case: If the head pointer is NULL (indicating an empty list) or if the head has no next node (head->next is NULL), then there is nothing to reverse, so the function simply returns the head as it is.

  • Recursive reversal: For non-empty lists, the function recursively calls itself with the head of the list's next node and stores the result in the temp pointer.

    • After returning from the recursive call, the temp pointer now points to the reversed list that starts from the next node.

    • The lines head->next->next = head; and head->next = NULL; reverse the connection of the current node (head) so that it points to the previous node, and its own next pointer is set to NULL to become the new tail of the list.

    • Finally, the function returns temp, which is now the new head of the reversed list.

This recursive approach effectively reverses the linked list in-place without using any additional data structures and has a time complexity of O(n), where n is the number of nodes in the linked list. It is a standard and efficient way to reverse a singly-linked list in C++.

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        //base case:-
        if(head == NULL || head -> next == NULL){
            return head;
        }

        //working:-
        ListNode* temp;
        temp = reverseList(head->next);
        head -> next -> next = head;
        head -> next = NULL;
        return temp;
    }
};
