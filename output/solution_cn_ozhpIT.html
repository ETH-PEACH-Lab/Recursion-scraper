Go 递归 -> 动态规划
👤 PiotrNewt 👍 0 2020-07-05 🖼 ↗ 查看原 Solution

概述

这里是个憨憨，可能要求直接想出动态规划的状态转移方程有点爆炸，所以先写递归，然后由递归改成动态规划，迂回的带走这一波头发。

递归

我们设置 i , j 分别为 s 和 p 当前正在匹配的下标，递归函数为 process(i,j) ，于是需要考虑以下几种情况：
- 1.边界情况：
- i == size of s
- 如果此时 j == size of p ，代表两个字符串匹配到尽头，返回 true
- 如果此时 p[j] == '*'，代表当前可以匹配，但要看 p 的下一个字符 p[j+1] 能不能匹配
- i != size of s 但 j == size of p ：说明 p 已经用完了但 s 还没匹配完， 返回 false
- 2.一般情况：
- p[j] == '*'，代表当前字符肯定能匹配，这里还分为两种情况：
- p[j] 当前的 * 还可以用于 s 的下一个字符匹配，即 process(i+1,j)
- p[j] 当前的 * 只用于 s 当前字符之前的字符匹配，即 process(i,j+1)
- p[j] == '?' 或 p[j] = s[j], 代表当前字符已经匹配好，应该看下一个位置匹配的情况，即 process(i+1,j+1)

整理一下：
当然可以用切片的形式来直接递归调用 isMatch 就行，但这里为了直观说明如何改动态规划，所以写成如下形式：
```golang []
func isMatch(s string, p string) bool {
return process(s,p,0,0)
}

// 递归
func process(s, p string, i, j int) bool {
if i == len(s) && j == len(p) {
return true
}

if i >= len(s) {
    return p[j] == '*' && process(s,p,i,j+1)
}

if j >= len(p) {
    return false
}

if p[j] == '*' {
    return process(s,p,i+1,j) || process(s,p,i,j+1)
}

return (p[j] == s[i] || p[j] == '?') && process(s,p,i+1,j+1)

}


## 动态规划
显然递归有很多重复的操作，不能直接通过所有测试用例，这里直接改成动态规划的形式。
首先考虑我们的状态，可以看到递归函数 `process(i,j)` 中，只要 `i , j` 确定，返回值一定确定，故整个状态空间由`i , j` 能够取到的所有值确定，即：
- `i` 可取 `[0,size of S]`
- `j` 可取 `[0,size of P]`

所以可以得到 dp 表为：
![image.png](https://pic.leetcode.cn/54f9552a2c4819b131688ebe0eef67e8183546bf593afa5df5f2619310ce5e60-image.png)

然后我们递归函数第一次调用的时候是 `process(0,0)`，因此我们需要的答案在 dp[0][0] 的位置。
现在我们根据递归函数来填 dp 表，具体可以参考考虑递归时候的情况，也可以直接只看递归函数：
- 1. 特殊情况：
    - 最右下角：`dp[size of s][size of p] = true`
    - 最后一列：`dp[i][size of p] = false`
    - 最后一行：`dp[size of s][j]` 由 `p[j] == '*'` ? 和 后面的 `dp[size of s][j+1]` 决定
- 2. 一般情况 `dp[i][j]`：
    - 如果 `p[j] == '*'`，`dp[i][j]` 由其下方的 `dp[i+1][j]` 和其右边的 `dp[i][j+1]` 决定
    - 如果不是，则 `dp[i][j]` 由其右下对角线的 `dp[i+1][j+1]` 与 `p[j] == s[i] || p[j] == '?'` 情况决定

![image.png](https://pic.leetcode.cn/e2e6999774a1841fc45cd5e197a8e484d34749debb460d88458e9050d0887138-image.png)


于是从右下填到最左上角即可，整理一下：
```golang []
func isMatch(s string, p string) bool {
    sizeS,sizeP := len(s), len(p)
    if sizeS == 0 && sizeP == 0 {
        return true
    }

    dp := makeMatrix(sizeS + 1, sizeP + 1)
    dp[sizeS][sizeP] = true
    for i := 0; i < sizeS; i++ {
        dp[i][sizeP] = false
    }

    for j := sizeP - 1; j >= 0; j-- {
        dp[sizeS][j] = p[j] == '*' && dp[sizeS][j+1]
    }

    for i := sizeS - 1; i >= 0; i-- {
        for j := sizeP - 1; j >= 0; j-- {
            if p[j] == '*' {
                dp[i][j] = dp[i+1][j] || dp[i][j+1]
            } else {
                dp[i][j] = (p[j] == s[i] || p[j] == '?') && dp[i+1][j+1]
            }
        }
    }
    return dp[0][0]
}

func makeMatrix(n,m int) [][]bool {
    matrix := make([][]bool, n)
    for i := 0; i < n; i++ {
        matrix[i] = make([]bool, m)
    }
    return matrix
}
