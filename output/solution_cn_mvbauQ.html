143. 重排链表

1. 递归

我们明确 reverseList 函数是反转链表并返回新的头结点。

那么在递归的时候，我们将问题子问题化，假设 reverseList 功能已经实现。

reverseList 函数 对于任意传入的头部节点 head。 都将链表分为了 两部分。

  1. 当前传入的头部结点 head
  2. 头部节点 head 之后的 已经反转好的链表头结点 p
  3. 此时头部节点 head 的next并未操作，依然指向 链表p 的尾节点。

举例说明：

假设有链表 1->2->3->4->5 。

那么当 传入当前结点 3 的时候，

我们通过 reverseList 函数 将 结点3 后面的反转 得到链表 5->4，并返回 节点5。

此时， 链表关系如下：

虽然 结点3 后续节点已经被反转，但是 结点3 的后续节点还是指向 结点4。

因此我们需要将 结点3 拼接到 结点4 后面，也就是 head?.next?.next = head， 并将 head?.next = nil 。此时我们已经得到反转的链表

5->4->3。 同时将 结点5 作为新链表头，传递出去。

代码如下：

```swift []
class Solution {
func reverseList(_ head: ListNode?) -> ListNode? {
if head == nil || head?.next == nil {
return head
} else {
//! 前面反转好的
let p = reverseList(head?.next)
//! 当前结点的下一个结点指向自己
head!.next!.next = head
//! 自己的 next 置为nil
head!.next = nil
return p
}
}
}

```c []
struct ListNode* reverseList(struct ListNode* head){
    if (head == NULL ||head->next == NULL) return head;
    struct ListNode *p = reverseList(head->next);
    head->next->next = head;
    head->next = NULL;
    return p;
}

```java []
class Solution {
public ListNode reverseList(ListNode head) {
if (head == null || head.next == null) {
return head;
}
ListNode p = reverseList(head.next);
head.next.next = head;
head.next = null;
return p;
}
}




递归的思路很新奇，常常将复杂问题简单化，是非常值得去理解和使用的。

#### 2.迭代

将尾递归转为循环操作，并且增加一个空的头部节点 作为一个哨兵,不然在遍历第一个节点的时候 需要判断

```swift []
class Solution {
    func reverseList(_ head: ListNode?) -> ListNode? {
      var curr = head
      var front : ListNode? = nil

      while curr != nil {
        //! 先保存后续节点
        let nextTemp = curr!.next
        //! 然后对当前的节点反转
        curr!.next = front
        //! 更新头部节点
        front = curr
        //! 移动指针
        curr = nextTemp
      }
      return front
    }
}

```c []
struct ListNode reverseList(struct ListNode head){

if (head == NULL ||head->next == NULL) return head;

struct ListNode *tempHeadNode = NULL;
struct ListNode *temp = NULL;

while (head) {
    temp = head->next;
    head->next = tempHeadNode;
    tempHeadNode = head;
    head = temp;
}

return tempHeadNode;

}


```java []
class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode curr = head;
        ListNode front = null;
        while (curr != null) {
            ListNode next = curr.next;
            curr.next = front;
            front = curr;
            curr = next;
        }
        return front;
    }
}
