Intuition

Well, in order to do this one, we need to be aware of how we reverse a singly linked list in general. Then we can see that since we need to reverse the list in groups of k, we can leverage recursion to recursively reverse the list in groups of k and return to us the node that becomes head after the reversal of the linked list.

Approach

We can do this by using a recursive approach to reverse the list in groups of k. Look at the image below to get a more clear idea of where the pointers are during the first time when no k sized group is reversed:

Now, every time, we first check the length of remaining nodes from current node to the last node, and only reverse the next k nodes if there are more than k nodes remaining b/w current node and the last node.

Once we have reversed the next k nodes, the prev pointer is pointing to the last reversed node, which will now be the head of this reversed k sized linked list and the curr and next pointers will be at the first node of the next group of k nodes that we want to reverse. Look at the image below to see where our pointers will be present after the first k sized group is reversed.

As you can see, tempHead pointer always points to the last node of each reversed group, and therefore, we make recursive calls to get the head of next reversed group, and we make the next of tempHead tempHead -> next = solve(next, k) and the recursive call reverses the next group and makes it's own recursive call, and at the end, as all the calls are returned we keep joining each group with the previous group's head and we are left with k sized reversed groups at the end.

Complexity

  • Time complexity:

O(N)

  • Space complexity:

O(1)

Code

```cpp []
/
* Definition for singly-linked list.
* struct ListNode {
* int val;
* ListNode next;
* ListNode() : val(0), next(nullptr) {}
* ListNode(int x) : val(x), next(nullptr) {}
* ListNode(int x, ListNode next) : val(x), next(next) {}
* };
/
class Solution {
private:
int countNodes(ListNode head){
int count = 0;
while(head != NULL){
count++;
head = head -> next;
}
return count;
}
public:
ListNode reverseKGroup(ListNode head, int k) {
if(head == NULL){
return NULL;
}
// reverse the LL in groups of K, we can do this recursively
ListNode prev_node = NULL;
ListNode next_node = NULL;
ListNode curr_node = head;
ListNode tempHead = head; // to temporarly hold a pointer to the first node of every recursive call
int t = k;
int leftNodes = countNodes(head); // count nodes from this node to the end of list

    if(leftNodes < k)
        return curr_node; // if we have less than k nodes remaining, then we don't reverse them

    while(t-- && curr_node != NULL){
        next_node = curr_node -> next;
        curr_node->next = prev_node;
        prev_node = curr_node;
        curr_node = next_node;
    }

    // {1 -> 2  -> 3 -> 4 -> 5 -> NULL} has become {NULL <- 1 <- 2   3 -> 4 -> 5 -> NULL}
    // prev is at 2, curr and next are at 3 and tempHead is at 1, so we say that tempHead->next = the reversed part of the remaining nodes that will be returned after all further recursive calls 
    tempHead -> next = reverseKGroup(next_node, k);
    return prev_node;
}

};
```
