Approach

The approach to converting a number to words involves breaking down the number into smaller chunks (specifically, groups of three digits) and converting each chunk separately. The results are then concatenated with the appropriate magnitude words (thousand, million, billion, etc.).

  1. Handle Base Case:
    - If the number is 0, directly return "Zero".

  2. Break Down the Number:
    - Divide the number into chunks of three digits, processing from the least significant digits to the most significant digits (i.e., from right to left).

  3. Convert Each Chunk:
    - For each chunk, convert the number to words using a helper method.
    - This helper method deals with numbers less than 1000 by further breaking them down into hundreds, tens, and ones.

  4. Concatenate Results:
    - Concatenate the converted chunks with the corresponding magnitude words (thousand, million, billion, etc.).
    - Aggregate the result into a single string.

  5. Trim and Return:
    - Remove any leading or trailing spaces from the final string and return the result.

Dry Run

Example 1234567 through the numberToWords method:

  1. Initial Setup:
    - num = 1234567
    - i = 0 (index for the thousands array)
    - words = "" (initial result string)

  2. First Iteration:
    - num % 1000 = 567
    - Call helper(567):

    • 567 >= 100 → "Five Hundred "
    • 567 % 100 = 67
    • Call helper(67):
    • 67 >= 20 → "Sixty "
    • 67 % 10 = 7
    • Call helper(7):
      • 7 < 20 → "Seven "
    • Result: "Sixty Seven "
    • Result: "Five Hundred Sixty Seven "
    • words = "Five Hundred Sixty Seven "
    • num /= 1000 = 1234
    • i = 1

  3. Second Iteration:
    - num % 1000 = 234
    - Call helper(234):

    • 234 >= 100 → "Two Hundred "
    • 234 % 100 = 34
    • Call helper(34):
    • 34 >= 20 → "Thirty "
    • 34 % 10 = 4
    • Call helper(4):
      • 4 < 20 → "Four "
    • Result: "Thirty Four "
    • Result: "Two Hundred Thirty Four "
    • words = "Two Hundred Thirty Four Thousand Five Hundred Sixty Seven "
    • num /= 1000 = 1
    • i = 2

  4. Third Iteration:
    - num % 1000 = 1
    - Call helper(1):

    • 1 < 20 → "One "
    • words = "One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven "
    • num /= 1000 = 0
    • i = 3

  5. Final Result:
    - Trim words to remove any extra spaces: "One Million Two Hundred Thirty Four Thousand Five Hundred Sixty Seven"

Complexity

  • Time complexity: O(log N) cause the number will be divisble by 1000. in all the iterations.
  • Space complexity: O(N) because we are hardcoding the words.

Code

class Solution {
    String[] ones = {"", "One", "Two", "Three", "Four", "Five", "Six", "Seven", "Eight", "Nine", "Ten", "Eleven", "Twelve", "Thirteen", "Fourteen", "Fifteen", "Sixteen", "Seventeen", "Eighteen", "Nineteen"};

    String[] tens = {"", "Ten", "Twenty", "Thirty", "Forty", "Fifty", "Sixty", "Seventy", "Eighty", "Ninety"};

    String[] thousands = {"", "Thousand", "Million", "Billion"};

    public String numberToWords(int num) {
        if (num == 0) return "Zero";

        int i = 0;
        String words = "";

        while (num > 0) {
            if (num % 1000 != 0) {
                words = helper(num % 1000) + thousands[i] + " " + words;
            }
            num /= 1000;
            i++;
        }

        return words.trim();
    }

    private String helper(int num) {
        if (num == 0) return "";
        else if (num < 20) return ones[num] + " ";
        else if (num < 100) return tens[num / 10] + " " + helper(num % 10);
        else return ones[num / 100] + " Hundred " + helper(num % 100);
    }
}
