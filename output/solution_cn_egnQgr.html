剑指 Offer 62. 圆圈中最后剩下的数字——递归（多种写法思路总结）

一、解题思路

  1. 计算出每次删除哪一个数字。分别包含 start + m < size 和 start + m > size ，当 start + m > size 又分为是否为size的整数倍
  2. 要一直删除，直到还剩一个数字。或者理解成要总共删除n-1个数字。

  2. 失败思路二：有了思路一的失败经验，换了一种思路，发现还是耗时。代码如下：
    ```java
    class Solution {
    public int lastRemaining(int n, int m) {
    LinkedList list = new LinkedList<>();
    for (int i = 0; i < n; i++) {
    list.add(i);
    }
    removeInt(list, 0, m);//start为开始计数的index
    return list.getLast();
    }

    private void removeInt(LinkedList<Integer> list, int start, int m) {
    int size = list.size();
    int end = 0;//将要删除的index
    if (start + m <= size) {
        //直接小于size
        end = start + m - 1;
    } else if ((start + m) % size == 0) {
        //当能整除时，比如start=4，m=17，size=7时，这个时候应该直接删除最后一个。
        end = size - 1;
    } else {
        //当不能整除时
        end = start + m - ((start + m) / size) * size - 1;
    }
    list.remove(end);
    if (list.size() == 1) {
        return;
    } else {
        removeInt(list, end, m);
    }
}

    }

        end = size - 1;

        end = remainder - 1;
    ```

  3. 通过方法一：在思路三的基础上继续优化：把 LinkedList 改为 ArrayList ，注意要调用 list.add(i,i) ，即保证 ArrayList 有序

    ```java
    class Solution {
    public int lastRemaining(int n, int m) {
    ArrayList list = new ArrayList<>();
    for (int i = 0; i < n; i++) {
    list.add(i,i);//不用LinkedList，用ArrayList的话，注意要有序。
    }
    removeInt(list, 0, m);//start为开始计数的index
    return list.get(0);
    }

    private void removeInt(ArrayList<Integer> list, int start, int m) {
    int size = list.size();
    if (size == 1) {
        return;
    }
    int end = 0;//将要删除的index
    int remainder = (start + m) % size;//取余数
    if (start + m < size) {//直接小于size
        end = start + m - 1;
    } else if (remainder == 0) {//当能整除时
        end = size - 1;
    } else {//当不能整除时
        end = remainder - 1;
    }
    list.remove(end);
    removeInt(list, end, m);
}

    }
    ```
