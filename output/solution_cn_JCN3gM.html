206. 反转链表

方法一：虚拟头节点+递归

  • 定义一个 dummy_head 作为新链表的头节点；
  • 在原来链表中，利用递归先进行到最深处 if (cur_node.next is not None): recurse(cur_node.next)，然后依次将节点接到新链表上。

利用的是递归“返回”的过程是逆序的，所以原链表的节点也会以逆序接到新链表上。最后返回 dummy_head.next 即可

class Solution:        
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None:
            return None
        dummy_head = ListNode()
        cur_node_new_list = dummy_head

        def recurse(cur_node: ListNode):
            nonlocal cur_node_new_list
            if (cur_node.next is not None):
                recurse(cur_node.next)
            cur_node_new_list.next = cur_node
            cur_node_new_list = cur_node_new_list.next

        recurse(head)
        head.next = None
        return dummy_head.next

方法二：双指针+迭代

不用虚拟头节点，在原链表上定义两个指针（快慢指针）pre_node 和 cur_node

  • 初始化 pre_node, cur_node = None, head————即 pre_node 在 cur_node “前一个”的位置；
  • 每次迭代都让 cur_node.next = pre_node，并更新它们；
  • 直到 cur_node is None，此时 pre_node 在原链表的最后一个位置，也就是新链表的表头，返回 pre_node 即可。

注意：

迭代时需要用临时指针存储 cur_node.next，否则会发生断链，找不到下一轮迭代的目标；
另外 pre_node 和 cur_node 的更新顺序也要注意。

总之，画个图会很清晰:

class Solution:        

    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:
        pre_node = None
        cur_node = head
        while (cur_node is not None):
            temp = cur_node.next
            cur_node.next = pre_node
            pre_node = cur_node
            cur_node = temp
        return pre_node

方法三：双指针+递归

思路与方法二一致，只不过用递归替代迭代。

注意：
这里的递归有返回值。我们需要返回反转后的头节点，即递归最深处的 pre_node，需要在递归中一层一层地向上返回。因此每一个递归函数都要返回更深一层的返回值

class Solution:        
    def reverseList(self, head: Optional[ListNode]) -> Optional[ListNode]:

        def recurse(pre_node: Optional[ListNode], cur_node: Optional[ListNode]):
            if cur_node is None:
                return pre_node
            temp = cur_node.next
            cur_node.next = pre_node
            return recurse(cur_node, temp)

        return recurse(None, head)
