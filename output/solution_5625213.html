Solution 1: Recursive Approach with Base Case Check

Overview:

This approach recursively reverses every k-group in a linked list. The method checks if there are fewer than k nodes remaining and, if so, returns the head as-is. Otherwise, it reverses the first k nodes and then recursively processes the next group.

Detailed Explanation:

  1. Base Case:
  • If the head is NULL, it means we've reached the end of the list, and we simply return NULL.
  1. Check if a Full k-Group Exists:
  • Before reversing, we must ensure there are at least k nodes left in the list. We use a pointer check to traverse k nodes ahead.
  • If fewer than k nodes are found (check becomes NULL), return head without making changes.
  1. Reverse the k-Group:
  • Initialize pointers: curr (current node), prev (previous node), and next (next node).
  • Traverse the nodes, reversing the links between them until k nodes have been processed.
  • After reversing, the prev pointer will point to the new head of the reversed k-group.
  1. Recursive Call:
  • After reversing the current k-group, make a recursive call to reverse the next k-group starting from next.
  • Link the head (which is now the tail of the reversed k-group) to the result of the recursive call.
  1. Return:
  • Return prev, which is the new head of the reversed list.

Complexity

  • Time complexity: O(N)
  • Space complexity: O(N/k)

Code

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        // Base case: if head is NULL, return NULL
        if(head == NULL) {
            return NULL;
        }

        // Check if there are at least k nodes to reverse
        ListNode* check = head;
        for (int i = 0; i < k; ++i) {
            if (!check) return head; 
            check = check->next;
        }

        // Reverse the k-group
        ListNode* next = NULL;
        ListNode* curr = head;
        ListNode* prev = NULL;
        int cnt = 0;

        while(curr != NULL && cnt < k) {
            next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
            cnt++;
        }

        // Recursively reverse the next groups and attach them
        if(next != NULL) {
            head->next = reverseKGroup(next, k);
        }

        // Return the new head of the reversed list
        return prev;
    }
};

Solution 2: Iterative Approach with k-Group Check

Overview:

This solution is similar to the first but with a slight variation in how it checks if a full k-group exists before reversing. Instead of making a base case check, it first counts the nodes in the group before proceeding with the reversal.

Detailed Explanation:

  1. Count the Nodes in the Group:
  • A pointer node starts from head, and we count k nodes to ensure there are enough nodes to reverse.
  • If there are fewer than k nodes (count < k), return head as it is since we don't need to reverse anything.
  1. Reverse the k-Group:
  • Similar to Solution 1, use curr, prev, and next pointers to reverse the first k nodes.

  • After reversing, prev points to the new head of the reversed group.
    3. Recursive Call:

  • Once the first k-group is reversed, recursively process the next group by calling reverseKGroup with the next pointer.

  • Link the tail of the reversed group (i.e., head) to the result of the recursive call.
    4. Return:

  • Return prev as the new head of the linked list.

Complexity

  • Time complexity: O(N)
  • Space complexity: O(N/k)

Code

/**
 * Definition for singly-linked list.
 * struct ListNode {
 *     int val;
 *     ListNode *next;
 *     ListNode() : val(0), next(nullptr) {}
 *     ListNode(int x) : val(x), next(nullptr) {}
 *     ListNode(int x, ListNode *next) : val(x), next(next) {}
 * };
 */
class Solution {
public:
    ListNode* reverseKGroup(ListNode* head, int k) {
        // Count the number of nodes in the current group
        ListNode* node = head;
        int count = 0;
        while (node != NULL && count < k) {
            node = node->next;
            count++;
        }

        // If there are fewer than k nodes, return the head as is
        if (count < k) {
            return head;
        }

        // Reverse the k-group
        ListNode* next = NULL;
        ListNode* curr = head;
        ListNode* prev = NULL;
        int cnt = 0;

        while(curr != NULL && cnt < k) {
            next = curr->next;
            curr->next = prev;
            prev = curr;
            curr = next;
            cnt++;
        }

        // Recursively reverse the next groups and attach them
        if(next != NULL) {
            head->next = reverseKGroup(next, k);
        }

        // Return the new head of the reversed list
        return prev;
    }
};
