栈 + 双指针 + 递归（1行代码，超96%）
👤 mantoufan 👍 1 2020-10-13 🖼 ↗ 查看原 Solution

递归

解题思路

  • 递归链表，next到底，反向回溯。在递归函数后，链表尾部节点值n.val先被访问
  • 此时head仍然是之前的链表。head头部值 与 链表尾部n.val比较
  • 不同，非回文链表，返回false，之后仅回溯不再比较
  • 相同，head向下移动一节点。返回true，继续回溯到链表尾部上一节点，继续比较

代码

var isPalindrome = function(head, t, d) {
   return d = n => n === null || d(n.next) && (t = n.val === head.val, head = head.next, t), d(head)
};

栈 + 双指针

解题思路

  • 慢指针p0速度1（1次移动1节点），快指针p1速度2。当p1到头时，p0刚好走一半
  • 链表长度为偶数：p1到头（while终止时，p1为空），p0在中间向后第一个节点
  • 链表长度为奇数：p1到头（while终止时，p1不为空，p1.next为空），p0在中间节点
  • 奇数情况，若p1存在和p1.next为空，将p0再后移一节点。无论奇偶，p0都在中间向后第一个节点
  • 栈s，p0走前一半时放入节点值，p0走后一半时，弹出值与p0.val比较，若不同，返回false

代码

var isPalindrome = function(head, p = [head, head], s = []) {
   while (p[1] && p[1].next) {
       s.push(p[0].val)
       p[0] = p[0].next
       p[1] = p[1].next.next
   }
   if (p[1] && !p[1].next) p[0] = p[0].next
   while (p[0]) {
        if (p[0].val !== s.pop()) return false
        p[0] = p[0].next
    }
   return true
};

反转链表 + 双指针

解题思路

  • 链表l，l = p0, p0 = p0.next, l.next = pre, pre = l。while(p0)重复这四步反转链表
  • p0走一半时，l刚好是一半反转链表，p0后一半应与l每节点值相同

代码

var isPalindrome = function(head, p = [head, head], l = new ListNode(), pre = null) {
   while (p[1] && p[1].next) {
       l = p[0]
       p[0] = p[0].next
       p[1] = p[1].next.next   
       l.next = pre
       pre = l
   }
   if (p[1] && !p[1].next) p[0] = p[0].next
   while (p[0]) {
        if (p[0].val !== l.val) return false
        p[0] = p[0].next
        l = l.next
    }
   return true
};
