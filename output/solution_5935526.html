Intuition

  • The problem involves constructing a binary string recursively and finding the Kth bit in the resulting string. The string is built as follows:
S1 = "0"
S2 = S1 + "1" + reverse(invert(S1)) = "0 1 1"
S3 = S2 + "1" + reverse(invert(S2)) = "0 1 1 1 0 1 0"
The general pattern for string Sn is Sn = Sn-1 + "1" + reverse(invert(Sn-1)).
  • Given a number n and an index k, you are asked to return the Kth bit in the string Sn.

First Approach (Naive Recursive Construction)

  1. Idea: Directly construct the string Sn using recursion, and then return the Kth bit.
  2. Key Functions:
    • getBits(n): Recursively construct the string Sn by using the previous string Sn-1.
    • invert(str): Flip all bits ('0' to '1', '1' to '0') and reverse the string.

Complexities

  • Time Complexity: O(2^n) to generate the full string and O(1) to access the Kth bit.
  • Space Complexity: O(2^n) due to recursive string construction.

```cpp []
class Solution {
private:
string invert(string str){
for(int i=0; i<str.size(); i++){
str[i] = str[i] == '0' ? '1' : '0';
}
reverse(str.begin(),str.end());
return str;
}
string getBits(int n){
if(n==1) return "0";
string str = getBits(n-1);
str = str + "1" + invert(str);
return str;
}
public:
char findKthBit(int n, int k) {
string str = getBits(n);
return str[k-1];
}
};

# Second Approach (Optimized Recursive)
1. Idea: Rather than constructing the entire string, which can be inefficient for large n, use recursion and properties of the string structure to directly determine the Kth bit.
2. Key Insight:
    - The length of Sn is (2^n - 1).
    - The middle bit of Sn is always '1'.
    - The first half of Sn is the same as Sn-1, and the second half is the reverse and inverted version of Sn-1.
    - If k lies in the second half, we can reduce the problem to Sn-1 by computing k' = length - k + 1 and inverting the bit.
    - This way, we avoid constructing the full string and use recursion to determine the bit.
# Complexity
- Time Complexity: O(n), as we reduce the problem size by half in each recursive step.
- Space Complexity: O(n) due to the recursive stack.
# Code
``` C++ []
class Solution {
public:
    char findKthBit(int n, int k) {
        if(n==1) return '0';

        int length = (1<<n)-1;
        int middle = length/2 + 1;

        if(middle == k) return '1';
        else if(middle > k) return findKthBit(n-1,k);
        else return findKthBit(n-1 , length-k+1) == '1' ? '0' : '1';
    }
};

class Solution {
public char findKthBit(int n, int k) {
if (n == 1) return '0'; // Base case

    int length = (1 << n) - 1;  // Length of the string Sn
    int middle = length / 2 + 1;  // Middle index of Sn

    if (middle == k) return '1';  // The middle element is always '1'
    else if (middle > k) return findKthBit(n - 1, k);  // If k lies in the first half, recurse on Sn-1
    else return findKthBit(n - 1, length - k + 1) == '1' ? '0' : '1';  // If k lies in the second half, invert the bit
}

}
