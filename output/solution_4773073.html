Simple java recursion solution with memoization || beats 96% of the user if you skip memoization

Intuition

So with a given number you have to build a tree based on the fact that the number will act as root. We have to find all the combination.

Please upvote if you like

Approach

Now lets see the problem closely, problem says that the tree should be complete. That means every node has either 0 or 2 children but not one child. So we need to think of the combinations.

For every even number, it is impossible to make a complete binary tree. For example if n is 2 then it can have only one child which does not satisfy our condition.

So point number 1 is that we can skip even number combinations like left child and right child as (2,0) or (4,2) etc.
Now lets start the combination with left as 1 and right as (n - 1) - left. n - 1 is because root has to decrease its own length before calling recursively.
For example: for n = 7, combinations would be (1,5), (3,3) and (5, 1)

Now you have to iterate over these combinations and call recursive solution.

and then we will make all the combination trees, add them in the result list and will return the result. Simple !!

Complexity

  • Time complexity: O(n^2)
  • Space complexity:0(n)

Code

/**
 * Definition for a binary tree node.
 * public class TreeNode {
 *     int val;
 *     TreeNode left;
 *     TreeNode right;
 *     TreeNode() {}
 *     TreeNode(int val) { this.val = val; }
 *     TreeNode(int val, TreeNode left, TreeNode right) {
 *         this.val = val;
 *         this.left = left;
 *         this.right = right;
 *     }
 * }
 */
class Solution {

    public List<TreeNode> allPossibleFBT(int n){

        //creating a matrix array to store the solutions
        //this saves a lot of time in computation
        List<TreeNode>[] matrix = new ArrayList[n + 1];
        return allPossibleFBT(n, matrix);
    }


    //helper function for memoization
    public List<TreeNode> allPossibleFBT(int n, List<TreeNode>[] matrix) {
        List<TreeNode> result = new ArrayList<>();

        //check if the solution already present in the matrix
        if(matrix[n] != null){
            return matrix[n];
        }

        //this condition is just for the test case. It would never come in recursion.
        if(n <= 0 || n%2 == 0){
              return matrix[n] = result;
        }

        //this is our actual base condition
        if(n == 1){
            TreeNode root = new TreeNode(0);
            result.add(root);
            return matrix[n] = result;
        }

        //start to find combination of length of childrens
        for(int h = 1; h<n-1; h = h+2){
            int first = h;
            int second = n - 1 - h;

            //calling recursive function to get all the combination trees from children
            List<TreeNode> left = allPossibleFBT(first);
            List<TreeNode> right = allPossibleFBT(second);

            //since we need only full binary tree
            //this condition will never come actually, this is just for safety
            if(left.size() == 0 || right.size() == 0){
                TreeNode root = new TreeNode(0);
                result.add(root);
            }

            //adding all the combination to result list.
            for(int i = 0; i<left.size(); i++){
                for(int j = 0; j<right.size(); j++){
                    TreeNode root = new TreeNode(0);
                    root.left = left.get(i);
                    root.right = right.get(j);
                    result.add(root);
                }
            }
        }
        return matrix[n] = result;

    }
}
