Intuition

The question is really simple, if we start looking in a certain direction..The direction will be something like this

1) Player 1 needs to get maximum score

2) If player 2 gets the chance, he should get minimum score

Now, the question comes=> How do we do that

The fist thing, you need to clear in your mind is that, we need to figure out all the cases..If we need to figure out all the cases, then the best thing is recusrion only...

Let us say, Player 1 is playing,

He will have 2 options

Option 1) He can choose from the start of array, let us say start = i

Option 2) He can choose from the end of array, let us say end = j

Now if he choose from start, then his score will increase by nums[i]and for the next turn, player 2 will have the option to choose from index i+1 to j

In code it will look like this...

int a = nums[i] + solve(i+1,j,nums, chance_of_second_player)

Now if he choose option 2, then his score will increase by nums[j] and for the next turn , player 2 has to choose from index i to j-1

In code it will look like this ...

int b = nums[j]+ solve(i,j-1,nums,chance_of_second_player)

Now, In the starting of the question , I told you that we will maximize player 1 score

SO out of these 2 options , we need to return the maximum, In code it will look like this 

return max(a,b);

Now, let us say, player 2 chance has come

Now, Initially i told you , we will be calculating the score of player 1 and for player 2 we will try to get the minimum score

Now, in the recursive function, i am trying to get the max score of player 1 => remember this

Player 2 will also have 2 options

Option 1) He can choose from the start , so if he choose from the start, so for the next player has to choose from i+1 to j

We won't include his score nums[i], because we are not calculating his score...so we don't care about his score, we will just think of player 1

In code it will look like this 

int c = solve(i+1,j,chance_of_first_player)

Option 2) He can choose from the end, so if we choose from the end, so for the next player that is (1), he will have option to choose from i to j-1, and we won't include the score of player 2, because we don't want it

In code...

int d = solve(i,j-1,chance_of_first_player)

Now , i ask you a really simple question , For player 2 , what do we want..

We want that he should loose, so to loose..whatever he choose..it should be minimum...Pls think it for a while...

Now there were 2 options for him c and d and if we want him to loose , we will choose the minimum out of two.....SIMPLEEEE

In code 

return min(c,d);

Now, what will be the base case

1) i was our start index, j was our end index...Now just think if i becomes greater then j, then how can we choose anything...so 

if(i>j)
{
return 0;
}

Now, how do we memoize it

The ans is simple...

Three things are changing
1) start index
2) end index
3) Turn of player(1st or 2nd)

Just make a 3-d dp array and store the results there....

That is how you do dynamic programming...

Now, we got the max score of player 1

We know the total sum of our array

so (total_sum_of_array - max score of player 1) will give the score of player 2, Now you just check which one is big .... ;)

Complexity

  • Time complexity:

We know the length of array is maximum 20(given in the question) , and we are making a 3-d dp array
of start_index , end_index and 2 players , so

start index can go from 1 to 20
end can go from 20 to 1
2 players ( 1 and 2)

so 20 * 20 *2

Or mathematically we can write O(N * N * 2) =>O(N * N )

  • Space complexity:

We are using a 3-d dp array so,

O(N * N * 2)

Code

class Solution {
public:


    int solve(int i,int j,vector<int>& nums,int chance,int dp[21][21][3])
    {


        if(i>j)
        {
            return 0;
        }


        if(dp[i][j][chance]!=-1)
        {
            return dp[i][j][chance];
        }
        if(chance==0)
        {

            int a = nums[i]+solve(i+1,j,nums,1,dp);
            int b = nums[j]+solve(i,j-1,nums,1,dp);

            dp[i][j][chance] = max(a,b);
            return dp[i][j][chance];

        }
        else
        {

            int a = solve(i+1,j,nums,0,dp);
            int b = solve(i,j-1,nums,0,dp);

            dp[i][j][chance] = min(a,b);
            return dp[i][j][chance];
        }

    }



    bool PredictTheWinner(vector<int>& nums) {


        int dp[21][21][3];

        for(int i=0; i<=20; i++)
        {
            for(int j=0; j<=20; j++)
            {
                for(int k=0; k<=2; k++)
                {
                    dp[i][j][k]=-1;
                }
            }
        }

        if(nums.size()==1)
        {
            return true;
        }

        int i = 0;
        int j = nums.size()-1;

        int sum = 0;

        for(int i=0; i<nums.size(); i++)
        {
            sum+=nums[i];
        }

        int chance = 0;
        int a = solve(i,j,nums,chance,dp);

        int b = sum-a;

        if(a>=b)
        {
            return true;
        }
        else
        {
            return false;
        }


    }
};
