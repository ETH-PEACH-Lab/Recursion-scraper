解题思路

  1. 题目情况解析【一个链表按k段k段翻转】
    1. 当k段能翻转==》就翻转
    2. 当不能翻转【前面的都反转完了 剩下的不足k个】==》直接加在后面
    3. 将【这一次】翻转得到新的【头部】和【上一次的尾部】相连接
    4. 当然也得记录【k+1项】因为如果直接翻转，则会丢失第【k+1项】
      毕竟你反转后 屁股变成头了 找不到第【k+1项】
  2. 由第一部分析得

判断是否能翻转

  • 最简单方法走一下 看看能不能走到底
  • 走到底就是能翻转 ==》true
  • 走不到底【有null的结点出现】==》false
function reservable(head,k){
  for(let i=k;i>0;i--){
    if(head==null)
      return false
    head=head.next
  }
  return true
}

对判断结果进行操作

  • 能翻转 就执行翻转函数
  • 我对此函数定义【3项数组】返回值==》 [翻转头，翻转尾，未翻转尾的next 【即k+1项】]
    【不知道为什么的看上面的1.3和11.4】
function reserve(head,k){
  if(k==1)
    return [head,head,head.next]
  var arr=reserve( head.next,k-1)
  arr[1].next=head
  return [arr[0],head,arr[2]]
}

边界处理

  • 此时功能函数都有了 就要综合起来 但发现【第一次翻转的头部】和【最后一次翻转的尾部】需要处理
  • 【第一次翻转的头部】作为return的返回值 不必多说
  • 【最后一次翻转的尾部】当有【不必翻转项】需要将其指向剩下的头部，当没有【不必翻转项】则指向空
  • 我定义了 【root】 和 【rear】实现上述的【返回头部】和【合并上次尾部】的操作

代码

var reverseKGroup = function(head, k) {
  let root=null
  let rear=null
  while(reservable(head,k)){
    var arr=reserve(head,k)
    if(!root){
      root=arr[0]
      rear=arr[1]
    }else{
      rear.next=arr[0]
      rear=arr[1]
    }
    head=arr[2]
  }
  rear.next=head
  return root
};
