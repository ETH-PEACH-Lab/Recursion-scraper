Intuition

  • We need to evaluate the boolean expression recursively. For each expression:
  1. If the operator is '!', the expression will have a single value, and we flip it (i.e., True becomes False and vice versa).
  2. If the operator is '&', we need all values to be True for the result to be True.
  3. If the operator is '|', we need at least one value to be True for the result to be True.
  4. The solution involves parsing the expression using recursion. When we encounter a sub-expression inside parentheses, we recursively evaluate it, and based on the operator at the start of the expression, we combine the results.

Approach

  1. Start with the first character of the expression.
  2. Based on the operator (!, |, &), apply the corresponding logic:
    • '!': Negate the result of the single sub-expression.
    • '|': Return True if at least one sub-expression evaluates to True.
    • '&': Return True only if all sub-expressions evaluate to True.
  3. For each sub-expression within parentheses, recursively evaluate the expression.
  4. Return the final result after parsing the entire expression.

Complexity

- Time Complexity: O(n) where n is the length of the string. We visit each character once during the recursion.
- Space Complexity: O(n) due to the recursive call stack and auxiliary space for string processing.

class Solution {
private:
bool helper(int &i,string &str){
char exp = str[i];
bool TruePresent=0, FalsePresent=0;

    i+=2; // skip '('
    while(str[i-1]!=')'){
        if(str[i]=='t') TruePresent=true;
        else if(str[i]=='f') FalsePresent=true;
        else
            if(helper(i,str)) TruePresent=true;
            else FalsePresent = true;
        i+=2;  // skip ','
    }
    i--;
    if(exp=='|') return TruePresent; // |
    if(exp=='&') return !FalsePresent; // &
    if(TruePresent) return false; // !
    return true;
}

public:
bool parseBoolExpr(string expression) {
int i=0;
return helper(i,expression);
}
};

class Solution {
    private boolean helper(int[] i, String str) {
        char exp = str.charAt(i[0]);
        boolean TruePresent = false, FalsePresent = false;

        i[0] += 2; // skip '('
        while (str.charAt(i[0] - 1) != ')') {
            if (str.charAt(i[0]) == 't') TruePresent = true;
            else if (str.charAt(i[0]) == 'f') FalsePresent = true;
            else if (helper(i, str)) TruePresent = true;
            else FalsePresent = true;
            i[0] += 2; // skip ','
        }
        i[0]--;
        if (exp == '|') return TruePresent; // OR
        if (exp == '&') return !FalsePresent; // AND
        return !TruePresent; // NOT
    }

    public boolean parseBoolExpr(String expression) {
        int[] i = {0};
        return helper(i, expression);
    }
}
