Recursion + Memoization | Clean Code and Explanation | Easy to Understand

Scenarios

Let's try to understand the different scenarios of the pattern. We will consider simplest pattern first and build up to more complicated scenarios.

Case 0: if Pattern doesn not have . or * characters in it

This is self explantory we just match each index of s with each index of p

Case 1: if Pattern has only . characters and letters in it

Everything we did in Case 0 + whenever you have . in the pattern just try to match the letter at each index after it, as . can be matched with anything

Case 2: if Pattern has both . and * along with letters in it

Case 2a: if you repeat the prev letter 0 times

Everything we did in Case 1 + whenever you're at a letter or . check if the next index is * if this is true we can skip the current index in pattern and check the next index of pattern with current index of s

Case 2b: if you repeat the prev letter more than 0 times

Everything we did Case 2a + if we can repeat the prev character more than 0 times, try every single possibility until you cannot repeat.

Here repeating is just moving the index of s until you can match with prev character.

Below is the scenario where s can be matched until the end of the string. repeating 0 - 2 times will return false

Approach

Based on all the scenarios we can see that we are processing the strings index by index. At each index we can have multiple scenarios. if any one of those scenarios returns true then the result would be true.

Which scenario has the highest importance ?
Case 2: It's clear that whenever we encounter * or letter with * ahead of it there can be many different paths we can take. We have to try out all the different paths branching from that. Since we might explore a multiple paths we don't want to repeat the work. So memoization will help us prune repeated work.

Case 1 & Case 0: These both are very similar so they can be handled in any order.

Now it's just matter of coding this up using pointers :)

Code

class Solution {
    public boolean isMatch(String s, String p) {
        int m = s.length(), n = p.length();
        return isMatch(s.toCharArray(), p.toCharArray(), 0, 0, new Boolean[m + 1][n]);
    }

    private boolean isMatch(char[] s, char[] p, int sIndex, int pIndex, Boolean[][] memo) {
        // both the pointers have reached the end of their strings.
        if(sIndex == s.length && pIndex == p.length) return true;

        // if you run out of pattern to compare the sentence with.
        if(pIndex == p.length) return false;

        // have we seen this state before ? 
        if(memo[sIndex][pIndex] != null) return memo[sIndex][pIndex];

        // can you ignore the current character ? 
        if(canIgnore(p, pIndex) && isMatch(s, p, sIndex, pIndex + 1, memo)) {
            return memo[sIndex][pIndex] = true;
        }

        // can we repeat the previous character
        if(p[pIndex] == '*') {
            // repeating 0 times or ignoring
            if(isMatch(s, p, sIndex, pIndex + 1, memo)) {
                return memo[sIndex][pIndex] = true;
            }

            // try every different possiblility of repeating the prev character
            char prev = p[pIndex - 1];
            int index = sIndex;
            while(index < s.length && (prev == '.' || prev == s[index])) {
                if(isMatch(s, p, index + 1, pIndex + 1, memo)) return memo[index][pIndex] = true;
                index++;
            }

            // if this is an invalid state
            return memo[sIndex][pIndex] = false;
        }

        // if you run out of sentence to match with pattern
        if(sIndex == s.length) return false;

        // match with any character
        if(p[pIndex] == '.' && isMatch(s, p, sIndex + 1, pIndex + 1, memo)) {
            return memo[sIndex][pIndex] = true;
        }

        // match the current character.
        if(s[sIndex] == p[pIndex] && isMatch(s, p, sIndex + 1, pIndex + 1, memo)) {
            return memo[sIndex][pIndex] = true;
        }

        // invalid result
        return memo[sIndex][pIndex] = false;
    }

    private boolean canIgnore(char[] pattern, int index) {
        return index < pattern.length - 1 && pattern[index + 1] == '*';
    }
}

Time Complexity:

O(M*N) we explore all M*N scenarios in the worst case. Where M is the length of s and N is the length of p

Space Complexity:

O(M*N) we store all M*N scenarios in the boolean matrix. Where M is the length of s and N is the length of p
