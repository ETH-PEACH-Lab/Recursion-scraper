For this problem, we want to implement pow(x, n), which calculates x raised to the power n (i.e., xn).

Explanation

To implement pow(x, n), we can use Top down DP approach to break the original problem down into smaller subproblems. We will solve pow(x,n) recursively as we will divide subproblems into smaller subproblem until we reach our base case, which tends to be the smallest subproblem.

During each step, we check if we have already solved the subproblem by using memoization. If the computed result is already present in our memoization table, then we can avoid the redundant recalculation and directly access it. Otherwise, we need to compute the result and store it in memo for future references.

dp()

  • dp helper method is defined which takes three arguments:

    1) x (base)

    2) n (exponent)

    3) memo , dictionary to store the pre-calculated results of subproblems

  • The base cases needed for recursion will be the following:

    1) If the exponent (n) is 0, the result will always be 1. This is a fundamental mathematical property, and it is essential to handle this base case correctly to ensure the function works properly for all possible inputs.

    3) If the exponent (n) is already present in our memo dictionary, return the pre-calculated result denoted as memo[n]

  • If base cases are not met, then we perform divide and conquer which we will divide the problem of calculating x^n into smaller problems.

  • Our recursive call is denoted as half = dp(x, n //2, memo)

    1) x: The base of the power operation, which remains the same throughout the recursion

    2) n // 2: The exponent will be halved. We are dividing the exponent n by 2 in each recursive call, effectively reducing it to half in each step.

  • The goal of this recursion is to calculate the base x raised to the power of n // 2. This approach is known as exponentiation by squaring, where we repeatedly square the base and halve the exponent until the exponent becomes 0 or 1.

  • Once the recursive call to calculate x^(n // 2) is complete and we have the result stored in the variable half, we calculate x^n by squaring the half value. This line of code stores the result of x^n in the memoization dictionary memo for future reference

  • Using what we have calculated for our recursive call, we check if the original n was odd in the current recursive call.

    1) If so, we calculate our result in our memo denoted as memo[n] by x once more to account for the remaining factor

    2) When the exponent n is odd, the algorithm multiplies the half * half result by x once more to correctly calculate the result of x^n. This ensures that we include the extra factor of x that would be left out by dividing the exponent in half.

For example, let's say we want to calculate x^5, where x = 2. If we use the recursive approach without considering the odd exponent, we would calculate 2^5 as follows:

  • Calculate half = x^(5 // 2) = x^2 = 2^2 = 4.

  • Multiply half * half = 4 * 4 = 16.

However, this would give us an incorrect result of 16, while the correct result is 32. The condition if (n % 2 === 1) is what ensures that we correctly include the remaining factor of x when n is odd.

  • To calculate 2^5:

  • Calculate half = 2^(5 // 2) = 2^2 = 4.

Since 5 is odd, we multiply the result by x, which is 2, once more: result = half * half * x = 4 * 4 * 2 = 32.

  • The method will then return the final result in our memo

myPow()

  • Create a memo dictionary to store pre-calculated results

  • If the exponent n is negative, the base of x will be inverted and the exponent n is made positive. This is because x^(-n) = 1 / x^n

  • We call dp method denoted as dp(x, n, memo) to correctly calculate x^n

Code

Python

class Solution:
    def myPow(self, x: float, n: int) -> float:
        def dp(x, n, memo):
            if n == 0: return 1.0
            if n in memo: return memo[n]

            half = dp(x, n //2, memo)
            memo[n] = half * half

            if n % 2 == 1: memo[n] *= x
            return memo[n]

        memo = {}
        if n < 0: 
            x = 1/x
            n = -n

        return dp(x, n, memo)

JavaScript

/**
 * @param {number} x
 * @param {number} n
 * @return {number}
 */
var myPow = function(x, n) {
     function dp(x, n, memo) {
        if (n === 0) return 1.0;
        if (memo[n]) return memo[n];

        const half = dp(x, Math.floor(n / 2), memo);
        memo[n] = half * half;

        if (n % 2 === 1) memo[n] *= x;
        return memo[n];
    }

    const memo = {};
    if (n < 0) {
        x = 1 / x;
        n = -n;
    }

    return dp(x, n, memo);
}

Time Complexity: O(log n)

Space Complexity: O(log n)
