Intuition ✨

The key idea to solve this problem is based on Divide and Conquer. The problem asks to return all possible results from computing different ways to group numbers and operators in a mathematical expression. Each operator can split the expression into two parts, and we can recursively compute the result for each part.

Here's the approach:
- Split the expression at each operator (+, -, *) and recursively compute the results for the left and right parts.
- Combine the results from the left and right parts based on the current operator.

This way, we compute all possible combinations and store intermediate results using memoization to avoid redundant calculations.

Approach

  1. Divide and Conquer:
    - For each operator in the string, split the expression into two parts: left and right.
    - Recursively compute all possible results for the left and right parts.
    - Combine the results of the left and right parts using the current operator.

  2. Memoization:
    - Since the same sub-expression may be encountered multiple times, we use a hash map (unordered_map) to store the results of already computed sub-expressions. This avoids recalculating the results for the same expression, improving efficiency.

  3. Base Case:
    - If the expression contains only a single number, return that number as the only result.

Complexity

Time Complexity ⏳

  • O(3^n): The complexity arises from the number of ways to split the expression at operators and the recursive nature of the solution.

Space Complexity

  • O(n): Space for storing intermediate results in the memoization table and recursive stack depth.

Diagram Representation

Here’s a more visually appealing diagram representation of the recursive steps to solve the problem using Divide and Conquer:

                       "2-1-1"
                      /       \\
                    "2"     "1-1"
                            /    \\
                          "1"    "1"

Computation Paths:
1. ((2 - 1) - 1)  → 0
2. (2 - (1 - 1))  → 2

Each node in this tree represents a recursive division of the expression at an operator, and the arrows show the progression as we break down the expression into smaller parts. Finally, the results are combined from the bottom up to compute the possible outcomes.

Expression Breakdown ️

  1. Split at the first '-':
    - Left Sub-expression: "2" → [2]
    - Right Sub-expression: "1-1" → Breakdown again at '-':
    • Left Sub-expression: "1" → [1]
    • Right Sub-expression: "1" → [1]

Combining 1 - 1 gives [0].

  1. Now combine the results for the original split "2-1-1":
    - Left Sub-expression: [2]
    - Right Sub-expression: [0]

Applying 2 - 0 results in [2].

  1. Split again at the second '-':
    - Left Sub-expression "2-1" → [1] (calculated previously)
    - Right Sub-expression "1" → [1]

Applying 1 - 1 results in [0].

Final Results:

  • Results from the two computation paths:
    1. ((2 - 1) - 1) → 0
    2. (2 - (1 - 1)) → 2

Thus, the final output is [0, 2].

vector<int> solve(string s)
{
    vector<int> ans;

    {

            for(auto x : left)
            {
                for(auto y : right)

                    else if(s[i] == '-') ans.push_back(x - y);
                    else ans.push_back(x * y);
                }
            }
        }
    }


    if(ans.empty()) ans.push_back(stoi(s));

}

unordered_map<string,vector<int>> m;
vector<int> solveTopDown(string s)
{
    vector<int> ans;
    if(m.find(s) != m.end()) return m[s];

    for(int i = 0; i < s.length(); i++)
    {

import java.util.HashMap;
import java.util.List;
import java.util.ArrayList;

class Solution {
    HashMap<String, List<Integer>> m = new HashMap<>();

    public List<Integer> solveTopDown(String s) {
        if (m.containsKey(s)) return m.get(s);

        List<Integer> ans = new ArrayList<>();
        for (int i = 0; i < s.length(); i++) {
            char c = s.charAt(i);
            if (c == '+' || c == '-' || c == '*') {
                List<Integer> left = solveTopDown(s.substring(0, i));
                List<Integer> right = solveTopDown(s.substring(i + 1));

                for (int l : left) {
                    for (int r : right) {
                        if (c == '+') ans.add(l + r);
                        else if (c == '-') ans.add(l - r);
                        else ans.add(l * r);
                    }
                }
            }
        }
        if (ans.isEmpty()) ans.add(Integer.parseInt(s));
        m.put(s, ans);
        return ans;
    }

class Solution:
def init(self):
self.memo = {}

def solveTopDown(self, s):
    if s in self.memo:
        return self.memo[s]

    ans = []
    for i in range(len(s)):
        if s[i] in "+-*":
            left = self.solveTopDown(s[:i])
            right = self.solveTopDown(s[i+1:])

            for l in left:
                for r in right:
                    if s[i] == '+':
                        ans.append(l + r)
                    elif s[i] == '-':
                        ans.append(l - r)
                    else:
                        ans.append(l * r)

    if not ans:
        ans.append(int(s))

    self.memo[s] = ans
    return ans

def diffWaysToCompute(self, expression: str):
    return self.solveTopDown(expression)

var diffWaysToCompute = function(expression) {
    const memo = new Map();

    // Helper function to recursively solve sub-expressions
    function solve(expr) {
        // If the result for the current expression is already computed, return it
        if (memo.has(expr)) return memo.get(expr);

        const results = [];

        // Traverse through the expression
        for (let i = 0; i < expr.length; i++) {
            const char = expr[i];

            // If the current character is an operator, split the expression
            if (char === '+' || char === '-' || char === '*') {
                // Divide into left and right sub-expressions
                const left = solve(expr.slice(0, i));
                const right = solve(expr.slice(i + 1));

                // Combine results from both sides based on the operator
                for (const l of left) {
                    for (const r of right) {
                        if (char === '+') {
                            results.push(l + r);
                        } else if (char === '-') {
                            results.push(l - r);
                        } else if (char === '*') {
                            results.push(l * r);
                        }
                    }
                }
            }
        }

        // If the expression is a number, convert it to a number and return it
        if (results.length === 0) results.push(parseInt(expr));

        // Memoize the result for the current expression
        memo.set(expr, results);
        return results;
    }

    return solve(expression);
};
