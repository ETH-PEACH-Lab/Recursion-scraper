Problem: 24. 两两交换链表中的节点

[TOC]

思路

依题意把链表里每两个结点位置相互交换，可以递归实现，通过实现交换前两个结点，然后递归把第三个结点传进去当作第一个结点，从而可以实现全部链表的结点的两两交换。

解题方法

通过递归实现交换前两个结点，然后递归把第三个结点传进去当作第一个结点，从而实现全部链表的结点的两两交换。


t1为第二个结点

t2为第三个结点

t1的下一个结点指向第一个结点，也就是第二个指向第一个结点

进入递归，第三个结点变为当前结点，t1变为当前结点的下一个结点，也就是第四个结点。上一轮递归开始时的第一个结点指向这轮递归的t1结点，也就是第一个结点指向第四个结点,继续递归，直至链表全部转换完毕。

复杂度

  • 时间复杂度:

    $O(n)$

  • 空间复杂度:

    $O(n)$

Code

```Java []

/*
* Definition for singly-linked list.
* public class ListNode {
* int val;
* ListNode next;
* ListNode() {}
* ListNode(int val) { this.val = val; }
* ListNode(int val, ListNode next) { this.val = val; this.next = next; }
* }
/
class Solution {
public ListNode swapPairs(ListNode head) {
//如果当前结点为空或当前结点的下一个结点为空 return
if(head == null || head.next ==null) return head;

    ListNode t1 = head.next;    //t1为当前结点的下一个结点，也就是第二个结点
    ListNode t2 = t1.next;      //t2为当前结点后的第三个结点
    t1.next = head;    //第二个结点的下一个结点为第一结点
    head.next = swapPairs(t2); //当前结点的下一个结点指向第三个结点传进去后返回的结点，实际也就是第四个结点。
    return t1; //返回第二个结点，也就是交换后的第一个结点
}

}
```
