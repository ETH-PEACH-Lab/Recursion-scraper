递归的核心思想

一个大问题可以分解为一层层的小问题 每一个问题的处理方法完全一样

拿斐波那契数列举例：

已知：F(0) = 0; F(1) = 1;

F(n) = F(n - 1) + F(n - 2) (n > 1)

求F(6)？

F(6) = F(5) + F (4) 那F(5)、F(4)分别是多少？

F(5) = F(4) + F(3) 那F(4)、F(3)分别是多少？

F(4) = F(3) + F(2) 那F(3)、F(2)分别是多少？

F(3) = F(2) + F(1) 那F(2)、F(1)分别是多少？

F(2) = F(1) + F(0) 那F(1)、F(0)分别是多少？

得到F(1)和F(0)的值-->得到F(2)的值-->得到F(3)的值-->得到F(4)的值-->得到F(5)的值-->得到F(6)的值

可以看到

F(6)等于多少这个问题，被转化为一个更小的问题F(5)；

F(5)等于多少这个问题，被转化为一个更小的问题F(1);

...

直到有一个问题得到解决

F(2)等于多少这个问题，根据初始条件可以解决。

解决之后再把小问题的答案拿去解决大问题

F(2)的答案拿去解决F(3)是多少的问题

F(3)的答案拿去解决F(4)是多少的问题

...

最终得到F(6)的答案

大问题可以被分解为一层层的小问题，而且每一层问题的处理方式完全一样，这种情况可以用递归。

看图理解：用栈的方式实现递归。每一层都是取上两层值之和得到该层的结果，即每层的处理方式完全一样。

看图理解：大问题可以被分解为一层层小问题。

两个重点：

  1. 一定要有一个小问题有合法答案，不然递归没完没了了，会出现栈溢出的问题。
  2. 既然每一层的处理方式一样，那么我的递归逻辑只需要关注一层的处理逻辑即可。其他层只需要调用同样的方法即可。

如何写递归

书写递归函数之前需要明确三个要素：

  1. 参数和返回值【参数：处理该层递归逻辑需要用到下一层的什么信息 比如处理斐波那契问题求f(n)就需要知道f(n-1)和f(n-2)的值；返回值：上一层需要这一层提供什么信息 比如求f(n+1)需要第n层提供f(n)的值的信息】

  2. 递归结束条件【即一定要有一个小问题有合法答案】

  3. 单层递归逻辑

时空复杂度分析

时间复杂度：O(T)

递归调用的次数为R；

单层递归逻辑的计算时间复杂度为O(s)；

则该递归算法的时间复杂度为O(T) = R * O(s)；

空间复杂度：O(T)

递归的深度 即为使用到的栈帧的个数R；

每一层递归的空间开销为O(s)；

则该递归算法的空间复杂度为O(T) = R * O(s)；

题目分析

面试题 08.06. 汉诺塔问题

这道题这是第三次做，终于找到自己的方法论。

同样的这道题也是一个大问题可以分为一层层的小问题，而且每一层问题的解决方式都一样。

通过观察上面n=1、2、3汉诺塔的处理过程，可以总结出这样的实现方法

目标：将A中的圆盘借助B转移到C

  • 把A的上面n - 1个圆盘借助C转移到B（n的问题转化为n - 1的问题）
  • 把A的第n个圆盘转移到C（转化为n = 1的问题）
  • 把B的上面n - 1个圆盘借助A转移到C（n - 1的问题）

n的问题转化为n - 1的问题，层层递归下去，最终可以转化为n = 1的问题。

根据上述的分析过程可知，汉诺塔问题处理方法满足递归的思想：一个大问题可以分解为一层层小问题【n的问题转化为n-1的问题，n-1的问题转化为n-2的问题...直到转化为n=1的问题】，且每层问题的处理方式一样。

递归三部曲：

  • 参数和返回值：参数 n， A， B， C 【把A的前n个元素借助B转移到C】

​ 返回值 无需返回值，参数传递的是列表A、B、C的引用地址，每一层修改的都是同样的三个列表

  • 递归结束条件：当n==1的时候，把A的最上面的一个元素直接转移到C上

  • 单层递归逻辑：

  • 把A的上面n - 1个圆盘借助C转移到B（n的问题转化为n - 1的问题）

  • 把A的第n个圆盘转移到C（转化为n = 1的问题）
  • 把B的上面n - 1个圆盘借助A转移到C（n - 1的问题）

实现代码

/**
 * 递归三部曲：
 * ①参数和返回值：参数
 *              n:把A的最上面n个元素借助B转移到C
 *              A: From List
 *              B: By List
 *              C: To List
 *            返回值 无需返回值 因为参数传递的是List的引用类型
 *                  每一层修改的都是同样的三个列表
 * ②递归结束条件：如果n==1 直接把A的最上面一个元素转移到C
 * ③单层递归逻辑：把A的前n-1个元素借助C转移到B
 *             把A的第n个元素转移到C
 *             把B中前n-1个元素借助A转移到C
 *
 * @param n
 * @param A
 * @param B
 * @param C
 */
public void move(int n, List<Integer> A, List<Integer> B, List<Integer> C) {
    // 递归结束条件
    if (n == 1) {
        C.add(A.remove(A.size() - 1));
        return;
    }
    // 单层递归逻辑
    // 把A的前n-1个元素借助C转移到B
    move(n - 1, A, C, B);
    // 把A的第n个元素转移到C
    C.add(A.remove(A.size() - 1));
    // 把B中前n-1个元素借助A转移到C
    move(n - 1, B, A, C);
}
public void hanota(List<Integer> A, List<Integer> B, List<Integer> C) {
    move(A.size(), A, B, C);
}

时间复杂度：O(2^n - 1)

空间复杂度：O(n) 递归最大深度为n，因此最多需要n个栈帧

常见错误

错误1：

/**
 * List中圆盘的排列[2, 1, 0]
 * 错误原因：C.add(A.remove(0));用这一句来实现[把A的第n个元素转移到C]
 * 问题在于，A此时不一定只有一个元素。
 * 我们的目的是把A的最上面的一个元素转移到C，C.add(A.remove(0))就默认了A[0]就是A列表的最后一个元素，即最上面的一个元素，也就是说认为A此时只有一个元素
 * 但A不一定只有一个元素的
 * 举个例子，我想把A[2, 1, 0]中最上面的元素转移到C，如果C.add(A.remove(0))转移的是2，而最上面的元素是0，所以应该使用C.add(A.remove(A.size() - 1));
 * 如果不能理解看图，或者自己用手模拟一下递归的过程即可 n=3就足够说明问题
 * @param n
 * @param A
 * @param B
 * @param C
 */
public void move(int n, List<Integer> A, List<Integer> B, List<Integer> C) {
    // 递归结束条件
    if (n == 1) {
        C.add(A.remove(0));
        return;
    }
    // 单层递归逻辑
    // 把A的前n-1个元素借助C转移到B
    move(n - 1, A, C, B);
    // 把A的第n个元素转移到C
    C.add(A.remove(0));
    // 把B中前n-1个元素借助A转移到C
    move(n - 1, B, A, C);
}

错误2：

/**
 * 错误原因：move2方法每次都A的全部元素转移到C
 * 存在一种情况A[1] C[3, 0] 目的是把B放在C的部分[0]移到A，而实际执行是把C的全部[3, 0](包含B放在C的部分[0]以及C原本就有的部分[3]移到A)
 * 就会出现A[1, 3, 0]的错误 最终导致stackOverflow的报错
 * @param A
 * @param B
 * @param C
 */
public void move(List<Integer> A, List<Integer> B, List<Integer> C) {
    // 递归结束条件
    if (A.size() == 1) {
        C.add(A.remove(A.size() - 1));
        return;
    }
    // 单层递归逻辑
    // 把A的前n-1个元素借助C转移到B
    move(A, C, B);
    // 把A的第n个元素转移到C
    C.add(A.remove(A.size() - 1));
    // 把B中前n-1个元素借助A转移到C
    move(B, A, C);
}

/**
  * 合并两个有序链表：
  * 找到list1和list2中val小的结点，作为合并链表的头结点
  * list1.val < list2.val  --> list1作为合并链表的头结点 并且合并list1.next和list2 合并结果拼接到list1头结点上
  * list1.val >= list2.val --> list2作为合并链表的头结点 并且合并list2.next和list1 合并结果拼接到list2头结点上
  *
  * 所以可以发现 满足递归的思想：一个大问题分解为一层层小问题 且每层问题的处理方式一样 每次只关注当前层(list1和list2当前头节点的val比较)
  * 递归三部曲：
  * ①参数和返回值 参数 list1和list2
  *             返回值 list1和list2两个链表合并之后的头节点
  * ②递归结束条件 list1==null --> return list2
  *              list2==null --> return list1
  * ③单层递归逻辑
  *      找到list1和list2中val小的结点，作为合并链表的头结点
  *      list1.val < list2.val  --> list1作为合并链表的头结点 并且合并list1.next和list2 合并结果拼接到list1头结点上
  *      list1.val >= list2.val --> list2作为合并链表的头结点 并且合并list2.next和list1 合并结果拼接到list2头结点上
  *
  * 时间复杂度: 每层递归的时间复杂度为O(1) 最差情况下递归的深度为m+n(m、n分别为list1和list2的长度)
  *           综上 时间复杂度为O(m+n)
  * 空间复杂度: 每层递归的空间复杂度为O(1) 栈的最大深度为m+n 即最多要使用m+n个栈帧
  *           综上 空间复杂度为O(m+n)
  * @param list1
  * @param list2
  * @return
  */
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
    // 递归结束条件
    if (list1 == null) {
        return list2;
    }
    if (list2 == null) {
        return list1;
    }
    // 单层递归逻辑
    // 找到list1和list2中val小的结点 作为合并链表的头节点
    if (list1.val < list2.val) {
        // list1作为合并链表的头结点 并且合并list1.next和list2 合并结果拼接到list1头结点上
        list1.next = mergeTwoLists(list1.next, list2);
        return list1;
    } else {
        // list2作为合并链表的头结点 并且合并list2.next和list1 合并结果拼接到list2头结点上
        list2.next = mergeTwoLists(list1, list2.next);
        return list2;
    }
}

344 反转字符串

344. 反转字符串

这一道题也可以分为一层层小问题，且每层问题的处理方式都一样。

只不过该题层和层之间不需要进行结果的传递，每层处理好本层的事情即可。

举个例子：反转字符串”hello“

第一层 把第一个和倒数第一个两个元素进行交换

第二层 把第二个和倒数第二个两个元素进行交换

第三层 把第三个和倒数第三个元素进行交换

结束

可以看到，每层的处理方式一样，如果使用char[]数组进行字符的存储则不需要进行结果的传递，因为实际上每层都是在修改同一个对象，Java中方法的参数如果是引用类型，则传递的都是参数的地址。

按照写递归的三个要素来做这道题：

①参数和返回值：参数 要进行交换的元素的下标，存储字符串中所有字符的字符数组；返回值：无需返回值，因为参数中传递的是数组的地址，即每层修改的是同一个数组。

②结束条件：我们可以看到 假设index1和index2分别是要进行交换的两个元素的下标。index1每次都右移1位，index2每次都左移一位。当index1>=index2的时候就说明反转已经完成。此时可以结束递归

③单层递归逻辑：把index1和index2两个位置的元素进行交换

实现代码：

    /**
     * 反转字符串
     * 设置leftIndex和rightIndex 每层只关注leftIndex和rightIndex两个位置的元素进行交换
     * leftIndex++ rightIndex--
     *
     * 递归三部曲：
     * ①参数和返回值：参数 数组s；要进行交换的两个位置下标leftIndex、rightIndex
     *             返回值 无需返回值 因为数组参数传递的是数组的地址 即每一层修改的都是同一个数组
     * ②递归结束条件：leftIndex>=rightIndex  说明反转完成 直接return
     * ③单层递归逻辑：交换leftIndex和rightIndex两个位置的元素
     *              leftIndex++ rightIndex-- 进行下一层的元素交换
     *
     * 时间复杂度: 单层递归时间复杂度O(1) 递归层数(n+1)/2
     *           综上 时间复杂度为O(n)
     * 空间复杂度: 单层递归空间复杂度O(1) 递归深度(n+1)/2 最多需要(n+1)/2个栈帧
     *           综上 空间复杂度为O(n)
     * @param s
     */
    public void reverse(char[] s, int leftIndex, int rightIndex) {
        // 递归结束条件
        if (leftIndex >= rightIndex) {
            return;
        }
        // 单层递归逻辑
        char tmp = s[leftIndex];
        s[leftIndex] = s[rightIndex];
        s[rightIndex] = tmp;
        leftIndex++;
        rightIndex--;
        reverse(s, leftIndex, rightIndex);
    }
    public void reverseString(char[] s) {
        reverse(s, 0, s.length - 1);
    }

24. 两两交换链表中的节点

24. 两两交换链表中的节点

同样的这一题也可以把大问题分为一层层的小问题，并且每一层的解决方式完全一样。

①参数和返回值：参数：当前要进行交换的两个节点中的第一个；返回值：交换之后位于链表前面的那个节点，方便连在前面的节点后面；

②结束条件：参数传来的节点node为null；或者 node.next为null 此时只剩一个节点 也无需交换

③单层递归逻辑：同图片

实现代码：

public ListNode swapPairs(ListNode head) {
    // 递归结束条件
    if (head == null || head.next == null) {
        return head;
    }

    // 单层递归逻辑
    ListNode p = head;
    ListNode q = p.next;
    ListNode m = q.next;
    q.next = p;
    p.next = swapPairs(m);
    return q; // 相当于图片中的p = p.next 图片为了便于说明 则p = p.next这样表示
}

时间复杂度:递归深度：(N+1)/2；单层的时间复杂度：O(1)；因此总的时间复杂度为(N+1)/2 * O(1) ≈ O(N)

空间复杂度:最深需要用到(N+1)/2个栈帧，故时间复杂度为O(N)

104. 二叉树的最大深度

求一棵树的最大深度

​ ---》 Max(左子树最大深度，右子树最大深度) + 1

​ 左子树的最大深度

​ ---》 Max(左子树的左子树的最大深度，左子树的右子树的最大深度) + 1

​ 右子树的最大深度

​ ---》 Max(右子树的左子树的最大深度，右子树的右子树的最大深度) + 1

​ .... 直到一个子树为null 返回0

所以这道题也满足一个大问题，可以分解为一层层的小问题，而且每个小问题的解决方式完全一致。

①参数和返回值：参数：树的根节点；返回值：该树的最大深度

②结束条件：当前参数传入的根节点为null，返回0即可

③单层递归逻辑：

depth = Max(MaxDepth(root.left), MaxDepth(root.right)) + 1

实现代码：

public int maxDepth(TreeNode root) {
    if (root == null) {
        return 0;
    }
    return Math.max(maxDepth(root.left), maxDepth(root.right)) + 1;
}

时间复杂度：单层递归的时间复杂度为O(1)，最坏情况下，树呈链状，此时递归的最大深度为n，故时间复杂度为O(n)。如果树为平衡二叉树，则最大递归深度为树的高度logn，此时时间复杂度为O(logn)

空间复杂度：最坏情况下，树呈链状，此时递归的最大深度为n，此时栈中有n个栈帧，空间复杂度为O(n)。如果树为平衡二叉树，则最大递归深度为树的高度logn，此时空间复杂度为O(logn)
