递归

以字符串"aaa"和模式串"ab*a*c*a"为例，递归调用树如下：

这里我们有两种匹配方式：
- 单个匹配，如果两个字符相同，或者模式串当前是万能字符.，则匹配成功，然后继续递归比较 s[i + 1:] 和p[i + 1:]
- 如果模式串后面跟了"*"，这又分为两种情况：
- (1)如果s[i]和p[i]不等(比如aa和b这种情况)，则将b*忽略掉，也就是继续递归比较s和p[i + 2:]
- (2)如果p[i]和s[i]相等(比如aa和a这种情况)，我们可以选择忽略a*，也就是执行(1)，也可以将字符串中的a忽略掉，继续递归比较s[i + 1:]和p

所以递归执行，需要注意当匹配*时候，走的两条分支

代码实现：
```java []
class Solution {
public boolean isMatch(String s, String p) {
return dfs(new HashMap(), s, p);
}

private boolean dfs(Map<Pair,Boolean> cache, String s, String p) {
    Pair pair = new Pair(s,p);
    //加个记忆化，不然纯递归会超时的
    if(cache.containsKey(pair)) {
        return cache.get(pair);
    }
    if(p.isEmpty()) {
        return s.isEmpty();
    }
    //检查s[0]和p[0]是否匹配
    boolean isFirstMath = s.length() > 0 && (p.charAt(0) == '.' || p.charAt(0) == s.charAt(0));
    //检查模式串的下个字符是否为"*
    boolean isMatchAny = p.length() > 1 && p.charAt(1) == '*';
    if(isMatchAny) {
        //如果包含"*"，可以忽略掉当前字符+*
        //也可以忽略掉字符串中的当前字符(如果能匹配上)
        cache.put(pair, dfs(cache, s, p.substring(2)) || (isFirstMath && dfs(cache, s.substring(1), p)) );
    }  
    else {
        //单个字符匹配的情况
        cache.put(pair, isFirstMath && dfs(cache, s.substring(1), p.substring(1)) );
    }
    return cache.get(pair);
}

}

class Solution(object):
    def isMatch(self, text, pattern):       
        d = {}
        def dfs(s,p):
            # 加个记忆化，不然纯递归会超时的
            if (s,p) in d:
                return d[s,p]
            if not p:
                return not s
            # 检查s[0]和p[0]是否匹配    
            is_first_match = len(s) > 0 and p[0] in (s[0],".")
            # 检查模式串的下个字符是否为"*
            try_match_any = len(p) >= 2 and p[1] == "*"
            if try_match_any:
                # 如果包含"*"，可以忽略掉当前字符+*
                # 也可以忽略掉字符串中的当前字符(如果能匹配上)
                d[s,p] = dfs(s,p[2:]) or (is_first_match and dfs(s[1:],p))
            else:
                # 单个字符匹配的情况
                d[s,p] = is_first_match and dfs(s[1:],p[1:])
            return d[s,p]
        return dfs(text,pattern)

动态规划

这里参考了官方解法(稍作改动)，算是对官方解加上一个详细的图解说明。原文参见这里

动态规划中的 dp数组，dp[i][j] 表示表示字符串 S 的前 i 位 和 模式串 P 的前 j 位是是否匹配。

比较单个字符

先以单个字符匹配来说，递归解的时候，如果字符串S和模式串P的当前字符是相等的，或者模式串P当前是.，就执行了这么一句: 

is_first_match and dfs(s[1:],p[1:])

也就同时去掉S和P的当前字符，继续递归比较后面的；对于动态规划来说，其转移方程就相当于：

dp[i][j] = dp[i - 1][j - 1]
dfs(s[1:],p[1:])

也就是dp[i][j]的值，是看S的上一个字符是否和P的上一个字符相等，对比下动态规划和递归，其实他们是很类似的。

比较*

再看来*这种情况，这是最复杂的：
在递归的程序中，分为两种情况

dfs(s,p[2:]) or (is_first_match and dfs(s[1:],p))

递归比较的时候，我们是往后看了一步，而动态规划中，我们是往前看的。也就是模式串P当前的字符是*，我们需要往前看一个字符，看P[j - 1]是否跟S[i]匹配：
如果不匹配呢，就相当于递归中的这句：dfs(s,p[2:])，直接去掉模式串P中的两个字符，然后继续递归比较。
对应到动态规划中，dp[i][j]的取值就依赖于dp[i][j - 2]。
同样也是把P的前两个字符给忽略掉了，仔细比较递归和动态规划这两句，发现他们异曲同工之妙：

dfs(s,p[2:])               递归，忽略掉P的两个字符(普通字符和*)，继续递归比较
dp[i][j] = dp[i][j - 2]    动态规划，这里i不动，j-2，忽略掉前一个普通字符和当前*

如果匹配呢，递归代码中除了dfs(s,p[2:])还有这么一句：
is_first_match and dfs(s[1:],p)，去掉了S的当前字符，然后继续递归比较后面的。
对应到动态规划中，dp[i][j]的取值就依赖于dp[i][j - 2] || dp[i - 1][j]。
这跟递归实际上很类似，匹配的时候有两条路径可以走：
- 可以忽略掉P的两个字符，前一个字符+当前的*
- 也可以忽略掉S的当前字符

再比较下递归和动态规划的代码，其实也是很相似的：

dfs(s,p[2:]) || dfs(s[1:],p)              递归，忽略P的两个字符(普通字符和*)，或忽略S的一个字符
dp[i][j] = dp[i][j - 2] || dp[i - 1][j]   动态规划，忽略前一个普通字符和当前*，或忽略S当前字符

到这里，动态规划的核心逻辑就完成了，但是需要补充一下边界问题。
一般边界问题都是 字符串S 为空，或者 模式串P 为空这种情况。
比如 字符串S 和 模式串P 都为空，那么自然是匹配的，即dp[0][0] = true

如果是 模式串P 为空，字符串S 不空那肯定是无法匹配了
如果是 字符串S 为空，但是 模式串 P 不为空，比如

S = ""
P = "a*b*

由a*可以作为整体全部忽略、b*也可以作为整体全部忽略，所以上述情况就是true，需要处理下这种边界问题。
具体请看代码实现吧。

```java []
class Solution {
public boolean isMatch(String s, String p) {
int n = s.length();
int m = p.length();
boolean[][] dp = new boolean[n + 1][m + 1];
//S和P都为空时，匹配
dp[0][0] = true;
//当S为空，P不空，要看P是否为 ab这种结构
for(int j = 1; j <= m; ++j) {
if(p.charAt(j - 1) == '') {
dp[0][j] = dp[0][j - 2];
}
}
for(int i = 1; i <= n; ++i) {
for(int j = 1; j <= m; ++j) {
//当前字符串是，可以将 字符+全部忽略掉，取f[i][j-2]的值
//或者看模式串P的上一个字符串是否能跟字符串S匹配
//如果能匹配上，可以忽略掉模式串的 字符+，也可以忽略掉字符串S中的当前字符
//这里其实跟递归一样，也有两条转移路径
if(p.charAt(j - 1) == '*') {
if(p.charAt(j - 2) == s.charAt(i - 1) || p.charAt(j - 2) == '.') {
dp[i][j] = dp[i - 1][j] || dp[i][j - 2];
}
else {
dp[i][j] = dp[i][j - 2];
}
}
//单个字符匹配的情况
else {
if(p.charAt(j - 1) == s.charAt(i - 1) || p.charAt(j - 1) == '.') {
dp[i][j] = dp[i - 1][j - 1];
}
}
}
}
return dp[n][m];
}
}

class Solution(object):
    def isMatch(self, s, p):
        n = len(s)
        m = len(p)
        dp = [[False] * (m + 1) for _ in range(n + 1)]
        #S和P都为空时，匹配
        dp[0][0] = True
        #当S为空，P不空，要看P是否为 a*b*这种结构
        for j in range(1, m + 1):
            if p[j - 1] == "*":
                dp[0][j] = dp[0][j - 2]
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                #当前字符串是*，可以将 字符+*全部忽略掉，取f[i][j-2]的值
                #或者看模式串P的上一个字符串是否能跟字符串S匹配
                #如果能匹配上，可以忽略掉模式串的 字符+*，也可以忽略掉字符串S中的当前字符
                #这里其实跟递归一样，也有两条转移路径
                if p[j - 1] == "*":
                    if p[j - 2] in (s[i - 1], "."):
                        dp[i][j] = dp[i - 1][j] or dp[i][j - 2]
                    else:
                        dp[i][j] = dp[i][j - 2]
                #单个字符匹配的情况        
                else:
                    if p[j - 1] in (s[i - 1], "."):
                        dp[i][j] = dp[i - 1][j - 1]
        return dp[-1][-1]
