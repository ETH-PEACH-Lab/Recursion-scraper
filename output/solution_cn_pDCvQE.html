方法一、递归

都说递归玄学，我也认为是的。但是满足递归必须具备两个条件。但是定义递归函数更难，就本题而言，就是如何将A上所有盘子移动到C。
1. 递归链：要将n个盘从A移动到C，首先需要把上面n-1个小盘子移走（一定放在B上），然后将第n个大盘从A移动到C。那么怎么把A上面n-1个盘子移动到 B 呢？这又回到该问题定义，因此使用玄学递归出现了。（因为 A 盘最底下那个是最大，可以认为“消失”了）
2. 递归出口（特例）：很明显当只有一个盘从源移动到目的地时，只需要一次即可完成。

例如n = 4 的递归图解：

else:

C.append(A.pop())
hanoi(n - 1, B, A, C) # 将n-1个盘从B->C，借助A
hanoi(len(A), A, B, C)

### 方法二、迭代实现
迭代就是上面递归系统栈由自己维护。熟悉二叉树的**中序遍历**的朋友们一定决定上面很眼熟吧。很明显就是维护递归函数退栈的记录问题。

为描述方便，我们将上面的两个子函数进行命名，从上往下依次为子函数①，子函数②。我们就是想知道**同层子函数①什么时候调用结束返回到本层**，这个时候涉及到`C.append(A.pop())` 和本层子函数②的调用。



**灵感来源**：二叉树后序遍历插入`NULL`指针标记右子树搜索完毕（由于先左后右，标记后直接打印父节点值）。



因此我们也可以在子函数①执行完毕后汇报！也就是**将子函数①压入栈之前，先将父函数信息压入栈内**，由递归函数参数可知，我们至少需要维护`n, src, tmp, dest`参数，现在我们加一个参数`which`构成`(n, src, tmp, dest, which)`。
+ `which = 0`：表示父函数，也即需要再次递归。
+ `which = 1`：表示这层是子函数①执行完毕后退栈，也就是需要将最大的盘移到目的地。

假设父函数的信息为`(n, src, tmp, dest, 0)`，当要执行子函数①时，我们压入`(n, src, tmp, dest, 1)`表示子函数①执行完毕了，然后再压入`(n - 1, src, dest, tmp, 0)`表示子函数①将要执行。具体细节部分看下方代码。

```python3 []
class Solution:
    def hanota(self, A: List[int], B: List[int], C: List[int]) -> None:
        """
        Do not return anything, modify C in-place instead.
        """
        stk = [(len(A), A, B, C, 0)]
        while stk:
            n, src, tmp, dest, which = stk.pop()
            if which == 0:  # 调用者
                if n == 1:  # 递归出口
                    dest.append(src.pop())
                else:  # 将两个子函数放入栈内
                    # stk.append((n - 1, src, tmp, dest, 2))  # 子函数②执行完毕退栈后（这里没必要写）
                    stk.append((n - 1, tmp, src, dest, 0))  # 先放子函数②

                    stk.append((n - 1, src, tmp, dest, 1))  # 子函数①执行完毕退栈，保留原调用函数信息
                    stk.append((n - 1, src, dest, tmp, 0))  # 后放子函数①
            elif which == 1:  # 子函数①结束，打印移动信息
                dest.append(src.pop())

复杂度分析：
+ 时间复杂度：一层递归函数启用两个子函数，因此为$O(2^n)$。
+ 空间复杂度：与递归层数相关。
