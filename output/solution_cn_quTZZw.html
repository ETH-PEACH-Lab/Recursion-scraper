递归找解法的思路
👤 keyyuan 👍 0 2023-05-23 🖼 ↗ 查看原 Solution

分析

首先这个问题是有很明显的递归的特点的，以 $n = 8,m = 3$ 为例，其获胜者也是下一组 $n = 7,m = 3$ 的获胜者（原问题的子问题），如果可以找到这两个获胜者之间的数量关系，就可以递归地解决原问题。

这里不要想着直接往后算，想清楚两层之间的关系，再找到边界条件，递归的问题就解决了。
如果还是一味地试图把完整过程想一遍，说句不礼貌的：

脑子能压几个栈啊

上图表示了从 $f(8,3)$ 到 $f(7,3)$ 的过程：

  • 第一个表格是原始的下标和原始的成员，标红的 $C$ 表示是第一轮出局
  • 下一轮从下一个位置 $D$ 开始，用第二个表格表示：
    • 在新的一轮 $f(7,3)$ 中， $D$ 的标号是 $0$ ，在原数组中的标号是 $3$ ；
    • 且第一轮跳过的 $A,B$ 要补在 $I$ 后面，其原始标号分别为 $0,1$，在新的组中，其标号分别为 $5,6$
    • 第二个表格的第一行和第二行分别为在递归中出现的新编号和原始编号

现在需要明确如何将新编号对应到原始编号上，也就是说：如果已知 $y$ 是 $f(7,3)$ 的结果，如何将其对应到 $f(8,3)$ 中的相应位置 $x$ 上。

观察第二个表格表示标号的前两行，首先有一个加 $3$ 的行为，上一轮的前三个都被跳过了，$0$ 表示原先的 $3$ ，将 $f(7,3)$ 的结果范围从 $[0,6]$ 映射到了 $[3,9]$ ，这是还有 $8,9$ 两个位置在 $f(8,3)$ 的结果中是不可能出现的，观察后，应当是对 $8$ 取余（这里的 $8$ 为上一轮的总数），就可以将 $8,9$ 对应到上一组的 $0,1$ 上。

综上，我们可以得出两组结果的对应关系，$x = (y+3)\%8$，即

f(8,3) = (f(7,3)+3)\%8

更通用的，可以写成是

f(n,m) = (f(n-1,m)+m)\%n

现在还差一个结束递归的终止条件，如果只剩一个，那么自然是这个最后被留下了，返回 $0$ 。到这里，可以写出完整的表达式：

f(n,m) = \begin{cases}
0 & n = 1 \
(f(n-1,m)+m)\%n & n>1
\end{cases}

之后要写成递归或者改为迭代都是较为容易的

程序

# 递归
class Solution:
    def lastRemaining(self, n: int, m: int) -> int:
        return (self.lastRemaining(n-1,m)+m)%n if n>1 else 0

# 迭代
class Solution:
    def lastRemaining(self, n: int, m: int) -> int:
        x = 0
        for k in range(2,n+1):
            x = (x+m)%k
        return x
