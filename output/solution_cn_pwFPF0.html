解法 1 —— 重新构建链表

思路

我们顺着原链表走一遍, 把原链表的每个节点复制一份, 并让其指针指向上一个复制的节点, 例如：
原链表：5 -> 4 -> 3 -> 2 -> 1 -> nullptr
第一轮复制: 5 -> nullptr
第二轮复制: 4 -> 5 -> nullptr
第三轮复制: 3 -> 4 -> 5 -> nullptr
第四轮复制: 2 -> 3 -> 4 -> 5 -> nullptr
第五轮复制: 1 -> 2 -> 3 -> 4 -> 5 -> nullptr
第六轮复制: 操作空指针, 以此为边界条件退出循环。

解题过程

值得注意的是, 我们要在一个循环里不断地建立新的节点, 必须使用节点指针的数组来保存这些节点指针, 这就要求我们要得到链表节点数的上界, 根据题意取为5000。

复杂度

  • 时间复杂度: $O(n)$

  • 空间复杂度: $O(n)$

Code

class Solution {
public:
    Solution() : _MaxListNumber(5000) {}

    ListNode* reverseList(ListNode* head) {
        if (head == nullptr)
            return nullptr;
        ListNode* newListArray[_MaxListNumber + 1];
        newListArray[0] = new ListNode(head->val);
        int i = 1;
        ListNode* cur = head->next;
        while (cur != nullptr) {
            newListArray[i++] = new ListNode(cur->val, newListArray[i - 1]);
            cur = cur->next;
        }
        return newListArray[i - 1];
    }

private:
    int _MaxListNumber;
};

解法 2 —— 双指针反转 next 指针方法

思路

我们用两个节点慢指针来夹住每个节点及其之前的节点, 其中较慢的一个是另一个的“阴影”, 即延迟一步, 然后用一个快指针来保存下一个节点(因为 next 指针已被修改, 无法通过 next 指针前往下一个节点)。

这样做的好处就是不需要消耗内存来建立新链表了, 也就是说这种方法是原地修改的。

复杂度

  • 时间复杂度: $O(n)$

  • 空间复杂度: $O(1)$

Code

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode *slow = nullptr, *fast = head;
        while (fast != nullptr) {
            ListNode* slowShadow = slow;
            slow = fast;
            fast = fast->next;
            slow->next = slowShadow;
        }
        return slow;
    }
};

解法 3 —— 递归

思路

递归的本质就是重复调用, 维持一个不断单调变化的结构, 此结构(称为循环不变量)具有在函数调用过程中不变的性质, 且单调变化会使此结构到达边值, 此时对边值的处理即为函数调用栈的出口(栈顶)。

解题过程

具体过程如下图所示:

函数调用栈为:

// node_i is the i_th call_stack parameter (head)
reverseList(node_0)
    reverseList(node_1 = node0->next)
        reverseList(node_2 = node_1->next)
            reverseList(node_3 = node_2->next)
                reverseList(node_4 = node_3->next)
                    reverseList(node_5 = node_4->next)
                    return rTail = node_5
                node_4->next->next = node_4
                node_4->next = nullptr
                return rTail = node_5
            node_3->next->next = node_3
            node_3->next = nullptr
            return rTail = node_5
        node_2->next->next = node_2
        node_2->next = nullptr
        return rTail = node_5
    node_1->next->next = node_1
    node_1->next = nullptr
    return rTail = node_5
node_0->next->next = node_0
node_0->next = nullptr
return rTail = node_5

写递归建议先设计调用栈再写函数。

复杂度

  • 时间复杂度: $O(n)$

  • 空间复杂度: $O(1)$

Code

class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        if (head == nullptr || head->next == nullptr) {
            return head;
        }
        ListNode* rTail = reverseList(head->next);
        head->next->next = head;
        head->next = nullptr;
        return rTail;
    }
};
