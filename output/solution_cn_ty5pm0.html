解题思路

本题解借鉴了 官方题解 的思想：
我们可以做这样的假设：

删除了第x个元素，
那么，下一轮将会从第x+1个元素开始遍历
那么，下一个要删除的元素 将会是 (X+1-1 + m) % n

为什么要给 (x+1) 减1 呢？

因为我们将 本轮查到的元素删除了，后面的元素 自动补在了 被删除的元素的位置（左移，下标-1）
因此，要给x+1的下标做 减1运算

根据上述推导，我们可以得知：

((n-1)个元素情况下，剩余元素的下标 + m) % n

因此，我们可以使用递归，来计算 (n-1)个元素情况下，剩余元素的下标

代码

class Solution {
    public int lastRemaining(int n, int m) {
        if (n <= 1) {
            return 0;
        }

        int index = lastRemaining(n - 1, m);    // 查找 有n-1个数字 的情况下，删除第m个数字 的剩余元素
        return (m + index) % n; // 根据 上一轮的计算结果，计算 本轮剩余元素
    }
}
