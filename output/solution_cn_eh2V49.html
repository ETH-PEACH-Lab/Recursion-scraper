递归的解释说明

解题思路

如果一个从来没有看过汉诺塔，或者没有了解过的人。我觉得看到题目的第一反应是，这个问题就是把集合A的数据，原封不动的移到集合C去。所以应该会有以下处理。

public void Hanota(IList<int> A, IList<int> B, IList<int> C) {
    for(int i=0;i<A.Count();i++){
        C.Add(A[i]);
    }
    //OR
    //C = A;
}

等到看了别人的题解后，应该终于明白是要干什么了，大概率会看到这么一个方法：move(n, A, B, C)，就是移动盘子，不过还是云里雾里，n是啥意思，为什么要传入A,B,C。怎么用这个A,B,C 来代表盘子被移动呢？

这里给出一个自己的看法，不管多少层的盘子，就把它当成只有两层，一层是最下层(也就是第N层)，另外就是一摞共同构成的一层(也就是N-1层)，递归有两个重要地方。

1.每次要处理的相同事情。

2.什么是终止条件。

下面举2个例子分别是N=2和4。

当N=2时，我们把 1从A=>B，把2从A=>C，在把1从B=>C，总共3步，但是这里有个疑问，好像A,B,C没有起到中转的作用，别急我们接着看N=4的情况。

在N=4中，我们把1,2,3 一起从A=>B。
1. 注意第一个箭头位置，1,2,3怎么从A=>B呢？我们需要往前推演一步，把B当成目标，C当成中间层，所以问题就变成了如何让1,2从A=>C，好了如果1,2要从A=>C，是不是又变成了我们上一个N=2的问题。
2. 在看箭头2,假设前面的的问题都已经解决了，这个时候4也直接从A=>C，我们最后到了把1,2,3从B=>C的情况，这个时候我们需要往后延伸一步，B现在是起始位置，C是最终位置,所以我们需要借助A来当中间者，我们需要把1,2从B=>A,再把3从B=>C,这一步好了后，我们会发现，1,2又回到了A，也就是我们最开始的N=2的情况

根据上面N=4的例子,我们发现.
1. 要把N个盘子从A=>C,我们需要把N-1个盘子先从A=>B,要想把N-1个盘子从A=>B，要把N-2个盘子先从A=>C，往前就开始套娃。
2. 要想把N-1个盘子最终从B=>C，先把n-2个盘子从B=>A，不然没法继续，往后也开始套娃。

在看看我们的移动函数move(n,开始，中间，目标)我们抓住上面的几个关键，注意不要把A,B,C默认当成开始，中间，目标，只有第一次被调用时，A,B,C=开始，中间，结束
1. 第一步 move(n-1,A,C,B) 把n-1从A往B
2. 两个操作，目标集合.Append(开始集合的最后一个) ，开始集合.Remove(开始集合的最后一个)
3. move(n-1,B,A,C)，把n-1从B往C。

终止条件就是n=1时，当剩下最后一个时，开始=>目标 （不要纠结A,B,C哪个是开始，哪个是目标，无所谓，最后开始集合中就剩一个了，肯定是往目标里面放的）。

这里记录一下自己的想法，还是有理解不到位的地方，也许下一次再做的时候，会有新的想法

代码

public class Solution {
    public void Hanota(IList<int> A, IList<int> B, IList<int> C) {
        Move(A.Count(),A,B,C);
    }
    private void Move(int count, IList<int> A, IList<int> B, IList<int> C)
    {
        if (count == 1)
        {
            C.Add(A[A.Count - 1]);
            A.RemoveAt(A.Count - 1);
            return;
        }
        Move(count - 1, A, C, B);
        C.Add(A[A.Count - 1]);
        A.RemoveAt(A.Count - 1);
        Move(count - 1, B, A, C);
    }
}
