不用位运算，帮助理清思路
👤 eternity-to 👍 17 2022-10-20 🖼 ↗ 查看原 Solution

先看看时空间复杂度的高低吧。


解题思路

首先先理清思路。

这道题观察一下数据，简单列举一下：
- n = 1 : 0
- n = 2 : 01
- n = 3 : 0110
- n = 4 : 01101001
到这里其实很清楚了，首先每一行的大小是上一行的两倍，且前半部分和上一行相同，后半部分也和上一行有关，上一行为 1 ，这一行就为 0，就这样相反添加。

所以我们拿一个字符串来拼接。代码如下

注意第一个代码仅仅是促进理解，当 n > 15 就会超时

代码

class Solution {
public:
    int kthGrammar(int n, int k) {
        // 这个代码仅仅是促进思路的理解
        string temp = "0";              // 第一行为 0 ，初始化
        for (int i = 2; i <= n; ++i) {  // 题中说索引从 1 开始，初始化temp，就是给第 1 行赋值，所以从第二行开始
            int len = temp.length();    // 得到上一行的长度，需要对上一行每一个元素进行反转
            for (int j = 0; j < len; ++j) {
                // 在当前尾部添加相反元素
                if (temp[j] == '0') temp = temp + '1';  
                else temp = temp + '0';
            }
        }
        return temp[k-1] - '0'; // 返回时注意返回数字类型
    }
};

到这里，把这个代码看懂，并且懂位运算的话就能看懂其他高手的位运算的方法的代码了。

思路优化

当然，看题解当然是想要能够提交正确啦，这里也换一个思路来优化上面的代码（同样不用位运算）
这里要用到递归，不过新手朋友也不用害怕，也能看懂。
上面的题解是正向的思维，先构造出来需要的东西。这里就是需要什么取什么的逆向思维。
- n = 1 : 0
- n = 2 : 01
- n = 3 : 0110
- n = 4 : 01101001
还是这个例子，我们把 k 考虑进去。

我们还是以上一行的大小为分界线。讨论k < 上一行的大小; k > 上一行的大小。这两种情况

例如：如果想要求 第 4 行的 第 6 个元素。
那第 6 个元素是 0，它是与上一行第 2 个元素相反的元素。也就是 与上一行的k - 上一行的大小个元素相反。————这是k > 上一行大小的情况
所以现在就需要知道第 3 行 第 2 个元素。当前k = 2,n = 3发现 k - 上一行的大小 < 0，所以应该是上一行的第 k 个元素的相同元素。————这是k < 上一行大小的情况

class Solution {
public:
    int kthGrammar(int n, int k) {
        return dfs(n, k);           // 想要得到第 n 行，第 k 个元素。
    }
    int dfs(int n, int k) {
        if(n == 1) return 0;        // 边界条件
        int len = pow(2, n - 2);    // 求上一行的大小
        if(k - len <= 0) return dfs(n - 1, k);  // k < 上一行大小的情况（直接返回，因为和上一行的同位置元素相同）
        else return dfs(n - 1, k - len) == 0 ? 1 : 0; // k > 上一行大小的情况（返回相反元素）
    }
};

新手朋友可以自己看着示例，写下来运行步骤，可能有利用理解递归的思路

最后再介绍一下逆向验证的思路。（这个可能对新手不太友好）
比如我假设第 n 行 第 k 个元素是 1，开始验证，直到最底层（第 1 行），如果一样，说明就是返回当前元素，否则返回相反元素。
这个思路也是我在宫水三叶那里看到的。大家想要理解这个思路可以去看看她的题解。

class Solution {
public:
    int kthGrammar(int n, int k) {
        return dfs(n, k, 0) == 1 ? 1 : 0;
    }
    int dfs(int n, int k, int cur) {
        if (n == 1) return cur;
        if ((k % 2 == 0 && cur == 0) || (k % 2 == 1 && cur == 1)) return dfs(n - 1, (k - 1) / 2 + 1, 1);
        else return dfs(n - 1, (k - 1) / 2 + 1, 0);
    }
};
