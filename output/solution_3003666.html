1. RECURSION

We can use Recursion to solve this problem.

And every Recursive problem has basically three things - 

1. Base Case
2. Recursive Call
3. Extra Calculations

is to just tell your function what it should do and Recursion will handle the rest. No need to think of the entire recursive call, how it happens etc.

Let's first define what our removeNodes() function actually does.

removeNodes() takes the head of a node and removes all the nodes which have a node with strictly greater value on right

Remember this above line.

Let's take the smallest possible case that we can have. WE might have a list with only one node. So in that case, we simply want to return because we know this is already a valid list and no need to remove anything. And that will be the base case. That is, the smallest possible valid value.

Now let's add one more node.

We have node1 -> node2

In this case, we just want to compare node1 with node2 and see whether node2 has a greater value. If yes, node1 will be removed. Otherwise, the list remains unchanged.

Now, let's add two more nodes now. 

We have node1 -> node2 -> node3

Now, let's break this problem into sub-problems. What if we first solve the part "node2 -> node3". So whatever result we get, it definitely will be present in the final result. Remember how we defined our function? We just pass it the head node and it handles the rest. So, here, we will simply call this as -> removeNodes(node2), passing it the head of the linked list "node2 -> node3".

And then, all that's left is to check whether "node1" itself needs to be removed or not. That is, whether the resulting node after we solve "node2 -> node3" has a greater value than "node1". Did you notice something? Isn't this the same thing that we did when we had two nodes only?

And that's how our Recursive function is going to work. You just need to correctly write the code for just one sub level and the Recursive function does the rest.

Now, no matter how big the input is, we can apply the same steps as above.

Suppose we have node1 -> node2 -> node3 -> node4 -> node5 -> node6

So, if we can solve the part "node2 -> node3 -> node4 -> node5 -> node6" first, then whatever result we get, we just need to compare the first node value from that result with the node1's value. And based on that, node1 will or will not be removed.

 def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:
        # Base case
        if not head.next: return head

        # Recursive call to remove every node (after head node) that has a strctly greater node to right of it
        # Whatever we get back, it will be appended after the head node
        head.next = self.removeNodes(head.next)

        # Now, we will compare the head node with the next node
        # so as to check if we want to remove head node as well
        if head.val < head.next.val: head = head.next

        return head

2. STACK

Another way to solve this problem is using a stack. Because, all we want to check for every node is whether it has a nearest greater element on its right. If it does, then this node should not be considered in the final linked list. And to efficiently check this, we can use a stack, a monotonic stack to be specific.

As we traverse the list, we will check if the nodes on the left are smaller or not. If yes, then it means they should not be in the final list so we should remove them. And by doing this, at the end, we will be left with just the nodes that the output linked list should have.

def removeNodes(self, head: Optional[ListNode]) -> Optional[ListNode]:

        # A Stack to quickly check if there is a greater value on right
        stack = []

        # Iterate over the list
        while head:

            # If there are nodes with smaller values, pop them
            while stack and stack[-1].val < head.val: stack.pop()

            # Push the current node in the stack
            stack.append(head)

            # Update the pointer
            head = head.next

        # The head of the new linked list
        head = stack[0]
        temp = head

        # Now, just join the nodes properly
        for i in range(1,len(stack)):
            temp.next = stack[i]
            temp = temp.next

        # Finally, return the head of the final linked list
        return head
