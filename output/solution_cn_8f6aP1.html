解题思路

递归分解，先计算所有的二位数、三位数......有多少个2，比如n=8765，就可以先确定在0-999的范围有多少个2，然后计算1000-8765有多少个2，当首位不为2时，比如1000-1999，4000-4999，这种区间的2的个数就等于0-999的个数，而这个在前面以经计算过，当首位是2时，就还需要加上从2000-2999的2的个数，特别的是，比如n=2765，要计算的是2000-2675的2的个数，上面的方法可以把最高位的所有情况都计算完，然后递归计算除去最高位的值，以n=8765为例，接下来递归计算765就好，765讨论完三位数的情况后，会递归计算65，再是5

代码

class Solution {
    public int numberOf2sInRange(int n) {
        if(n<=1) return 0;
        int bit=1,start=n;
        while(start>=10) {
            start=start/10;
            ++bit;
        } 
        if(bit==1) return 1;
        int[] num=new int[bit-1];
        num[0]=1;
        for(int i=1;i<bit-1;++i) num[i]=10*num[i-1]+(int)Math.pow(10,i);
        int max=n/(int)Math.pow(10,bit-1);
        if(max==2) return 2*num[bit-2]+numberOf2sInRange(n-max*(int)Math.pow(10,bit-1))+n-max*(int)Math.pow(10,bit-1)+1;
        else if(max==1) return num[bit-2]+numberOf2sInRange(n-max*(int)Math.pow(10,bit-1));
        else return num[bit-2]+(int)Math.pow(10,bit-1)+(max-2)*num[bit-2]+num[bit-2]
            +numberOf2sInRange(n-max*(int)Math.pow(10,bit-1));
    }
}
