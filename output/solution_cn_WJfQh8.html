剑指 Offer 25. 合并两个排序的链表

最初的思路误区

受剑指offer前几题的影响，第一眼想到的办法是快慢指针法，l1做母本正常遍历，逐步将l2的元素插入l1中，最后返回l1，这种思路不妥之处在于l1和l2无法判断谁是母本，把谁的元素插入谁才是最简便的思路。

所以此思路废弃

迭代法

更适合的思路应该是抛弃掉原本那两个链表结构，不在原有链表上进行操作，而是从头至尾重新规划出一个链表，并且在遍历两链表时指定新链表元素的顺序。

  • 引入伪头节点：由于初始状态新链表没有元素，头节点还要根据两个链表的元素大小来指定，这个步骤无法正常放入链表遍历的循环之中，所以定义一个辅助的头节点dummy，将其作为新链表的头节点，后续的所有节点均添加到他后面，返回时只需要返回dummy.next即可

dummy作为链表的伪头节点，在函数返回时使用，所以应新定义一个节点cur用来遍历，在最后当有任何一个链表遍历结束后，把另一个链表的所有内容直接加到新链表后面即可（因为二者本身已经是递增顺序）

public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
    ListNode dummy = new ListNode(-1);
    ListNode cur = dummy;
    while(l1 != null && l2 != null){
        if(l1.val <= l2.val){
            cur.next = l1;
            l1 = l1.next;
        } else{
            cur.next = l2;
            l2 = l2.next;
        }
        cur = cur.next;
    }
    cur.next = l1==null ? l2 : l1;
    return dummy.next;
}

递归法

递归法思路与迭代法类似，只不过将循环体写进方法中，利用反复调用方法并更改方法参数达到循环的目的

递归法主要就是现在一般情况下找到整个过程中的循环单元，然后再追加终止条件和特殊情况处理

由于此处使用本身的方法作为递归体，所以需要定义全局的变量，循环过程与上述类似

  • 定义伪头节点dummy和遍历节点cur后，每一次递归都将l1 和 l2 中较小的值赋给cur.next
  • 新链表的cur下移一个，移到链表尾部，递归方法的参数链表中也应将刚才的节点移出， cur.next 与 l1 或 l2 其中一个作为参数，进入下一次递归。
  • 最后终止条件为，两个链表中有一个遍历结束。然后将另一个链表的所有内容添加到新链表尾部。

由于此题中存在多处 l1 和 l2 的比较，所以多处运用了三目运算符? :来简化代码

class Solution {
    ListNode dummy = new ListNode(-1);
    ListNode cur = dummy;
    public ListNode mergeTwoLists(ListNode l1, ListNode l2) {
        if(l1 == null || l2 == null) {
            cur.next = l1==null ? l2 : l1;
            return dummy.next;
        }
        cur.next = l1.val <= l2.val ? l1 : l2;
        cur = cur.next;
        return l1.val <= l2.val ? mergeTwoLists(cur.next, l2) : mergeTwoLists(l1, cur.next);
    }
}
