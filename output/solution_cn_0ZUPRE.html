解法一：递归

正则表达式匹配字符串可以使用自动机状态转换图分析，剑指offer上面的解法，比如模式字符串p = "abcd",那么可以简单画下下图所示的状态转换图

题目主要难点在于的分析：
*可以复制前一个字符，可以复制0次、1次、n次，我们需要从这些策略中找出一种能匹配上的复制次数就行，我们使用SP记录字符串S的位置，PP记录模式字符串P的位置，那么上面的复制次数我们可以使用如下表达式表示

matchCore(S, SP, P, PP + 2) || matchCore(S, SP + 1, P, PP + 2) || matchCore(S, SP+1, P, PP)

S：匹配字符串
P：模式字符串
SP：指向S的指针
PP：指向P的指针

matchCore(S, SP, P, PP + 2)：指向P的指针跳过了当前字符和，复制0次
matchCore(S, SP + 1, P, PP + 2)：指向S的指针指向下一个字符，指向P的指针跳过当前字符和，复制1次
matchCore(S, SP+1, P, PP)：指向S的指针指向下一个字符，指向P的指针不动，说明还要继续使用P的当前字符去匹配S后面的字符，复制n次
完整代码：

class Solution {
    int len_s,len_p;
    public boolean isMatch(String s, String p) {
        if (null == s || null == p) {
            return false;
        }
        len_s = s.length();
        len_p = p.length();
        return matchCore(s,0,p,0);
    }
    private boolean matchCore(String s, int sp, String p, int pp) {
        //sp、pp分别代表指向s,p的指针
        //终止条件，两个字符串都匹配完了
        if (sp == len_s && pp == len_p) {
            return true;
        }
        //模式不足以匹配字符串时
        if (sp < len_s && pp == len_p) {
            return false;
        }
        if (pp < len_p - 1 && p.charAt(pp + 1) == '*') {
            if ((sp < len_s && s.charAt(sp) == p.charAt(pp)) || (p.charAt(pp) == '.' && sp < len_s)) {
                //*复制前面一个字符一次
                return matchCore(s, sp+1, p, pp+2)
                        //复制k次
                        || matchCore(s, sp+1, p, pp)
                        //复制0次
                        || matchCore(s, sp, p, pp+2);
            }
            else {
                return matchCore(s, sp, p, pp+2);
            }
        }
        //模式字符串p下一个字符不是*且与字符串能匹配上，sp,pp后移一位进入下一个字符的匹配
        if ((sp < len_s && s.charAt(sp) == p.charAt(pp)) || (p.charAt(pp) == '.' && sp < len_s)) {
            return matchCore(s, sp+1, p, pp+1);
        }
        return false;
    }
}

解法二：动态规划

  1. 定义dp：dp[i][j]表示s中前i个字符和p中前j个字符是否匹配。
  2. 初始化dp
//为防止一些边界问题处理，定义dp数组时长度为字符串长度+1
boolean[][] dp = new boolean[len_s + 1][len_p + 1];
//两个字符串的前0个字符当然匹配
dp[0][0] = true;
//dp[0][n]这个有个特殊处理，当p.charAt(n) == '*'时，必须匹配0次可能匹配上，所以可能为true,不能直接设置为false
for (int i = 1; i <= len_p; i++) {
    if (p.charAt(i) == '*') {
        //匹配0次就相当于删除p中第i和i-1个字符
        dp[0][i] = dp[0][i - 2];
    }
}
  1. 递推公式推导：比较难处理的就是p中字符为的情况
    - p.charAt(j - 1) != '    '：注意下这个dp中和字符串中index的关系，dp中的i对应字符串中的i-1,因为字符串中index是从0开始的，比如s.charAt(0)是第一个字符。
    $dp[i][j] = dp[i - 1][j - 1]$, (s[i - 1] = p[j - 1] || p.charAt(j - 1) == '.')
    - p.charAt(j - 1) == ''：复制前一个字符的次数是不确定的
    复制0次：$dp[i][j] = dp[i][j-2]$
    复制1次：$dp[i][j] = dp[i-1][j-2],\kern{20pt} s[i-1] = p[j-2]$
    复制2次：$dp[i][j] = dp[i-2][j-2],\kern{20pt} s[i-2,i-1] = p[j-2]$
    复制k次：$dp[i][j] = dp[i-k][j-2],\kern{20pt} s[i-k,i-1] = p[j-2]$
    //在等式后面的条件都满足的情况下，可以推导出如下等式
    ==>$dp[i][j] = dp[i][j-2] || dp[i-1][j-2] || dp[i-2][j-2] || .....||dp[i-k][j-2]$
    ∵ $dp[i-1][j] = dp[i-1][j-2] || dp[i-2][j-2] || .....||dp[i-k][j-2]$
    ==>$dp[i][j] = dp[i][j-2] || dp[i-1][j]$
    - 综上我们可以整理出完整的递推公式
    dp[i][j] = \begin{cases}

dp[i][j-2], & ext{if } p[j] = ''\kern{2pt} and\kern{2pt}s[i]
ot=p[j-1]\kern{2pt} and\kern{2pt}p[j-1]
ot= '.' \
dp[i][j-2] || dp[i-1][j],& ext{if } p[j] = ''\kern{2pt} and\kern{2pt}s[i]==p[j-1]\kern{2pt}\
dp[i-1][j-1],& ext{if } p[j]
ot= '*'\kern{2pt} and\kern{2pt}s[i]==p[j]\kern{2pt}||\kern{2pt}p[j] == '.'
\end{cases}

class Solution {
    public boolean isMatch(String s, String p) {
        if (null == s || null == p) {
            return false;
        }
        int len_s = s.length();
        int len_p = p.length();

        //定义dp:dp[i][j]表示S中前i个字符和P中前j个字符匹配
        boolean[][] dp = new boolean[len_s + 1][len_p + 1];
        //为减少边界判断，dp[0][0]表示两个空
        dp[0][0] = true;
        //当p.charAt(j - 1) == '*',dp[0][j] = dp[0][j - 2]
        for (int n = 1; n <= len_p; n++) {
            if (p.charAt(n - 1) == '*') {
                //这是初始化的第一个坑，因为dp[0]是表示字符串s的第0个字符，也就是空，那么*就只能复制前一个字符复制0次两个字符串才能匹配上
                //也就是忽略*和前一个字符，即dp[i][j-2]
                dp[0][n] = dp[0][n - 2];
            }
        }
        //状态更新
        //i=1才是字符串S的第一个字符，j=1同理
        for (int i = 1; i <= len_s; i++) {
            for (int j = 1; j <= len_p; j++) {
                if (s.charAt(i - 1) == p.charAt(j - 1) || p.charAt(j - 1) == '.') {
                    dp[i][j] = dp[i - 1][j - 1];
                }
                else if (p.charAt(j - 1) == '*') {
                    //如果s当前字符和*复制的字符不一样，*只能复制0次了
                    if (s.charAt(i - 1) != p.charAt(j - 2) && p.charAt(j - 2) != '.') {
                        //复制0次即忽略*及前一个字符，由于题目保证不会第一个字符就为*，所以j>=2
                        dp[i][j] = dp[i][j - 2];
                    }
                    else {
                        //递推关系推导
                        dp[i][j] = dp[i][j -2] || dp[i - 1][j];
                    }
                }
            }
        }
        return dp[len_s][len_p];
    }

}
