Intuition

Separating the problem to smaller problems

All numbers can be separated to parts of three numbers each. And each of those parts have its own name + a suffix that tells us its position.

For example, in the number 420,666 the parts are 420 and 666.

the first part's name is 'Four Hundred Twenty' and the suffix is 'Thousand'. The other part's name is 'Six Hundred Sixty Six' and the suffix is ''.

If we combine them all, we get 'Four Hundred Twenty Thusand Six Hundred Sixty Six' which is the number name.

So all we need to do is find the name and the suffix for each part.

Finding each part and its suffix

If our number is less than 1,000 (num <= 999), than it got only three parts and its suffix is ''.

If our number is more than 1,000,000 and less than 1,000,000,000, we can find the first part by dividing in 1,000,000 and flooring the number. For example:

floor(543,753,875 / 1,000,000) => floor(543.753875) => 543.

The first part's suffix is 'Million'.

We can get the rest of the number by doing a modulo with 1,000,000. For example:
543,753,875 % 1,000,000 => 753,875.

And then we can take the rest of the number, and continue recurisvely until we don't have any parts left.

Of course we should apply the same intuition for thousands and billions.

Finding each part name

Each part contains three numbers. The first number indicates the hundreds number, and the second one indicates the rest of the name.

Finding the first part is easy because it's just numbers 1..9 and the word hundred after them. "One Hundred", "Two Hundred"...

The second part is a little bit more tricky. You got two cases there:
1. It's less than 20. In this case, you can just use the number name like we did in the hundreds part. "One", "Two" ... "Twelve", "Thirteen"...
2. It's 20 or more, and then you want to separate it to two parts. The first part is 20,30,40... and the second one is 1,2,3... So we just want to handle both of those cases separately and connect the numbers.

Let's take an example - 46. It's more than 20, so we can't find the name immediately. We'll separate it to 40+6.

We can find the names of both of those numbers immediately. 'Forty' and 'Six'. And then we can just combine them to 'Forty Six'.

Approach

  1. Take the first part and its suffix
  2. Separate it to hundreds + second part of the number.
  3. Find their names and combine them.
  4. Add the suffix.
  5. Remove the first part from the number and continue until you reach zero.

Complexity

  • Time complexity:
    O(n).
    n is the length of the number.

Code

impl Solution {
    // A util function that helps us find the name of each two numbers
    fn two_number_name(num: i32) -> String {
        // It's either an immediate case, like those:
        String::from(match num {
            0 => "",
            1 => "One",
            2 => "Two",
            3 => "Three",
            4 => "Four",
            5 => "Five",
            6 => "Six",
            7 => "Seven",
            8 => "Eight",
            9 => "Nine",
            10 => "Ten",
            11 => "Eleven",
            12 => "Twelve",
            13 => "Thirteen",
            14 => "Fourteen",
            15 => "Fifteen",
            16 => "Sixteen",
            17 => "Seventeen",
            18 => "Eighteen",
            19 => "Nineteen",
            20 => "Twenty",
            30 => "Thirty",
            40 => "Forty",
            50 => "Fifty",
            60 => "Sixty",
            70 => "Seventy",
            80 => "Eighty",
            90 => "Ninety",
            _ => {
                // Or we need to separate this number, and combine both cases
                let mudolo: i32 = num % 10;
                let tens: i32 = num - mudolo;

                let mut num_name = String::new();

                num_name.push_str(Solution::two_number_name(tens).as_str());
                num_name.push_str(" ");
                num_name.push_str(Solution::two_number_name(mudolo).as_str());

                return num_name;
            }
        })
    }

    pub fn number_to_words(num: i32) -> String {
        // Special case
        if num == 0 {
            return String::from("Zero");
        }

        // Create a mutable number so we can remove parts
        let mut m_num = num;
        // Save the 'parts' names in a vector to combine them later easily
        let mut num_name_builder: Vec<String> = Vec::new();

        while m_num > 0 {
            // Find the first part suffix and its 'index' in the number
            let (div_value, div_name): (i32, &str) = if m_num >= 1_000_000_000 {
                (1_000_000_000, "Billion")
            } else if m_num >= 1_000_000 {
                (1_000_000, "Million")
            } else if m_num >= 1_000 {
                (1_000, "Thousand")
            } else {
                (1, "")
            };

            // Separate the first part
            let three_nums: i32 = m_num / div_value;

            // Get the rest of the number without hundreds
            let mudolo: i32 = three_nums % 100;

            // If it's bigger than 100, we need to find hundreds name
            if three_nums >= 100 {
                num_name_builder.push(Solution::two_number_name(three_nums / 100));
                num_name_builder.push(String::from("Hundred"));
            }

            // Get the last part name
            if mudolo > 0 {
                num_name_builder.push(Solution::two_number_name(mudolo));
            }

            // Add suffix is it's not ''
            if m_num >= 1000 {
                num_name_builder.push(String::from(div_name));
            }

            // Remove first part and continue
            m_num = m_num % div_value;
        }

        // Return the parts with spaces between them
        num_name_builder.join(" ")
    }
}
