方法一：递归 / 迭代

我们需要确定第 $k$ 个字符位于 $S_n$ 的左半、正中间还是右半。为此，首先要知道 $S_n$ 的长度。

用 $|s|$ 表示字符串 $s$ 的长度。根据题意，$|S_1| = 1$，$|S_n| = 2|S_{n-1}| + 1$，所以有

|S_n| + 1 = 2(|S_{n-1}| + 1)

所以 ${|S_n| + 1}$ 是个首项为 $2$，公比为 $2$ 的等比数列，得

|S_n| = 2^n - 1

所以 $|S_{n-1}| = 2^{n-1} - 1$，这说明 $S_n$ 的左半是第 $1$ 个字符到第 $2^{n-1}-1$ 个字符，正中间是第 $2^{n-1}$ 个字符，右半是第 $2^{n-1} + 1$ 个字符到第 $2^n-1$ 个字符。

分类讨论：

  • 如果 $k < 2^{n-1}$，那么第 $k$ 个字符位于 $S_n$ 的左半，问题变成 $S_{n-1}$ 的第 $k$ 个字符。这可以递归解决。
  • 如果 $k > 2^{n-1}$，那么第 $k$ 个字符位于 $S_n$ 的右半，问题变成 $S_{n-1}$ 反转后的第 $k-2^{n-1}$ 个字符，即反转前的第 $2^{n-1}-(k-2^{n-1}) = 2^n-k$ 个字符（比如 $k=2^n-1$ 对应反转前的第 $1$ 个字符）。这个字符再翻转，即为 $S_n$ 的第 $k$ 个字符。这也可以递归解决。

递归边界：

  • 如果 $n=1$，那么返回 $S_1$ 唯一的字符 $ exttt{0}$。
  • 如果 $k = 2^{n-1}$，那么返回 $S_n$ 正中间的字符 $ exttt{1}$。

class Solution:
def findKthBit(self, n: int, k: int) -> str:
if n == 1:
return '0'
if k == 1 << (n - 1):
return '1'
if k < 1 << (n - 1):
return self.findKthBit(n - 1, k)

### 迭代写法

```py [sol-Python3]
class Solution:
    def findKthBit(self, n: int, k: int) -> str:
        rev = 0  # 翻转次数的奇偶性
        while True:
            if n == 1:
                return '1' if rev else '0'
            if k == 1 << (n - 1):
                return '0' if rev else '1'
            if k > 1 << (n - 1):
                k = (1 << n) - k
                rev ^= 1
            n -= 1

复杂度分析

  • 时间复杂度：$\mathcal{O}(n)$。
  • 空间复杂度：$\mathcal{O}(1)$。

方法二：数学公式

奇数位

$S_4 = exttt{011100110110001}$，只看奇数位（下标从 $1$ 开始）的字符，是 $ exttt{01010101}$，这是一个 $ exttt{01}$ 交替序列，为什么？

只看奇数位：

  • $S_1 = exttt{0}$。
  • $S_2$ 把 $ exttt{0}$ 反转再翻转，得到 $ exttt{1}$，拼起来是 $ exttt{01}$。
  • $S_3$ 把 $ exttt{01}$ 反转再翻转，得到 $ exttt{01}$，拼起来是 $ exttt{0101}$。
  • $S_4$ 把 $ exttt{0101}$ 反转再翻转，得到 $ exttt{0101}$，拼起来是 $ exttt{01010101}$。

一般地，由于 $ exttt{01}$ 交替序列反转再翻转，结果不变，所以从 $S_{i-1}$ 到 $S_i\ (i\ge 3)$，其中奇数位相当于复制了一份自身，拼在了自身后面，得到的仍然是 $ exttt{01}$ 交替序列。

所以，当 $k$ 是奇数时，可以立刻得出答案：

  • 设 $k' = \dfrac{k-1}{2}$。这会把 $k=1,3,5,7,\ldots$ 变成 $k'=0,1,2,3,\ldots$
  • 如果 $k'$ 是偶数，那么答案是 $ exttt{0}$。
  • 如果 $k'$ 是奇数，那么答案是 $ exttt{1}$。
  • 一般地，答案为 $k'\bmod 2$ 对应的字符。

偶数位

奇数位的字符，都发源于 $S_1 = exttt{0}$。

偶数位的字符呢？都发源于 $S_i\ (i\ge 2)$ 正中间的那个 $ exttt{1}$，即位置为 $2,4,8,16,\ldots$ 的字符 $ exttt{1}$。

根据方法一的结论，$S_{n-1}$ 的第 $k$ 个字符，反转后，是 $S_n$ 的第 $2^n-k$ 个字符。

$2^n-k$ 有什么性质？

比如二进制 $10000 - 100 = 1100$，去掉末尾的两个 $0$，相当于 $100 - 1 = 11$，结果最低位一定是 $1$，所以 $100$ 和 $1100$ 的尾零个数相同。一般地，$k$ 和 $2^n-k$ 的尾零个数是相同的，这是个不变量！我们可以根据 $k$ 的尾零个数，找到 $k$ 发源于哪个 $S_i$ 正中间的 $ exttt{1}$。

以 $S_2$ 的中间字符（第 $2$ 个字符）为例：

  • 我们把 $S_2$ 的第 $2$ 个字符反转到了 $S_3$ 的第 $8-2=6$ 个字符。把 $ exttt{1}$ 反转再翻转，得到 $ exttt{0}$，拼起来是 $ exttt{10}$。
  • 我们把 $S_3$ 的第 $2,6$ 个字符反转到了 $S_4$ 的第 $14,10$ 个字符。把 $ exttt{10}$ 反转再翻转，得到 $ exttt{10}$，拼起来是 $ exttt{1010}$。注意 $2,6,10,14$ 的二进制尾零个数都是 $1$，且这些位置上的字符拼起来是一个 $ exttt{10}$ 交替序列。

一般地，设 $t$ 为 $k$ 去掉尾零后的值，即 $k = t\cdot 2^x$ 且 $t$ 是奇数。比如 $k=2,6,10,14,\ldots$ 对应着 $t=1,3,5,7,\ldots$

  • 设 $t' = \dfrac{t-1}{2}$。这会把 $t=1,3,5,7,\ldots$ 变成 $t'=0,1,2,3,\ldots$
  • 如果 $t'$ 是偶数，那么答案是 $ exttt{1}$。
  • 如果 $t'$ 是奇数，那么答案是 $ exttt{0}$。
  • 一般地，答案为 $1 - t'\bmod 2$ 对应的字符。

如何去掉 $k$ 的尾零？把 $k$ 除以其 $ ext{lowbit}$ 即可。关于 $ ext{lowbit}$ 的原理，请看 从集合论到位运算，常见位运算技巧分类总结。

```py [sol-Python3]
class Solution:
def findKthBit(self, _, k: int) -> str:
if k % 2:
return str(k // 2 % 2)
k //= k & -k # 去掉 k 的尾零
return str(1 - k // 2 % 2)

class Solution {
    public char findKthBit(int n, int k) {

        }
        k /= k & -k; // 去掉 k 的尾零
        return (char) ('1' - k / 2 % 2);
    }
}
