21. 合并两个有序链表
👤 stormsunshine 👍 1 2022-02-07 🖼 ↗ 查看原 Solution

解法一

思路和算法

如果两个链表都为空，则合并后的链表也为空。如果两个链表中有一个链表为空，则合并后的链表为另一个链表。这两种情况可以概括为：分别判断两个链表是否为空，如果其中一个链表为空，则返回另一个链表作为合并后的结果。

如果两个链表都不为空，则为了满足合并后的链表有序，合并后的链表的头结点应为两个链表的头结点中的值较小的结点，确定头结点之后，再对剩下的结点进行合并。

对于链表 $ extit{list}$，用 $ extit{list}[0]$ 表示其头结点，$ extit{list}[1:]$ 表示除了头结点以外的部分，则合并操作可以表示成如下形式：

extit{mergeTwoLists}(   extit{list}_1,  extit{list}_2) =

\begin{cases}
extit{list}_1[0] + extit{mergeTwoLists}( extit{list}_1[1:], extit{list}_2), & extit{list}_1[0]. extit{val} \le extit{list}_2[0]. extit{val} \
extit{list}_2[0] + extit{mergeTwoLists}( extit{list}_1, extit{list}_2[1:]), & extit{list}_1[0]. extit{val} > extit{list}_2[0]. extit{val}
\end{cases}

根据上述表示形式，合并操作是一个递归的过程。

递归的终止条件是两个链表中至少有一个链表为空，如果其中一个链表为空，则返回另一个链表作为合并后的结果。

如果两个链表都不为空，则可以调用上述递归完成链表的合并。

代码

```Java [sol1-Java]
class Solution {
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
if (list1 == null) {
return list2;
} else if (list2 == null) {
return list1;
} else {
if (list1.val <= list2.val) {
list1.next = mergeTwoLists(list1.next, list2);
return list1;
} else {
list2.next = mergeTwoLists(list1, list2.next);
return list2;
}
}
}
}

复杂度分析

  • 时间复杂度：$O(m + n)$，其中 $m$ 和 $n$ 分别是两个链表的长度。合并过程中最多需要遍历两个链表中的每个结点一次。

  • 空间复杂度：$O(m + n)$，其中 $m$ 和 $n$ 分别是两个链表的长度。空间复杂度主要取决于递归调用栈的深度，递归调用栈最多不会超过 $m + n$ 层。

解法二

思路和算法

也可以使用迭代的方法合并链表。当两个链表都不为空时，比较两个链表的对应结点值，将值较小的结点合并到结果链表中，然后将对应链表的结点向后移动一步。如果一个链表为空，或者遍历完毕，则将另一个链表的剩下的部分合并到结果链表中。

由于合并后的链表的头结点需要通过比较两个链表的头结点决定，因此需要创建哑结点 $ extit{dummyHead}$，将合并的结点依次添加到哑结点的后面。具体做法是，创建指针 $ extit{temp}$ 表示上一个合并的结点，初始时 $ extit{temp}$ 指向 $ extit{dummyHead}$，每次合并结点时，将合并的结点添加到 $ extit{temp}$ 的后面，然后将 $ extit{temp}$ 向后移动一步，直到合并完毕。合并结束之后，$ extit{dummyHead}. extit{next}$ 即为合并后的新链表的头结点。

下图为一个迭代合并链表的例子。灰色表示哑结点，黄色表示两个链表中遍历到的结点，绿色表示 $ extit{temp}$ 指向的结点。

代码

```Java [sol2-Java]
class Solution {
public ListNode mergeTwoLists(ListNode list1, ListNode list2) {
ListNode dummyHead = new ListNode(0);
ListNode temp = dummyHead;
while (list1 != null && list2 != null) {
if (list1.val <= list2.val) {
temp.next = list1;
list1 = list1.next;
} else {
temp.next = list2;
list2 = list2.next;
}
temp = temp.next;
}
if (list1 != null) {
temp.next = list1;
} else {
temp.next = list2;
}
return dummyHead.next;
}
}
