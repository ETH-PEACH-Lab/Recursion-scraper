小白思路233.数字1的个数（递归）
👤 yu-wender 👍 0 2021-08-13 🖼 ↗ 查看原 Solution
  1. 暴力
    作为小白最先想到的就是暴力了，枚举每一种情况。
    n的范围从[0],[1,9],[10,99],[100,999],[1000,9999]...
    具体可以细分为[0],[1,9],[10,20],[20,99],[100,109],[110,111],[120,199],[200,999]...
    直觉上这种方法是可行的因为这种方法只是情况很多，会用到很多if else语句。但是不存在循环，所以应该满足时间、空间复杂度。
    接下来就是实践，在没有思路的时候先尝试这种方法。

    在这时候我发现了一个规律，就是当n在[0,9]范围中时1的个数不是0就是1，当n不在这个范围的时候只有最高位会对1的个数产生影响，非最高位中1的个数都可以用递归求的。
  2. 递归
    已知n范围应该是[0],[1,9],[10,99],[100,999],[1000,9999]...
    设函数count_1()为求得1的个数的函数，ind为最高位数
    当n在[0]范围中时：count_1(n) = 0
    当n在[1,9]范围中时：count_1(n) = 1
    当n在其他范围中时：
    首先将其分为两种情况：
    • 一种是最高位是1的情况
      首先，在这种情况中，随着n的增大，由于最高位是1，所以1的个数随之增多。
      如：100，101，102。在只考虑最高位的情况下，count_1（102）比count_1（100）的多2。
      导致这个现象出现的原因是：最高位出现的次数不同。在n=100时，最高位出现了1次，因为100之前百位是0，而n=102时，最高位出现3次。
      所以， 只考虑最高位影响的情况下：此时的结果为：n=最高位前一个数时1的个数+n与这个数的差值
      递归方程为：count_1（n） = count_1（10(ind)-1） + (n-(10(ind)-1))
      如：当n=100023时。只考虑最高位影响的情况下：count_1（100023） = count_1（10000-1） + （n - 10000 + 1）
      最后，消除了最高位的影响，n为非最高位的情况之前一定计算过，所以可以直接获取。
      综上所述，最终结果为：只考虑最高位影响的情况下1的个数+n为非最高位1的个数
      递归方程为：count_1（n） = count_1（10(ind)-1） + (n-(10(ind)-1)) + count_1（n % (10**(ind))）
      如n=123456时：count_1（n） = count_1（100000 -1） + （n-100000 + 1） + count_1（23456）
    • 一种是最高位不是是1的情况
      这种情况下，最高位是1的所有情况已经计算完。
      此时，最终结果为：n为最高位是1的最大数时1的个数 + （最高位每增加1时，1增加的个数 ）（n相对于最高位是1的最大数增加了几次） + n为非最高位1的个数
      递归方程为：count_1（n）= count_1（2 * 10      (ind)-1） + count_1(10(ind)-1) （n//10(ind) - 2）+ count_1（n % 10(ind-1)）
      如：n = 244时，count_1（244） = count_1（200-1） + count_1（100-1） （244//100 - 2) + count_1（44）
      n = 3358时，count_1（3358） = count_1（2000-1） + count_1（1000-1）       （3358//1000 - 2) + count_1（358）
      代码为：
class Solution:
    def countDigitOne(self, n: int) -> int:
        if n == 0:
            return 0
        elif n // 10 == 0:
            return 1
        else:
            ind = 0
            while n//10**ind!=0:
                ind += 1
            if n < 2 * 10**(ind-1):
                return self.countDigitOne(10**(ind-1)-1) + (n-(10**(ind-1)-1)) + self.countDigitOne(n % (10**(ind-1)))
            else:
                return self.countDigitOne(2 * 10**(ind-1)-1) + self.countDigitOne(10**(ind-1)-1)*(n//10**(ind-1) - 2) + self.countDigitOne(n % 10**(ind-1))
