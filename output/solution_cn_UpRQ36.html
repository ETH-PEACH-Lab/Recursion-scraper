解题思路：

实现计算 x 的 n 次方的函数可以使用分治法（递归）来解决，以减少计算次数，正常直接相乘的时间复杂度为O(n)，但是递归可以降到O(logn)。

当 n 为偶数时，我们可以将 x^n 拆分为 (x^(n/2))^2，从而减少计算量。当 n 为奇数时，可以将 x^n 拆分为 x * (x^((n-1)/2))^2。

下面是具体的算法步骤：
1. 如果 n 为负数，则将 x 取倒数，n 取相反数，以便后续计算。
2. 定义递归函数 power(x, n)，在该函数中：
3. 如果 n 为 0，返回 1，因为任何数的 0 次方都等于 1。
4. 如果 n 为 1，返回 x，因为任何数的 1 次方都等于它本身。
5. 如果 n 为偶数，返回 power(x, n/2) * power(x, n/2)。
6. 如果 n 为奇数，返回 x * power(x, (n-1)/2) * power(x, (n-1)/2)。
7. 最终返回递归函数 power(x, n) 的结果

时间复杂度分析：

在每次递归调用中，问题的规模减少一半，所以递归的深度为 log(n)。每一层递归中都进行了常数次的计算，因此总体时间复杂度为 O(log n)

空间复杂度分析：

递归调用的深度为 log(n)，所以空间复杂度为 O(log n)


代码

class Solution(object):
    def myPow(self, x, n):
        """
        :type x: float
        :type n: int
        :rtype: float
        """
        # if n is negative, we invert x and negate n for calculation
        if n < 0:
            x = 1 / x
            n = -n

        return self.power(x, n)

    def power(self, x, n):
        if n == 0:
            return 1
        if n == 1:
            return x
        # if n is even, we can convert x^n to (x^(n/2))^2 to reduce calculation times
        # if n is odd, we can convert x^n to ((x^((n-1)/2))^2)*x to reduce calculation times
        half = self.power(x, n // 2)
        if n % 2 == 0:
            return half * half
        else:
            return half * half * x
