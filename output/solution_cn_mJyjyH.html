解题思路

只要看到这种把链表后面的元素放到前面的题目，第一反应就是二叉树的后序遍历，后序遍历不行，再考虑其他方法，因为递归天然支持从后往前遍历链表。

本质上链表也是树，只不过这棵树退化了，只往一边长，长成了链表的样子。

后序遍历入门（熟悉后序遍历的直接看下一步）

假设我们现在要从后往前遍历这个链表，按顺序输出4-3-2-1，应该怎么做？

最简单的方法显然是用递归，代码如下

public static void reverse(ListNode cur){
    if(cur == null){
        return;
    }

    reverse(cur.next);

    //后序遍历位置
    System.out.println(cur.val);
}

完整代码

class Solution {
    ListNode first;
    boolean finish = false;
    public void reorderList(ListNode head) {
        first = head;
        reorder(head);
    }

    private void reorder(ListNode cur){
        if(cur == null){
            return;
        }

        reorder(cur.next);

        if(first == cur){
            cur.next = null;
            finish = true;
        }

        if(!finish){
            ListNode newFirst = first.next;
            first.next = cur;
            cur.next = newFirst == cur ? null : newFirst;

            first = newFirst;

            if(newFirst == cur){
                finish = true;
            }
        }
    }
}
