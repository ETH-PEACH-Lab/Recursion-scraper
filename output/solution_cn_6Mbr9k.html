时间复杂度O(n)递归解决
👤 machinechen 👍 1 2022-01-16 🖼 ↗ 查看原 Solution

核心

  • 根据后序遍历序列构建二叉搜索树，虽然仅靠后序遍历不能唯一确定一棵树，但只要能构建即可。
  • 树的问题大部分可以用递归解决，检查子树是否可为二叉搜索树。转为二叉树，则为左子树是否为二叉树搜索树？右子树是否为二叉搜索树？
  • 代码中所遵循的思路是尽可能多的利用节点构建二叉搜素树，若最后节点没有使用完毕，则认为该后序遍历不是二叉搜索树的。

前提

  • 后序遍历末尾元素是该二叉树的根结点
  • 对于节点i，节点i-1是该节点的右或左孩子。

  • 二叉搜索树满足 a < b < c

  • 二叉搜索树存在取值范围限制

左子树值允许区间表示位于节点10与节点20间的节点值必须在该范围内，否则不是二叉搜索树

根结点的取值范围为[-inf, 20), (20, inf]

不难发现，变化的仅有左子树值允许区间的最小值与右子树允许区间的最大值，我们只用传递这两个值即可。
维护该区间很简单，
- 右子树的左子树值允许区间的最小值 = 当前根节点的值
- 左子树的右子树值允许区间的最大值 = 当前根节点的值

其余直接传递即可。

解题思路

代码

class Solution {
public:
    void isBinaryTree(vector<int>& postorder, int& index, int left, int right) {
        记录当前子树的根结点
        int root = index;
        // 检查前一位，
        index -= 1;
        if(index < 0)
            return;
        // 判断右子树是否为二叉树. 要在区间 [[root], right]
        if(postorder[index] < right && postorder[index] > postorder[root]) {
            isBinaryTree(postorder, index, postorder[root], right);
        }
        if(index < 0)
            return;
        // 判断左子树是否为二叉树, 要在区间 [left, [root]]
        if(postorder[index] > left && postorder[index] < postorder[root]) {
            isBinaryTree(postorder, index, left, postorder[root]);
        }
    }
    bool verifyPostorder(vector<int>& postorder) {
        int i = postorder.size() - 1;
        isBinaryTree(postorder, i, INT_MIN, INT_MAX);
        // 若 i == -1则说明节点使用完毕
        return i < 0;
    }
};
