1. 常规解法

对于链表中元素的删除，最容易想到的方法就是创建一个哑结点（dummyNode），遍历链表中的元素，并将值不等于val的结点依次累加到dummyNode所在链表的尾部。代码如下：

class Solution {
public:
    ListNode* removeElements(ListNode* head, int val) {
        //基础解法 遇到值不等于val的节点，累加在哑结点尾部
        ListNode node;
        ListNode *pre = &node, *p = head;
        while (p) {
            if (p->val != val) {
                pre->next = p;
                pre = p;
            }
            p = p->next;
        }
        //特别注意的地方，当尾节点的值是val时，上述循环会跳过，但pre->next仍为尾结点
        pre->next = nullptr;
        return node.next;
    }
};

2. 递归解法

对于该题，还可以通过递归的方式求解。我们不妨把链表分为头结点与其余结点组成的链表，如下图所示：

则从链表中删除值为val的结点的问题可以转换为：
Step1. 删除suffix链表中值为val的结点（重复子问题）
Step2. 若head结点值为val，则直接返回suffix；否则返回head结点与suffix组成的新链表
代码如下：

    ListNode *removeElements(ListNode *head, int val) {
        //递归实现
        if (head == nullptr)
            return head;
        //获取{第2个节点之后组成的链表}删除元素val后的链表
        ListNode *suffix = removeElements(head->next, val);
        //若首节点元素为val，则删除，即返回suffix
        if (head->val == val)
            return suffix;
        else {
            //若首节点元素不为val，则保留，即返回head
            //更新链表为首节点+suffix
            head->next = suffix;
            return head;
        }
    }

递归解法延伸

删除指定元素的递归解法不仅可以用在链表中，同样可以用在数组中，思想相同。这里给出引用版本与非引用版本：

引用版本

    void removeElementsRef(vector<int> &nums, int val) {
        if (nums.size() == 0)
            return;
        vector<int> suffix(nums.begin() + 1, nums.end());
        //获取数组 nums[1:]删除val后得到的数组
        removeElementsRef(suffix, val);
        //若首元素不为val，则保留
        if (nums[0] != val)
            suffix.insert(suffix.begin(), nums[0]);
        nums = suffix;
    }

非引用版本

    vector<int> removeElements(vector<int> nums, int val) {
        //递归实现
        if (nums.size() == 0)
            return nums;
        vector<int> suffix(nums.begin() + 1, nums.end());
        //获取数组 nums[1:]删除val后得到的数组
        vector<int> removedSuffix = removeElements(suffix, val);
        vector<int> result(removedSuffix.begin(), removedSuffix.end());
        result.insert(result.begin(), nums[0]);
        //若首元素为val，则删除，即直接返回removedSuffix
        if (nums[0] == val)
            return removedSuffix;
        else {
            //若首元素不为val，则保留，即返回head
            return result;
        }
    }
