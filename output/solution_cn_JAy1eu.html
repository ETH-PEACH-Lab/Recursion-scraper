递归

可以理解为在递归的过程中返回翻转后的头结点。举个例子：

在这个例子中，当遍历到尾结点时（Next == nil），直接返回。递归的上一层（假设这一层的结点——尾结点的前一个——记为x）收到返回的结点之后，不对其做任何动作。此时x用x.Next.Next = x; x.Next = nil完成x到尾结点的翻转，然后继续把尾结点向上层传递。最终，我们得到了新的头节点（原来的尾结点）。对于有区间要求（25-分组翻转，92-区间内翻转）的题目，我们可以在递归条件中加一个计数值k。当递归到下一层时，k = k-1。最终以k == 1为边界条件（k == 0时得到的是尾结点的下一个结点），并把下一个区间的第一个结点返回。
代码：
```go []
func reverseKGroup(head ListNode, k int) ListNode {
n := 0
for tmp := head; tmp != nil; tmp = tmp.Next{
n++
}
if n < k{
return head
}
var dfs func(node ListNode, k int) (ListNode, ListNode)
dfs = func(node ListNode, k int) (ListNode, ListNode){
if k == 1{
return node, node.Next
}
newnode, end := dfs(node.Next, k-1)
node.Next.Next = node
node.Next = nil
return newnode, end
}
newhead := &ListNode{0, head}
cur := newhead
for i := 0; i < n/k; i++{
tmp1, tmp2 := dfs(cur.Next, k)
nxt := cur.Next
cur.Next.Next = tmp2
cur.Next = tmp1
cur = nxt
}
return newhead.Next
}


### 迭代
比较好理解，我们需要三个结点（假设为pre，cur，nxt）。初始时，pre.Next = cur, cur.Next = nxt。每次让cur.Next 指向 pre，完成翻转，然后nxt负责记录下一个需要翻转的结点，三个结点变为：pre = cur, cur = nxt, nxt = nxt.Next。
![image.png](https://pic.leetcode.cn/1679803635-PegxQX-image.png){:width=400}
需要注意的是，nxt = nxt.Next时有可能nxt 本身为nil，自然也就没有Next，需要特判一下。
代码：
``` go []
func reverseKGroup(head *ListNode, k int) *ListNode {
    n := 0
    for tmp := head; tmp != nil; tmp = tmp.Next{
        n++
    }
    if n < k || n == 1 || k == 1{
        return head
    }
    newhead := &ListNode{0, head}
    start := newhead
    pre, cur, nxt := (*ListNode)(nil), head, head.Next
    for i := 0; i < n/k; i++{
        for j := 0; j < k; j++{
            cur.Next = pre
            pre = cur
            cur = nxt
            if nxt != nil{ //nxt 可能为nil
                nxt = nxt.Next
            }
        }
        nxt = start.Next
        start.Next.Next = cur
        start.Next = pre
        start = nxt
        pre = nil
        if cur != nil{ //需要指向一个结点的Next时，需要判断这个结点为不为空
            nxt = cur.Next
        }
    }
    return newhead.Next
}

头插法

要翻转一个链表，我们还可以把后面的结点插到前面。同样假设有3个结点pre，cur，nxt。每次让cur.Next = nxt.Next, nxt.Next = pre.Next, pre.Next = nxt。

代码：
go [] func reverseKGroup(head *ListNode, k int) *ListNode { n := 0 for tmp := head; tmp != nil; tmp = tmp.Next{ n++ } if n < k || n == 1 || k == 1{ return head } newhead := &ListNode{0, head} pre, cur, nxt := newhead, head, head.Next for i := 0; i < n/k; i++{ for j := 1; j < k && nxt != nil; j++{ //注意只需要k-1次头插法就可以，因为当k-1个结点调整到头部时，原本的第一个结点就是最后一个结点 cur.Next = nxt.Next nxt.Next = pre.Next //注意必须让nxt.Next -> pre.Next，而不是cur，cur代表的是头插法结束后的最后一个结点。 pre.Next = nxt nxt = cur.Next } pre = cur cur = cur.Next if cur != nil{ nxt = cur.Next } } return newhead.Next }
