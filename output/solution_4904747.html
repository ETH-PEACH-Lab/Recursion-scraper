Intuition 1

The intuition behind this approach is to reverse the given linked list recursively. By recursively reversing the pointers of each node, we can effectively reverse the entire list.

Approach 1

  • We define a recursive function reverseList that takes the current node (head) as input.
  • In the function, we check if the current node is null or if it is the last node in the list (head.next == null). If either condition is true, we return the current node as it is the new head of the reversed list.
  • Otherwise, we recursively call the reverseList function with the next node (head.next) as input and store the returned node as newHead.
  • After the recursion returns, we update the next pointer of the current node (head.next.next) to point back to the current node (head). This effectively reverses the link between the current node and its next node.
  • We then set the next pointer of the current node (head.next) to null, as it now becomes the last node in the reversed list.
  • Finally, we return newHead, which is the new head of the reversed linked list.

Complexity

  • Time complexity: O(n),
    where n is the number of nodes in the linked list.
  • Space complexity: O(n),
    as the recursive calls consume space on the call stack, with n being the number of nodes in the linked list.

Code

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {

        if(head==null || head.next == null) return head;
        ListNode newHead = reverseList(head.next);
        head.next.next = head;
        head.next = null;
        return newHead;
    }
}

Intuition 2

The intuition behind this approach is to reverse the given linked list iteratively. By reversing the pointers of each node, we can effectively reverse the entire list.

Approach 2

  • We initialize two pointers, prev and cur, where prev will initially be null and cur will point to the head of the list.
  • We iterate through the list using the cur pointer.
  • At each iteration, we reverse the link of the current node (cur) to point to the previous node (prev).
  • We then move prev to cur and cur to the next node in the list.
  • We continue this process until we reach the end of the list.
  • Finally, we return prev, which now points to the new head of the reversed linked list.

Complexity

  • Time complexity: O(n),
    where n is the number of nodes in the linked list.
  • Space complexity: O(1),
    as only a constant amount of extra space is used for pointers

Code

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */
class Solution {
    public ListNode reverseList(ListNode head) {

        ListNode prev = null, cur = head;
        while(cur != null){
            ListNode next = cur.next;
            cur.next = prev;
            prev = cur;
            cur = next;
        }
        return prev;
    }
}
