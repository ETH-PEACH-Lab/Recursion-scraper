Intuition :

  1. The task involves modifying the structure of the linked list by changing the next pointers of the nodes.
  2. For every two adjacent nodes:
    - Swap their order.
    - Update the next pointers so that the swapped nodes are correctly linked.
  3. Continue the process for all pairs of adjacent nodes until the end of the list.

Algorithm :

Steps:

  1. Base Cases:
    - If the list is empty (head == nullptr) or has only one node (head->next == nullptr), return the head as no swapping is possible.

  2. Initialization:
    - Create a dummy node before the head to simplify edge case handling (e.g., when swapping the first two nodes).
    - Let prev point to the dummy node and curr point to the head.

  3. Iterate and Swap:
    - While there are at least two nodes remaining (curr and curr->next):

    1. Identify the two nodes to swap: curr (first node) and curr->next (second node).
    2. Update prev->next to point to curr->next (second node).
    3. Update curr->next to point to the node after curr->next (third node or nullptr).
    4. Update curr->next->next (second node) to point to curr (first node).
    5. Move prev to curr and curr to curr->next.

  4. Return the Modified List:
    - Return dummy->next as the new head of the swapped list.

Complexity :

  • Time Complexity: \( O(n) \)
  • We traverse each node once, and each pair is processed in \( O(1) \).
  • Space Complexity: \( O(1) \)
  • Only pointers are used for manipulation; no additional space is needed.

Implementation Yeh :

C++ :

#include <iostream>
using namespace std;


class Solution {
public:
    ListNode* swapPairs(ListNode* head) {
        if (!head || !head->next) return head;

        ListNode* dummy = new ListNode(0);
        dummy->next = head;
        ListNode* prev = dummy;

        while (prev->next && prev->next->next) {
            ListNode* first = prev->next;
            ListNode* second = prev->next->next;

            first->next = second->next;
            second->next = first;
            prev->next = second;

            prev = first;
        }

        return dummy->next;
    }
};

Java :


class Solution {
    public ListNode swapPairs(ListNode head) {
        if (head == null || head.next == null) return head;

        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode prev = dummy;

        while (prev.next != null && prev.next.next != null) {
            ListNode first = prev.next;
            ListNode second = prev.next.next;

            first.next = second.next;
            second.next = first;
            prev.next = second;

            prev = first;
        }

        return dummy.next;
    }
}

class Solution:
    def swapPairs(self, head: ListNode) -> ListNode:
        if not head or not head.next:
            return head

        dummy = ListNode(0)
        dummy.next = head
        prev = dummy

        while prev.next and prev.next.next:
            first = prev.next
            second = prev.next.next

            first.next = second.next
            second.next = first
            prev.next = second

            prev = first

        return dummy.next

  • Process:

  • Swap 3 and 4: 2 -> 1 -> 4 -> 3
  • Output: [2,1,4,3]
