Intuition

The key idea in reversing a linked list recursively is to focus on each node’s next pointer. By adjusting these pointers in reverse order as we return from each recursive call, we achieve the reversal. We start with the last node as the new head of the reversed list and work backward to connect all nodes.

Approach

  1. Base Case: If the list is empty (head == null) or contains only one node (head.next == null), return head as it is already reversed.
  2. Recursive Step: Call reverseList(head.next) to reverse all nodes after the current node. This call will eventually reach the end of the list, returning the last node as newNode.
  3. Reversal Step:
    - Reverse the current node’s connection by setting head.next.next = head, making head the next node of head.next.
    - Set head.next = null to mark the original head’s position as the end of the reversed list.
  4. Return New Head: At each level of recursion, return newNode, which points to the new head of the reversed list.

Complexity

  • Time Complexity: O(n), where \( n \) is the number of nodes in the linked list. Each node is visited once as the recursion unfolds and returns.
  • Space Complexity: O(n) due to the recursion stack, where \( n \) recursive calls are made in total.

Code

/**
 * Definition for singly-linked list.
 * public class ListNode {
 *     int val;
 *     ListNode next;
 *     ListNode() {}
 *     ListNode(int val) { this.val = val; }
 *     ListNode(int val, ListNode next) { this.val = val; this.next = next; }
 * }
 */

class Solution {
    public ListNode reverseList(ListNode head) {
        if (head == null || head.next == null) { // Base case
            return head;
        }
        ListNode newHead = reverseList(head.next); // Recursive step
        head.next.next = head; // Reverse the link
        head.next = null; // Mark the original head as end
        return newHead; // Return the new head
    }
}

Explanation

  • Goal: Reverse the linked list by adjusting pointers so that each node’s next points to its previous node.
  • Process:
  • The recursion dives to the end of the list, reaching the last node, which will become the new head of the reversed list.
  • As the recursion unwinds, each node points back to the previous node, effectively reversing the direction.

Dry Run

Suppose the list is 1 -> 2 -> 3 -> 4 -> 5 -> NULL.

  1. Initial Call: reverseList(head) where head is pointing to the node with value 1.
  2. Recursive Steps: Each recursive call goes one step deeper until it reaches the end node (5).

Step-by-Step Recursive Calls

Call Depth Input (head) Action
1 1 Calls reverseList(2)
2 2 Calls reverseList(3)
3 3 Calls reverseList(4)
4 4 Calls reverseList(5)
5 5 Base case: returns 5

Unwinding the Recursion

Now, the recursion begins unwinding, and each step reverses the next pointer.

  1. Returning to Call 4 (head = 4):
    - newHead = 5 (from the recursive call).
    - head.next.next = head → 4.next.next = 4 → 5.next = 4.
    - head.next = null → 4.next = null.
    - Returns newHead, which is 5.

  2. Returning to Call 3 (head = 3):
    - newHead = 5 (reversed list starting with 5 -> 4 -> NULL).
    - head.next.next = head → 3.next.next = 3 → 4.next = 3.
    - head.next = null → 3.next = null.
    - Returns newHead, which is 5.

  3. Returning to Call 2 (head = 2):
    - newHead = 5 (reversed list 5 -> 4 -> 3 -> NULL).
    - head.next.next = head → 2.next.next = 2 → 3.next = 2.
    - head.next = null → 2.next = null.
    - Returns newHead, which is 5.

  4. Returning to Call 1 (head = 1):
    - newHead = 5 (reversed list 5 -> 4 -> 3 -> 2 -> NULL).
    - head.next.next = head → 1.next.next = 1 → 2.next = 1.
    - head.next = null → 1.next = null.
    - Returns newHead, which is 5.

Final Result

After all recursive calls complete, the list is reversed as 5 -> 4 -> 3 -> 2 -> 1 -> NULL.

Code Breakdown

  1. Base Case Check: The function first checks if head is null or if head.next is null (i.e., if there's only one node left in the list).

    • Purpose: If the list is empty or we’ve reached the last node, we return head as the new head of the reversed list. This acts as the termination condition for the recursion.

  2. Recursive Step: If the base case isn’t met, the function calls itself recursively with head.next.

    • Purpose: This continues moving down the list until we reach the end. Essentially, we’re pushing recursive calls onto the stack, each moving one node further down the list until we hit the last node, which becomes the new head of the reversed list.

  3. Reversing the Link: Once we start returning from the recursive calls, we begin to reverse the links.

    • After the recursive call returns, the newHead variable points to the head of the reversed portion of the list.
    • head.next.next = head reverses the link by pointing the next node's next back to head.

  4. Marking the End: head.next = null sets the next pointer of the current head to null, effectively marking it as the new end of the list.

  5. Returning the New Head: Finally, newHead is returned up the recursive stack until it becomes the return value of the initial function call.

Summary of Control Flow

  1. Recursive Calls: Move to the end of the list.
  2. Returning Phase: Reverse the link at each recursive return.
  3. End Condition: Each node’s next is set to null in the reversed list, creating a new head of the reversed linked list.

Summary of Key Points

  • Recursive Approach: Each function call moves one step deeper until it reaches the last node.

  • Return: newHead always points to the last node (now the new head), which propagates back up through each recursive call.

To reverse a linked list iteratively, we can use a three-pointer approach. This approach eliminates the need for recursion by iteratively adjusting the pointers of each node to reverse the list.

Iterative Solution in Java:

class Solution {
    public ListNode reverseList(ListNode head) {
        ListNode prev = null;      // Initially, there's no previous node
        ListNode current = head;    // The current node starts at the head
        ListNode next = null;       // Used to temporarily store the next node

        // Iterate through the list until current becomes null
        while (current != null) {
            next = current.next;    // Store the next node
            current.next = prev;    // Reverse the link (current.next points to prev)
            prev = current;         // Move prev forward to the current node
            current = next;         // Move current to the next node in the original list
        }

        return prev; // At the end, prev will be the new head of the reversed list
    }
}

Explanation of the Flow Control

  1. Initialize Three Pointers:
    - prev is set to null since it will eventually point to the new end of the list.
    - current points to head initially (the node we’re currently processing).
    - next is a temporary pointer that will store the original current.next during each iteration.

  2. Iterate Through the List:
    - Store the Next Node: next = current.next stores the next node in the list before we change current.next.
    - Reverse the Link: current.next = prev reverses the current node's next pointer, making it point backward to prev.
    - Move prev Forward: prev = current moves prev one step forward to become the current node. This prepares prev for the next iteration as the new "last processed" node.
    - Move current Forward: current = next advances current to the next node in the original list (which we stored in next).

  3. Termination:
    - The loop continues until current is null, meaning we’ve processed every node in the original list.
    - At the end, prev will point to the last node of the original list, which becomes the new head of the reversed list.

Example Execution with List: 1 -> 2 -> 3 -> 4 -> 5 -> null

  1. Initial State:
    - prev = null
    - current = 1

  2. First Iteration:
    - next = 2 (store current.next)
    - current.next = prev (1.next = null)
    - Move prev to current (prev = 1)
    - Move current to next (current = 2)
    - List state: 1 <- null with prev at 1 and current at 2

  3. Second Iteration:
    - next = 3
    - current.next = prev (2.next = 1)
    - Move prev to current (prev = 2)
    - Move current to next (current = 3)
    - List state: 2 -> 1 <- null with prev at 2 and current at 3

  4. Continue until the list is fully reversed:
    - Final State: 5 -> 4 -> 3 -> 2 -> 1 -> null with prev pointing to 5, which is the new head of the reversed list.

  5. Return prev, which is now the head of the reversed list.

This iterative approach has O(n) time complexity and O(1) space complexity, making it efficient in both time and space.
