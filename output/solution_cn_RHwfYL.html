【C++】排序序列：在原初序列上交换位置，简单的递归思想

解题思路

以n=4为例，序列最小的排列为1234，直接在原初序列进行交换位置的操作，这样就可以避免了重复数字的产生
方法如下：
1. 首先是确定第一个位置的数字，然后把对应的数字放在第一个位置，剩余的数字按升序排列
具体的操作：比如k=14，得到(k-1)/(3!)=2，也就是要第一个位置的数字1要换成比他大俩位的数字3，剩余的数字按升序排列，得到3124，这里需要俩步交换的操作，分别是第一位与第二位交换，从1234到2134，第一位与第三位交换得到3124，这样第一位得到了我们想要的数字，后续的数字还是保持了按升序排列

  1. 然后我们发现问题变成了规模更小的子问题了：从1234求k=14的排列，变成134求'k%(3!)=2'的排列，所以我们可以用递归的思想，重复上述的交换过程，得到需要的序列。

代码

class Solution {
public:
    string getPermutation(int n, int k) {
        vector<int> jiecheng={1,1,2,6,24,120,720,5040,40320};
        //初始化s="123...n"
        string s="";
        for(int i=1;i<=n;i++){
            s+='0'+i;
        }
        //k=1就已经是原初序列了
        k--;
        for(int i=0;i<n;i++){
            //当前位置i要与后面的位置交换次数
            int tmp=k/jiecheng[n-i-1];
            int index=tmp;
            k=k%jiecheng[n-i-1];
            //不停交换第i位和i位后面的位置，直到交换第i位和第i+k/jiecheng[n-i-1]位
            while(tmp--){
                swap(s[i],s[i+index-tmp]);
            }
        }
        return s;
    }
};
