解题思路

递归分治 + 二叉搜索树性质

可以通过递归判断所有子树的正确性，而每次递归都通过二叉搜索树性质判断是否所有子树都满足：
+ 左侧子树所有值小于根节点
+ 右侧子树所有值大于根节点

递归解析

  • 终止条件： 当 start ≥ end ，说明此子树节点数量小于等于1 ，无需判别正确性，因此直接返回 true；
  • 划分左右子树： 由于根节点索引 end，遍历后序遍历的 [start, end] 区间元素，寻找 第一个大于根节点 的节点，索引记为 midIndex。此时，可划分出二叉搜索树的左子树区间 [start, midIndex - 1] 、右子树区间 [midIndex, end - 1]。

判断是否为二叉搜索树

  • 左子树区间 [start, midIndex - 1] 内的所有节点都应小于 postorder[now]。而上面 划分左右子树 步骤已经保证左子树区间的正确性，因此只需要判断右子树区间即可。
  • 右子树区间 [midIndex, end - 1] 内的所有节点都应大于 postorder[now] 。实现方式为遍历，当遇到小于 postorder[now] 的节点则跳出，说明不满足了；
  • 则可通过 now === end ？ 判断是否为二叉搜索树。

返回值

所有子树都需正确才可判定正确，因此使用 与逻辑符 && 连接。
+ now === end ： 通过是否 now 指针遍历到了最后等于 end 指针，来判断此树是否正确，是否每个结点都满足二叉搜索树性质。
+ isPostorder(start, midIndex - 1)： 判断 此树的左子树 是否正确。
+ isPostorder(midIndex, end - 1)： 判断 此树的右子树 是否正确。


代码

/**
 * @param {number[]} postorder
 * @return {boolean}
 */
var verifyPostorder = function(postorder) {
    const isPostorder = (start, end) => {
        if(start >= end)
            return true;
        let now = start, midIndex;
        // 找到第一个大于当前子树根节点的值，代表是二叉搜索树的右子树了，对于后序遍历，根节点是数组最后一位，即 postorder[end]
        while(postorder[now] < postorder[end])
            now++;
        midIndex = now;
        // 找到第一个小于当前子树根节点的值，正常来说应该遍历到结尾的，即二叉搜索树右侧不应出现比根节点要小的值，如果出现了说明不符合，提前跳出循环
        while(postorder[now] > postorder[end])
            now++;
        // 如果没遍历到末尾，提前跳出了循环，那么 now !== end，同时判断左子树和右子树是否都符合
        return now === end && isPostorder(start, midIndex - 1) && isPostorder(midIndex, end - 1);
    }

    return isPostorder(0, postorder.length - 1);
};
