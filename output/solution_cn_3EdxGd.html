递归

假设字符串 s 为adceb，模式串 p 为*a?*b，匹配过程如下：

当两个字符相等，或者模式串的字符为?时，s[i]就和p[j]匹配。
匹配后，下一步还需要继续比较，所以去掉 S 的当前字符，去掉 P 的当前字符，继续比较s[i + 1:]和p[i + 1:]。
如果模式串 p 的当前字符为*怎么匹配呢？
*是个万能字符，可以连续匹配任意字符：
- aaa 和 *a， 这样是匹配的，因为 * 可以匹配 aa
- aaba 和 *a，这样也是匹配的，因为 * 可以匹配 aab
- ba 和 *ba，也是匹配的，因为 * 可以匹配 0 到多个空字符

*匹配 跟单个字符匹配，其后续步骤是不一样的，单个字符匹配后，只有一条分支可以走，而*匹配后，有两条分支可以走：

我们定义i表示字符串 S 的下标位置
定义j表示模式串 P 的下标位置
那么递归的终止条件就是i == len(S) 或者j == len(P):
- i == len(S) 说明字符串遍历到头了，如果模式串也遍历到头了，那么可以返回 true了
- i == len(S) 还有另一种场景，即模式串没有遍历到头(字符串 aaa,模式串aaa 这种场景)，但模式串当前字符是， 可以匹配任意字符，所以要去掉当前字符，再往后面递归
- 如果是模式串遍历到头了，那说明两个字符串不匹配，返回 false

有了上面的边界条件，加上图解的说明，我们就可以把递归写出来了，请看下面代码

```java []
class Solution {
public boolean isMatch(String s, String p) {
return new Helper(s,p).dfs(0,0);
}
//增加一个工具类，完成递归调用
private class Helper {
private String s;
private String p;
//用来缓存结果
private Map map = new HashMap<>();
private int n;
private int m;
Helper(String s, String p) {
this.s = s;
this.p = p;
this.n = s.length();
this.m = p.length();
}

    private boolean dfs(int i, int j) {
        Pair pair = new Pair(i,j);
        if(map.containsKey(pair)) {
            return map.get(pair);
        }
        //i==n说明字符串匹配完了，如果p的首字符是*，可以忽略，然后再递归检查
        //比如"aaa"和"aaa**"就是匹配的
        if(i == n) {
            return (j == m) || (p.charAt(j) == '*' && dfs(i, j + 1));
        }
        //如果模式串到头了，说明没匹配上
        if(j == m) {
            return false;
        }
        boolean res = false;
        //模式串当前字符为 *，有两条分支可以走
        //可以去掉S的首字符(i + 1)，也可以去掉P的首字符(j + 1)
        if(p.charAt(j) == '*') {
            res = dfs(i + 1, j) || dfs(i, j + 1);
        }
        else {
            //检查S和P的首字符是否相同，或者P首字符为?
            boolean isFirstMathc = p.charAt(j) == s.charAt(i) || p.charAt(j) == '?';
            //如果匹配则去掉S和P的首字符，继续递归
            res= isFirstMathc && dfs(i + 1, j + 1);
        }
        map.put(pair, res);
        return map.get(pair);
    }
}
//一个辅助类，用来包装字符串S的下标i，和模式串P的下标j
//把i和j两个int作为一个整体封装为一个对象，hashmap的key会用到这个对象
class Pair {
    private int i;
    private int j;
    public Pair(int i, int j) {
        this.i = i;
        this.j = j;
    }

    public boolean equals(Object o) {
        if (this == o) return true;
        Pair other = (Pair)o;
        return this.i == other.i && this.j == other.j;
    }

    public int hashCode() {
        return this.i * 97 + this.j;
    }
}

}

class Solution(object):
    def isMatch(self, s, p):
        n = len(s)
        m = len(p)
        d = {}
        def dfs(i, j):
            if (i,j) in d:
                return d[i,j]
            #i==n说明字符串匹配完了，如果p的首字符是*，可以忽略，然后再递归检查
            #比如"aaa"和"aaa**"就是匹配的                
            if i == n:
                return j == m or (p[j] == "*" and dfs(i, j + 1))
            #如果模式串到头了，说明没匹配上    
            if j == m:
                return False
            #模式串当前字符为 *，有两条分支可以走
            #可以去掉S的首字符(i + 1)，也可以去掉P的首字符(j + 1)
            if p[j] == "*":
                d[i,j] = dfs(i + 1, j) or dfs(i, j + 1)
            #如果匹配则去掉S和P的首字符，继续递归    
            else:
                d[i,j]  = p[j] in (s[i], "?") and dfs(i + 1, j + 1)
            return d[i,j]
        return dfs(0,0)

动态规划

既然递归已经写出来了，那么我们按照递归的思路，去实现动态规划。
我们定义dp[n][m]数组，这里的n是字符S长度 + 1，m是模式串p长度 + 1。
dp[i][j]，表示S从开始到下标i，P从开始到下标j是否匹配。初的时候dp[0][0]为true，因为两个字符串都为空时是匹配的。如下图：

注意，我们定义的数组长度，要比原始字符长度 + 1。这是因为我们推导的时
候，有i - 1、j - 1这种情况。
核心代码，也就是那两层for循环，是从下标1开始的，而取得
的当前字符是需减一的。
比如当前的i是1，j也是1。
那么s[i - 1]拿的就是s的第一个字符，p[j - 1]
拿的是p的第一个字符。
所以p[j - 1] == s[i - 1]比较的是当个字符串的第一个字符。
很多字符串类型的动态规划，都会有这种问题，刚开始看可能很变扭，多看看，习惯了就好^_^

写递归的时候，如果s和p的当前字符相同，或者p的当前字符为?，就将s和p的当前字符删掉，继续递归比较两者的后续字符。
到动态规划，其转移公式为：

dfs(i + 1, j + 1)                递归，忽略S和P的当前字符，继续比较后面的
dp[i][j] = dp[i - 1][j - 1]      动态规划，当前结果由S的上一个和P的上一个的值转移而来

单个字符相对好理解一些，比较难的是*这种情况。
对于递归，当模式串p当前字符是*会有两条分支:
- 可以忽略掉 S 的当前字符，继续递归比较 S[i + 1:] 和 P
- 可以忽略掉 P 的当前字符，继续递归比较 p[j + 1:] 和 S

那么动态规划也是类似的，dp[i][j]的值由两条路径转移而来： 

递归，忽略掉S当前字符，或者P当前字符
dfs(i + 1, j) or dfs(i, j + 1)

动态规划，当前结果由S的上一个字符和P当前字符的值， 或者P的上一个字符和S的当前字符的值 转移而来
dp[i][j] = dp[i - 1][j] || dp[i][j - 1]

字符串为空，对应的就是第一行，具体实现过程请参考代码部分

class Solution {
public boolean isMatch(String _s, String _p) {
int n = _s.length();
int m = _p.length();
char[] s = _s.toCharArray();
char[] p = _p.toCharArray();
boolean[][] dp = new boolean[n + 1][m + 1];
//S为空，P为空时两个字符串相等
dp[0][0] = true;
//当字符串S为空，模式串P不空，检查P中是否有
for(int j = 1; j <= m; ++j) {
if(p[j - 1] == '') {
dp[0][j] = true;
} else {
break;
}
}
for(int i = 1; i <= n; ++i) {
for(int j = 1; j <=m; ++j) {
//如果P当前是 ，从递归的角度看
//可以将S的当前字符去掉(dp[i-1][j])
//也可以去掉P的当前字符(dp[i][j-1])
if(p[j - 1] == '') {
dp[i][j] = dp[i - 1][j] || dp[i][j - 1];
}
//否则，要看P和S的当前字符是否匹配，或者P当前字符为?
//如果当前字符匹配，从递归的角度看
//可以去掉S的当前字符，P的当前字符(dp[i-1][j-1])
else {
boolean isFirstMatch = p[j - 1] == s[i - 1] || p[j - 1] == '?';
dp[i][j] = isFirstMatch && dp[i - 1][j - 1];
}
}
}
return dp[n][m];
}
}

class Solution(object):
    def isMatch(self, s, p):
        n = len(s)
        m = len(p)
        dp = [[False] * (m + 1) for _ in range(n + 1)]
        #S为空，P为空时两个字符串相等
        dp[0][0] = True
        #当字符串S为空，模式串P不空，检查P中是否有*
        for j in range(1, m + 1):
            if p[j - 1] == '*':
                dp[0][j] = True
            else:
                break
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                #如果P当前是 *，从递归的角度看
                #可以将S的当前字符去掉(dp[i-1][j])
                #也可以去掉P的当前字符(dp[i][j-1])
                if p[j - 1] == '*':
                    dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
                #否则，要看P和S的当前字符是否匹配，或者P当前字符为?
                #如果当前字符匹配，从递归的角度看
                #可以去掉S的当前字符，P的当前字符(dp[i-1][j-1])
                else:
                    if p[j - 1] == s[i -1] or p[j - 1] == "?":
                        dp[i][j] = dp[i - 1][j - 1]

        return dp[-1][-1]
