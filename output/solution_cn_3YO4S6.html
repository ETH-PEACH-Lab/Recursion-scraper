LCR 141. 训练计划 III

解法一

思路和算法

原始链表中，每个结点的 $ extit{next}$ 指针都指向后一个结点。反转链表之后，每个结点的 $ extit{next}$ 指针都指向前一个结点。因此，反转链表需要改变每个结点的 $ extit{next}$ 指针指向的结点。

由于单链表中的每个结点都只有指向后一个结点的 $ extit{next}$ 指针，因此需要另外存储前一个结点，在遍历链表的过程中完成反转。

具体做法是，维护两个变量 $ extit{prev}$ 和 $ extit{curr}$ 分别表示前一个结点和当前结点，初始时 $ extit{prev} = ext{null}$，$ extit{curr} = extit{head}$。改变 $ extit{curr}$ 的 $ extit{next}$ 指针指向时，需要先得到其后面一个结点 $ extit{next}$，然后令 $ extit{curr}. extit{next}$ 指向 $ extit{prev}$，再将 $ extit{prev}$ 和 $ extit{curr}$ 都向后移动一步。对于链表中的每个结点进行上述操作，当 $ extit{curr}$ 变成 $ ext{null}$ 时，遍历结束，此时完成链表的反转，$ extit{prev}$ 指向反转后的链表的头结点。

下图为反转链表的例子。对于每个结点，需要将指向后一个结点的 $ extit{next}$ 指针变成指向前一个结点。虚线表示 $ extit{next}$ 指针原来的指向。

代码

```Java [sol1-Java]
class Solution {
public ListNode trainningPlan(ListNode head) {
ListNode prev = null, curr = head;
while (curr != null) {
ListNode next = curr.next;
curr.next = prev;
prev = curr;
curr = next;
}
return prev;
}
}

解法二

思路和算法

也可以使用递归的方法反转列表。迭代的方法较简单，递归的方法相对复杂。

对于递归问题，首先需要考虑终止条件。这道题的终止条件是链表为空或者只有 $1$ 个结点，此时不需要反转，直接返回链表即可。

当链表至少有 $2$ 个结点时，首先将除了头结点以外的部分反转，然后改变头结点和头结点后面一个结点的 $ extit{next}$ 指针的指向。

例如，原始链表为：

1 \rightarrow 2 \rightarrow 3

到达结点 $3$ 时为递归的终止条件，回到结点 $2$。

到达结点 $2$ 时，$3$ 已经反转完毕，将 $3$ 的 $ extit{next}$ 指针变成指向 $2$，将 $2$ 的 $ extit{next}$ 指针变成指向 $ ext{null}$。此时链表为：

1 \rightarrow 2 \leftarrow 3

到达结点 $1$ 时，$2$ 和 $3$ 已经反转完毕，将 $2$ 的 $ extit{next}$ 指针变成指向 $1$，将 $1$ 的 $ extit{next}$ 指针变成指向 $ ext{null}$。此时链表为：

1 \leftarrow 2 \leftarrow 3

反转链表结束。

需要注意的是，递归过程中将当前结点的 $ extit{next}$ 指针变成指向 $ ext{null}$ 是不可缺少的操作，否则链表中会出现环。

解法三

思路和算法

解法二使用递归，空间复杂度是 $O(n)$。如果使用尾递归，则可以将空间复杂度优化至 $O(1)$。

尾递归的含义是，一个方法或函数中所有递归形式的调用都出现在方法或函数的末尾，则这个递归方法或函数是尾递归的。当递归调用是整个方法或函数体中最后执行的语句，且返回值不属于表达式的一部分时，递归调用就是尾递归。尾递归的特点是在回归过程中不用做任何操作，当编译器检测到尾递归时，会覆盖当前的栈帧而不是新建一个栈帧，从而优化栈空间。

这道题可以使用尾递归实现。使用尾递归实现，需要创建一个辅助方法，该辅助方法包含两个参数，分别是前一个结点 $ extit{prev}$ 和当前结点 $ extit{curr}$。尾递归的具体实现如下：

  • 终止条件是 $ extit{curr} = ext{null}$，此时返回 $ extit{prev}$；

  • 当 $ extit{curr}
    e ext{null}$ 时，用 $ extit{next}$ 表示 $ extit{curr}$ 的后一个结点，令 $ extit{curr}. extit{next}$ 指向 $ extit{prev}$，然后用 $ extit{curr}$ 和 $ extit{next}$ 作为参数调用尾递归，返回值即为尾递归调用的返回值。

在主方法中调用尾递归方法时，参数为 $ extit{prev} = ext{null}$，$ extit{curr} = extit{head}$，反转后的链表的头结点即为调用尾递归方法的返回值。

class Solution {
public ListNode trainningPlan(ListNode head) {
return trainningPlanTail(null, head);

public ListNode trainningPlanTail(ListNode prev, ListNode curr) {
    if (curr == null) {
        return prev;
    }
    ListNode next = curr.next;
    curr.next = prev;
    return trainningPlanTail(curr, next);
}

}
