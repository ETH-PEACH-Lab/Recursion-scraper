简单易懂的递归方法
👤 arya-14 👍 0 2020-05-28 🖼 ↗ 查看原 Solution

解题思路

这道题很容易想到递归的方法，但是实现起来总会有些小问题。

递归的主旨就是一层一层地剥嘛，不管里面是什么都交给递归调用自身再处理。由于编码的格式是标准的，所以可以借助特殊字符'['、']'、'0'-'9'区分处理，但是遇到多层括号以及没有编码的字符时，简单地依靠特殊字符分类处理会导致错误计算字符串的重复次数。
以"a3[a2[c]]"为例：
1. 最外层还存在数字以外、未经编码的字符，如果只根据'['分割编码数字和编码字符串，会将"a3"认为是编码数字。
2. 双层括号，只根据'['分割编码数字和编码字符串，会将"a3[a2"认为是字符串"c"的重复次数。

那么我们采用递归的方法时，就需要注意如何区分未编码的字符和数字字符、外层括号和里层字符串。除了弹栈以及官方题解我没看懂的递归（好吧，其实是我根本没看咋回事，也不知道是不是跟我一样的思路），还可以用一个简单的cnt来指示：

  1. 将cnt初始化为0，遇到一个左括号就+1，遇到一个右括号就-1。也就是说cnt > 0的时候表示在括号里面；
  2. 当字符不是括号字符时，根据cnt是否为0来确定当前是不是外层，如果是外层并且不是数字字符，就直接加到答案字符串中，否则就记入重复字符串中，作为数字字符串待处理。
  3. 当遇到'['且cnt = 1的时候，就意味着我们进入了第一个里层，需要将前面记录的数字字符串转化成编码数字，接下来需要记录里层的字符串，当遇到里层的'['、']'时，对cnt进行相应的加减操作，因此当遇到']'且cnt不等于0时，就不用管它，直接记入里层字符串就可以，只有当cnt = 0时的']'时才表示这是最外层的结束括号，这个时候就可以把记录下来的里层字符串递归调用自身进行处理了。

代码

class Solution {
public:
    string decodeString(string s) {
        if(s.find('[')==s.npos) return s;
        int num = 0;
        string repe = "";
        string ans = "";
        int ind = 0;
        int cnt = 0;
        for(int i=0;i<s.length();i++) {
            char ch = s[i];
            if(ch=='[') {
                cnt ++;
                if(cnt==1) {    
                    for(char w:repe) {
                        num = num*10+(w-'0');
                    }
                    repe.clear();
                }
                else repe += ch;
            }
            else if(ch==']') {
                cnt --;
                if(cnt==0) {
                    repe = decodeString(repe);
                    for(int j=0;j<num;j++) {
                        ans+=repe;
                    }
                    repe.clear();
                    num = 0;
                }
                else repe += ch;
            }
            else {
                if(cnt==0&&(ch<'0'||ch>'9')) ans += ch;
                else repe += ch;
            }
        }
        return ans;
    }
};
