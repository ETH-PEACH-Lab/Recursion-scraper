C++ String and Recursion || 0ms + beats 99.89% Memory
👤 AIan 👍 0 2024-01-10 🖼 ↗ 查看原 Solution

Intuition

Everytime a [ is encountered, recursively explore the nested string fragment (defined as the string between the opened and closed brackets). The preceding number controls how many times the nested string is looped through. Anytime a character is encountered, append it to the target string.

Approach

Read inline comments

Complexity

  • Time complexity:
    O(n) - length of string

  • Space complexity:
    O(n+m) - length of string + max call stack

Code

class Solution {
private:
    int recurDecode(int sPtr, int loops, const string& s, string& dec) {
        int tempPtr; // to reassign with sPtr in each loop

        // Loops based on number before open bracket
        for (int loop = 0; loop < loops; loop++) {
            tempPtr = sPtr;
            while (tempPtr < s.size() && s[tempPtr] != ']') {
                if (isalpha(s[tempPtr])) {
                    dec += s[tempPtr];
                }
                else if (isdigit(s[tempPtr])) {

                    // Capture multiple digits in string number
                    string number;
                    while (isdigit(s[tempPtr])) {
                        number += s[tempPtr];
                        tempPtr++;
                    }

                    // Explore nested string fragment (recursively)
                    tempPtr = recurDecode(tempPtr+1, stoi(number), s, dec);
                }
                tempPtr++;
            }
        }
        return tempPtr; // return ptr so prev call knows where to continue
    }

public:
    string decodeString(string s) {
        int sPtr = 0; // string pointer
        string decoded;
        recurDecode(sPtr, 1, s, decoded);
        return decoded;
    }
};
